## ADDED Requirements

### Requirement: 桌面书籍详情保持双区工作台

`BookDetailsDesktop` MUST 在桌面断点下保持左侧目录/上下文侧栏与右侧主工作区同时可见，无论当前处于章节阅读还是设置上下文，MUST NOT 退化为 mobile/tablet 的模式切换式单主视图。

#### Scenario: 选择章节后侧栏仍保持可见

- **WHEN** 用户在桌面端选择某个章节进入阅读工作区
- **THEN** 左侧目录/上下文侧栏 MUST 继续保持可见，主工作区仅更新为该章节内容与工具栏

#### Scenario: 打开设置上下文后仍停留在当前书籍工作台

- **WHEN** 用户在桌面端切换到术语、角色或记忆管理
- **THEN** 系统 MUST 在当前书籍详情工作台内切换主内容区，而不是离开当前书籍或隐藏目录侧栏

### Requirement: 桌面侧栏采用分区式信息架构

`BookDetailsDesktop` 的左侧栏 MUST 将书籍概览、设置快捷入口、目录工具、章节树和返回入口组织为清晰分区，同时复用现有书籍编辑、设置跳转、卷/章节创建和章节拖拽行为。

#### Scenario: 书籍概览区显示关键元数据与编辑入口

- **WHEN** 桌面书籍详情页已加载书籍数据
- **THEN** 左侧栏 MUST 在顶部显示书籍封面、书名和关键统计，并保留现有书籍编辑入口

#### Scenario: 目录工具与拖拽行为保持可用

- **WHEN** 用户在桌面端使用卷/章节列表
- **THEN** 系统 MUST 保留新增卷、新增章节、编辑、删除和拖拽重排等现有直接操作行为

### Requirement: 桌面阅读工具栏突出主任务层次

`BookDetailsDesktop` MUST 将章节身份、主翻译操作和次级工具分层展示，优先突出当前章节与翻译任务，同时保留搜索、导出、快捷键、特殊指令等现有次级工具可达性。

#### Scenario: 章节主操作保持集中可达

- **WHEN** 用户在桌面端阅读某个章节
- **THEN** 页面 MUST 在章节工具栏中突出主要翻译操作，并使其无需进入额外弹层即可触发

#### Scenario: 次级工具仍在同一工作区内可达

- **WHEN** 用户需要搜索、导出、查看快捷键或打开章节设置
- **THEN** 系统 MUST 在同一桌面工作区内提供这些工具入口，而不是依赖 mobile/tablet 的抽屉式工具流

### Requirement: 桌面设置上下文与阅读上下文连续切换

`BookDetailsDesktop` MUST 在阅读上下文和术语/角色/记忆上下文之间提供连续切换，并保留当前书籍、路由语义和目录侧栏状态。

#### Scenario: 从阅读切换到术语后保持当前书籍上下文

- **WHEN** 用户从某本书的章节阅读切换到该书的术语设置
- **THEN** 系统 MUST 保持当前书籍详情路由上下文与目录侧栏可用，且 MUST NOT 跳转到全局设置页

#### Scenario: 从设置上下文返回内容区时保持当前工作台

- **WHEN** 用户从术语、角色或记忆上下文返回章节内容
- **THEN** 系统 MUST 返回同一个桌面书籍详情工作台，而不是重置为移动端默认入口态
