## Purpose

定义月詠桌面应用从发现正式版本、后台下载到用户主动重启更新的行为，确保平台架构匹配、状态可恢复、失败可重试，并避免更新过程打断正在执行的小说处理和数据保存。

## ADDED Requirements

### Requirement: 正式桌面包可检查和下载更新

系统 MUST 在可更新的正式桌面包启动后延迟检查，并以低频周期检查同平台架构的正式新版本，发现后后台下载。开发环境和 Web MUST NOT 执行原生更新。

#### Scenario: 发现可用更新

- **WHEN** 更新源有适用于当前包的较新正式版本
- **THEN** 应用显示目标版本和下载进度，并在下载完成后显示重启操作

#### Scenario: 请求重叠或网络失败

- **WHEN** 用户重复检查或检查时网络不可用
- **THEN** 系统不得重复并发下载，失败显示可重试信息并保持应用工作可用

### Requirement: 安装只能由用户主动且安全地触发

系统 MUST 只在用户确认后安装已下载更新；存在翻译、导入、同步、未完成保存时 MUST 拒绝重启并说明原因。准备成功到退出之间 MUST 阻止新工作启动。

#### Scenario: 活跃任务阻止重启

- **WHEN** 下载完成但仍有工作任务或持久化未完成
- **THEN** 重启请求失败且应用继续运行，更新包保持可用

#### Scenario: 空闲时更新

- **WHEN** 用户确认重启，准备和持久化检查成功
- **THEN** 应用退出后应用更新并重新启动，书库与设置继续使用原数据位置

#### Scenario: 取消、准备失败或超时

- **WHEN** 用户取消确认、renderer 无响应或保存检查失败
- **THEN** 系统不得启动安装程序，并恢复正常使用

### Requirement: 更新接口绑定可信应用和目标

系统 MUST 从固定官方更新源选择目标，renderer MUST NOT 指定任意安装路径或 URL；其他窗口或子 frame MUST NOT 触发更新命令。

#### Scenario: 非主窗口调用安装

- **WHEN** 子窗口、子 frame 或不匹配请求发送安装指令
- **THEN** 主进程拒绝请求且不安装任何包

### Requirement: 更新状态跨页面保留

系统 MUST 在关于区显示当前更新状态、手动检查和错误回退入口，切换页面不得重复注册检查或丢失主进程状态。

#### Scenario: 下载中重新打开关于区

- **WHEN** 用户离开关于区后重新打开
- **THEN** 界面展示当前下载状态，而不是重新开始检查或下载
