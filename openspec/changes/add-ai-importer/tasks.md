# Tasks

按下列依赖顺序推进。运行时逻辑任务中的验收用例须先运行并确认失败，再实现至转绿；纯类型、模板、样式和文档项使用相应的类型检查、页面检查或产物核对。每项完成后再勾选，规划完成不代表实现完成。

## 1. 回归基线与导入数据契约

- [x] 1.1 核对现有助手、网站抓取、书籍／正文保存、同步与恢复的回归测试及数据库版本，记录将复用或调整的入口；验收：相关现有 Vitest 用例运行结果与写入入口清单已记录，新增导入代码前的失败与既有问题可区分。
- [x] 1.2 定义任务、来源用途、发现引用、不可变快照、提取结果、内容范围、草稿操作、确认方案及应用回执类型；验收：类型检查通过，原文引用与模型生成字段可区分，模型入参不能设置宿主任务身份或用户确认标识。
- [x] 1.3 在 `bun run build:electron` 的产物中实测 `file://` 下 Web Locks、`BroadcastChannel` 与模块 Worker，核对同工作区多实例、窗口重建与旧执行清理，并在主进程接入按 `userData` 区分的单实例锁；验收：各能力有复现步骤，同一工作区第二次启动直接退出并唤醒已有工作台，不以单个 `mainWindow` 变量推导单上下文保证，不另建无锁的进程内互斥；Worker 不可用时验证分段让出、取消与规模上限。此结论是 3.8、8.4、5.5 与 7.6 的前置输入。

## 3. 书库保存边界与修改序号

- [x] 3.2 调整 `BookService` 的单本和批量保存，使一次书籍结构与所带正文保存使用共同事务并维护序号；验收：持久化中途失败不会留下半次保存，原公共调用方式及未变化正文跳过行为的回归用例通过。
- [x] 3.3 为 `ChapterContentService` 的单章／批量正文修改与删除接入所属书籍序号，并抽取共用提交后维护入口；验收：独立译文写入和正文删除递增序号，失败事务不提前更新缓存或索引，原章节服务回归用例通过。
- [x] 3.7 新增基于当前数据库快照的严格正文读取入口及按书装载能力，区分 `loaded`、`absent`、`failed`；验收：读取错误、损坏 JSON 和非法形状返回失败，记录不存在才是 `absent`，合法空数组为 `loaded`；已有正／负缓存都不能遮蔽当前结果，瞬时失败可再次读取，既有 loader 调用方与缓存行为不变。
- [x] 3.4 为 Memory 的创建、语义修改、删除及批量清理接入所属书籍序号；验收：内容变更能够阻止旧导入撤销，访问时间、派生嵌入更新和纯读取不会使小说被误判为后续修改。
- [x] 3.5 接通书籍删除、清空、同步下载和备份恢复等实际写入路径的序号维护；验收：通过各入口修改目标小说都会使旧预览失效，完整重置同时清理导入状态，定向删除不回退其他书籍序号。
- [x] 3.6 抽取同步删除记录的定向事务合并能力，供普通删除和新建导入撤销共用；验收：基于最新配置追加目标小说墓碑，并发或旧缓存不会覆盖其他删除记录、同步设置或凭据，既有删除／同步用例通过。
- [ ] 3.8 接入按书籍的 AI 写执行共享占用与短时提交独占守卫，覆盖整章、批量、单段翻译／润色／校对及其他正文写回入口；验收：占用在读取操作快照前取得，并保持到 composable 的回调及最外层最终保存结束，取消／终态标记不能提前释放；Web 跨标签有效，Electron 条件降级遵循 1.3，同书多章原有并发与其他书、只读任务不被误阻止，占用者信息可查询。

- [x] 4.3 实现相对链接解析、章节锚点保存和任务内资源去重；验收：保留有语义的查询参数，循环分页或重复发现不重复登记，文件名相同但资源不同不会合并，非 HTTP(S) 网络输入被拒绝。

- [x] 4.5 实现失败来源的错误记录与同任务补文件关联；验收：登录／验证页面、动态空壳和请求失败不成为正文，补充文件需要核对归属且保留原失败记录，成功章节不会被丢弃。

## 5. 文件解析与可调整的内容提取

- [x] 5.1 实现 TXT 编码识别、解码和稳定文本范围；验收：BOM、明确编码、乱码失败、换行保留、空输入及单行长文本的边界用例转绿，可读内容不因非常用扩展名被直接拒绝。
- [x] 5.2 实现 Markdown 块解析及规范化文本到原文的偏移映射，不直接把 token 的 `raw.length` 当原文件偏移；验收：CRLF／CR、空白、引用定义、嵌套块和多字节字符的切片往返正确，父子 token 不重复计数，无法核对位置时返回失败，脚本与外部资源不会执行或自动请求。
- [x] 5.3 实现 HTML／XHTML 的结构检查、链接提取、站点规则与通用 CSS 范围提取；验收：规则在保存的快照上执行，既有站点解析结果保持兼容，高层规则不适用时仍可通过通用读取和范围提取取得正文。
- [x] 5.4 按需引入 `fflate` 并实现 EPUB 容器、OPF、spine、导航／NCX 和资源检查；验收：EPUB 目录与阅读顺序样本解析正确，目录页、版权页、封面与正文可区分，不把所有归档条目直接建成章节。
- [x] 5.5 实现解包路径、条目数、解压量和执行时间限制，将大文件解码与解包放到按需 Worker，并落实 1.3 中适用的受限主线程路径；验收：越界路径、损坏／加密归档、超限输入及取消返回明确错误，主线程回退可让出并响应取消，两条路径停止后都不保存迟到结果。
- [x] 5.6 实现元信息、正文、前言／后记／注释的分类以及排除记录；验收：时间、导航和广告可从正文分离，附属文字默认保留，不确定片段不会静默删除，清理后可追溯原始范围。
- [x] 5.7 实现按规则重新提取与分页内容查看；验收：返回正文引用、预览、异常和后续游标，空正文不算成功，新规则生成新结果但不自动替换草稿引用，长文本不会因展示截断而丢失正文。

- [x] 6.2 实现卷章创建、拟名、拆合、移动、排序和正文引用关联；验收：推断结构与标题带标识，重组不改写原文，拒绝无效范围、其他任务内容和其他候选小说的既有段落引用。
- [x] 6.3 实现小说候选、来源范围归属和用户选择证据；验收：多本文件或单文件多作品先等待选择，新增冲突来源重新进入待处理状态，取消、跳过、旧问题答案或模型参数不能伪造确认。
- [x] 6.4 实现 `search_books` 及显式候选书籍的只读适配器，正文读取接入 3.7；验收：同名多版本不默认合并，切换全局书籍不改变目标，存储失败向 Agent 返回明确失败而非空章节，工具不修改书库。

- [x] 6.6 实现候选元信息采用与冲突处理，以及远程／EPUB 封面的持久值转换；验收：不同作者或版本作为待处理项，用户可选择采用字段，本地封面在刷新后仍有效，保存值不依赖临时 object URL。

## 9. 原子应用、撤销与提交后维护

- [x] 9.1 实现只由用户确认入口调用的应用服务和方案有效性检查；验收：草稿、目标或相关内容版本变化返回 `PLAN_STALE`，没有实际用户确认、模型声明确认及重载后的旧确认都不能写书库。
- [ ] 9.7 将 3.8 的目标书籍独占守卫用于应用与撤销，取得后再校验方案和修改序号，完成提交及必要缓存刷新后释放；验收：其他页写任务、取消／结束后尚未收尾的写入均返回 `TARGET_BUSY`，新写任务与提交竞争不会取得旧快照，只有实际完成最终保存后才可应用；其他书及只读任务不误拦截，重复已提交请求按回执返回而不重新写入。
- [x] 9.2 实现前镜像、小说结构、受影响正文、修改序号和操作回执的单事务提交；验收：任一写入或快照保存失败使书库保持原状，未影响章节不丢失，提交前不替换 UI 书库状态，受影响章节的前镜像通过 3.7 的入口读取且任一章节返回读取失败时整次应用被阻止（不得把读取失败的章节快照成空正文）。
- [x] 9.3 实现应用幂等、提交中断恢复及部分导入后继续补齐；验收：重复请求只返回既有结果，关闭页面后可辨别已提交与未提交，97／100 章的部分导入及后续补齐不会重复章节或再次清空未变译文。
- [x] 9.4 实现更新与新建的整次撤销及事务内后续修改检查；验收：可恢复被清空译文和原结构，新建撤销仅删除本次小说，新增译文／其他导入／同步变更／改后改回均阻止旧快照覆盖，纯查看不阻止撤销。
- [x] 9.5 将新建撤销的目标墓碑纳入事务，恢复操作使用新的本地修改序号与编辑时间；验收：撤销后既有同步可观察最终修改，不恢复旧全局配置、不删除共享封面历史，导入私有 stores 不进入同步载荷。
- [x] 9.6 接入共享缓存、全文索引和嵌入维护，持久化未完成维护事项并通知其他标签页；验收：已提交但维护失败不会重做导入，恢复可幂等补做，旧通知／旧任务不能写回旧正文，当前页和其他页重新读取后展示一致数据。
