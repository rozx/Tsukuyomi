# Tasks

按下列依赖顺序推进。运行时逻辑任务中的验收用例须先运行并确认失败，再实现至转绿；纯类型、模板、样式和文档项使用相应的类型检查、页面检查或产物核对。每项完成后再勾选，规划完成不代表实现完成。

## 1. 回归基线与导入数据契约

- [ ] 1.1 核对现有助手、网站抓取、书籍／正文保存、同步与恢复的回归测试及数据库版本，记录将复用或调整的入口；验收：相关现有 Vitest 用例运行结果与写入入口清单已记录，新增导入代码前的失败与既有问题可区分。
- [ ] 1.2 定义任务、来源用途、发现引用、不可变快照、提取结果、内容范围、草稿操作、确认方案及应用回执类型；验收：类型检查通过，原文引用与模型生成字段可区分，模型入参不能设置宿主任务身份或用户确认标识。

## 2. 本地任务与资源持久化

- [ ] 2.1 在下一个可用 IndexedDB 版本中创建设计指定的六个 stores 及必要索引，更新完整清理和测试重置入口；验收：升级、新建、升级被阻塞及重置用例转绿，既有书籍和正文记录不被重写。
- [ ] 2.2 实现导入任务、来源描述与资源仓库的创建、读取、分页和状态保存；验收：多个任务互不污染，来源列表查询不加载全部正文，Blob、来源关系和处理状态经过数据库往返后保持完整。
- [ ] 2.3 实现原始快照、提取结果和内容范围引用的保存与版本关联；验收：重复句子的块标识不同，刷新产生新快照而不覆盖旧引用，同名异内容文件不能冒充原快照。
- [ ] 2.4 实现消息、工具调用、工具结果和进度的事件记录与检查点保存；验收：重载可恢复完整工具调用配对，资源与完成回执一致提交，未完成的流式参数不会被当成可重放调用。
- [ ] 2.5 实现存储失败反馈及任务专属资源清理；验收：模拟配额或写入失败时显示未可靠保存，删除任务只清理其资源和撤销记录，不删除已导入小说，也不误清理仍被其他有效引用使用的数据。

## 3. 书库保存边界与修改序号

- [ ] 3.1 实现事务内的书籍语义修改序号维护及共用序列化辅助方法；验收：修改递增、无语义变化不递增、改后改回仍递增、删除后序号不复用，缺少历史序号的小说能够读取。
- [ ] 3.2 调整 `BookService` 的单本和批量保存，使一次书籍结构与所带正文保存使用共同事务并维护序号；验收：持久化中途失败不会留下半次保存，原公共调用方式及未变化正文跳过行为的回归用例通过。
- [ ] 3.3 为 `ChapterContentService` 的单章／批量正文修改与删除接入所属书籍序号，并抽取共用提交后维护入口；验收：独立译文写入和正文删除递增序号，失败事务不提前更新缓存或索引，原章节服务回归用例通过。
- [ ] 3.4 为 Memory 的创建、语义修改、删除及批量清理接入所属书籍序号；验收：内容变更能够阻止旧导入撤销，访问时间、派生嵌入更新和纯读取不会使小说被误判为后续修改。
- [ ] 3.5 接通书籍删除、清空、同步下载和备份恢复等实际写入路径的序号维护；验收：通过各入口修改目标小说都会使旧预览失效，完整重置同时清理导入状态，定向删除不回退其他书籍序号。
- [ ] 3.6 抽取同步删除记录的定向事务合并能力，供普通删除和新建导入撤销共用；验收：基于最新配置追加目标小说墓碑，并发或旧缓存不会覆盖其他删除记录、同步设置或凭据，既有删除／同步用例通过。

## 4. 来源登记、范围与页面读取

- [ ] 4.1 实现网址、单文件、批量文件和文件夹输入登记，仅保存输入及必要信息；验收：登记测试中没有正文请求、解码、解包或章节生成，浏览器目录清单只建立用户授予的文件范围。
- [ ] 4.2 实现正文根来源、正文派生来源及 `metadata-only` 的用途约束、父来源关系和宿主发现引用；验收：拒绝跨任务引用、任意本地路径和元信息来源的自行提权，用户主动补充同一网址可建立新的正文授予关系。
- [ ] 4.3 实现相对链接解析、章节锚点保存和任务内资源去重；验收：保留有语义的查询参数，循环分页或重复发现不重复登记，文件名相同但资源不同不会合并，非 HTTP(S) 网络输入被拒绝。
- [ ] 4.4 从现有抓取器抽取共用页面传输与可复用的单页面解析入口，支持取消和响应快照；验收：原代理、站点请求头及已支持网站的抓取回归通过，新导入调用只请求指定资源，返回下一页链接但不隐式继续抓取。
- [ ] 4.5 实现失败来源的错误记录与同任务补文件关联；验收：登录／验证页面、动态空壳和请求失败不成为正文，补充文件需要核对归属且保留原失败记录，成功章节不会被丢弃。

## 5. 文件解析与可调整的内容提取

- [ ] 5.1 实现 TXT 编码识别、解码和稳定文本范围；验收：BOM、明确编码、乱码失败、换行保留、空输入及单行长文本的边界用例转绿，可读内容不因非常用扩展名被直接拒绝。
- [ ] 5.2 实现 Markdown 标题和块结构解析及原文位置映射；验收：目录与正文片段可定位，嵌入脚本和外部资源不会执行或自动请求，按范围保存的内容保持原文。
- [ ] 5.3 实现 HTML／XHTML 的结构检查、链接提取、站点规则与通用 CSS 范围提取；验收：规则在保存的快照上执行，既有站点解析结果保持兼容，高层规则不适用时仍可通过通用读取和范围提取取得正文。
- [ ] 5.4 按需引入 `fflate` 并实现 EPUB 容器、OPF、spine、导航／NCX 和资源检查；验收：EPUB 目录与阅读顺序样本解析正确，目录页、版权页、封面与正文可区分，不把所有归档条目直接建成章节。
- [ ] 5.5 实现解包路径、条目数、解压量和执行时间限制，将大文件解码与解包放到按需 Worker；验收：越界路径、损坏／加密归档、超限输入及取消用例返回明确错误，Worker 停止后不继续保存迟到结果。
- [ ] 5.6 实现元信息、正文、前言／后记／注释的分类以及排除记录；验收：时间、导航和广告可从正文分离，附属文字默认保留，不确定片段不会静默删除，清理后可追溯原始范围。
- [ ] 5.7 实现按规则重新提取与分页内容查看；验收：返回正文引用、预览、异常和后续游标，空正文不算成功，新规则生成新结果但不自动替换草稿引用，长文本不会因展示截断而丢失正文。

## 6. 草稿操作、小说范围与元信息补充

- [ ] 6.1 实现同一草稿服务下的具名编辑操作及 `baseDraftRevision` 比较；验收：手动编辑与 Agent 编辑共享状态，过时操作返回 `DRAFT_CHANGED`，整批操作失败不会留下部分草稿修改。
- [ ] 6.2 实现卷章创建、拟名、拆合、移动、排序和正文引用关联；验收：推断结构与标题带标识，重组不改写原文，拒绝无效范围、其他任务内容和其他候选小说的既有段落引用。
- [ ] 6.3 实现小说候选、来源范围归属和用户选择证据；验收：多本文件或单文件多作品先等待选择，新增冲突来源重新进入待处理状态，取消、跳过、旧问题答案或模型参数不能伪造确认。
- [ ] 6.4 实现 `search_books` 及按显式候选书籍读取的只读适配器；验收：建议依据来自本地书库，同名多版本不默认合并，切换全局当前书籍不会改变读取目标，也不触发书库修改。
- [ ] 6.5 为 `search_web` 和后续信息页读取接入元信息专用用途，复用现有搜索配置；验收：作者、简介、别名和封面候选保留出处，未配置或失败时不丢草稿，搜索页中的正文及派生链接不能绕过正文来源限制。
- [ ] 6.6 实现候选元信息采用与冲突处理，以及远程／EPUB 封面的持久值转换；验收：不同作者或版本作为待处理项，用户可选择采用字段，本地封面在刷新后仍有效，保存值不依赖临时 object URL。

## 7. 章节匹配与实际变更计划

- [ ] 7.1 实现基于一致书库快照的章节候选和显式匹配，读取懒加载正文并绑定书籍修改序号；验收：URL、已有应用映射和用户选择可作为依据，标题／顺序只作为候选，读取失败不会被当成空章节。
- [ ] 7.2 实现限定范围内的精确段落锚点与顺序匹配；验收：插入导致的索引偏移、跨章移动和重复句子用例转绿，未变段落保留正确 ID 与全部译文，歧义不会随机移植译文。
- [ ] 7.3 实现原文修订、新增及明确范围替换的计划生成；验收：修订段落清空全部翻译和当前选用，新段落没有借用译文，多对多替换列出实际损失，不使用标点或语义近似掩盖原文变化。
- [ ] 7.4 实现显式卷章重组、范围外内容保留与设置冲突；验收：拆合仅处理确认范围，缺席、未选择和失败的旧章节保留，章节专属设置冲突可定位，术语、角色及其他无关小说数据不被覆盖。
- [ ] 7.5 实现 `ImportPlan`、稳定实体 ID 和 `preview_import`；验收：以真实数据计算字段差异及译文清空数量，“3 段／5 个版本”样本结果准确，未知完整性与缺失章节明确显示，未解决覆盖歧义不可应用。
- [ ] 7.6 将大范围匹配放入可取消 Worker，并保存已应用的来源到书库 ID 映射；验收：算法规模受限且取消不写回旧结果，同任务补齐缺章可生成新方案，已应用且未变化的内容不重复创建。

## 8. Agent 工具集、执行与恢复

- [ ] 8.1 为现有助手调用循环增加显式执行配置、检查点及让出执行接口，保持普通聊天默认配置；验收：先建立配置注入与任务上下文隔离的失败用例，普通聊天流式输出、摘要及工具调用回归通过。
- [ ] 8.2 注册设计中的来源、提取、草稿、本地对照和预览工具，校验入参、宿主上下文及本轮工具集合；验收：批次只执行指定范围并逐项返回结果，伪造任务身份、任意脚本、普通书库写工具以及直接应用／撤销调用均不能越界。
- [ ] 8.3 实现 `ImportAgentService`、导入提示词与显式模型配置绑定；验收：来源文本只作为数据，模型凭据不进入任务和日志，正文按需读取，工具／上下文限额触发保存后暂停而非伪报完整导入。
- [ ] 8.4 实现 Web Locks 单运行协调、运行代次校验和任务状态转换；验收：同源两个标签页不能同时执行导入 Agent，未取得锁明确返回忙碌，不排队自动启动或抢占，缺少必要能力时不启用假互斥执行。
- [ ] 8.5 实现暂停、取消在途请求、迟到结果处理和持久检查点恢复；验收：显示已暂停后不发起新步骤，切换查看不改变运行归属，刷新不自动运行或写书库，恢复不重放已成功的提取及草稿操作。
- [ ] 8.6 适配导入专属问答和待办，保存必要问题并在等待回答时让出执行；验收：刷新可恢复候选和待回答工具调用，回答严格绑定问题及来源版本，取消／跳过／他任务回答不解除门槛，普通问答行为保持兼容。

## 9. 原子应用、撤销与提交后维护

- [ ] 9.1 实现只由用户确认入口调用的应用服务和方案有效性检查；验收：草稿、目标或相关内容版本变化返回 `PLAN_STALE`，没有实际用户确认、模型声明确认及重载后的旧确认都不能写书库。
- [ ] 9.2 实现前镜像、小说结构、受影响正文、修改序号和操作回执的单事务提交；验收：任一写入或快照保存失败使书库保持原状，未影响章节不丢失，提交前不替换 UI 书库状态。
- [ ] 9.3 实现应用幂等、提交中断恢复及部分导入后继续补齐；验收：重复请求只返回既有结果，关闭页面后可辨别已提交与未提交，97／100 章的部分导入及后续补齐不会重复章节或再次清空未变译文。
- [ ] 9.4 实现更新与新建的整次撤销及事务内后续修改检查；验收：可恢复被清空译文和原结构，新建撤销仅删除本次小说，新增译文／其他导入／同步变更／改后改回均阻止旧快照覆盖，纯查看不阻止撤销。
- [ ] 9.5 将新建撤销的目标墓碑纳入事务，恢复操作使用新的本地修改序号与编辑时间；验收：撤销后既有同步可观察最终修改，不恢复旧全局配置、不删除共享封面历史，导入私有 stores 不进入同步载荷。
- [ ] 9.6 接入共享缓存、全文索引和嵌入维护，持久化未完成维护事项并通知其他标签页；验收：已提交但维护失败不会重做导入，恢复可幂等补做，旧通知／旧任务不能写回旧正文，当前页和其他页重新读取后展示一致数据。
