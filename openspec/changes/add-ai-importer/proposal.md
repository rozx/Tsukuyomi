# Proposal

## Why

现有导入以特定网站抓取和应用 JSON 数据为主，用户需要自行整理普通小说文件、辨认卷章并对应书库中的内容。新增独立的 AI 导入工作台，让 Agent 按需调用工具读取来源、提取小说资源并整理为一本小说，在用户检查并确认具体变更后创建或更新书籍，同时保留可恢复的任务进度和可撤销的导入结果。

## What Changes

- 新增与首页、书库、AI 管理平级的 AI 导入入口。桌面工作台左侧提供文件选择、来源列表和卷章预览编辑，右侧复用月詠的消息、输入、工具操作记录及适用的通用工具；桌面、平板、手机均提供等价功能入口。
- 接收网址、单个文件、批量文件和用户选定的文件夹。通过提供给 Agent 的解析工具支持 EPUB、TXT、Markdown、HTML；其他格式只要现有解析能力能读出内容、Agent 能识别小说结构，也可接纳，不仅凭文件后缀判定支持范围。
- 添加来源只登记任务输入及必要元信息，不自动启动内容抓取或正文解析。由 Agent 决定并调用工具查看来源、枚举文件、读取内容、提取小说信息与章节资源，根据工具返回结果决定下一步。工具可执行 Agent 明确指定范围的单次或批量提取，来源添加事件不启动独立的固定抓取流程。
- 同时提供小说目录、章节正文等高层提取能力，以及来源检查、分页读取和按范围提取的通用能力。正文保存为可追溯的内容引用，Agent 通过引用组织草稿；草稿查看、编辑和导入预览工具按实际数据返回结果，最终书库写入由用户确认触发。
- Agent 在现有网页抓取与代理能力范围内调用工具读取目录，从返回结果中识别章节、下一章和分页链接，再按需调用工具继续读取并追加来源；文件夹中的文件发现与追加同样由工具调用驱动。记录工具调用、提取结果、每个来源由用户提供还是由 Agent 发现，以及发现路径。
- 正文来源限于用户提供的来源及其相关资源。保留 `search_web` 用于补充作者、简介、封面、别名等元信息，支持读取候选信息页和提取实际封面地址，保留出处并在草稿中供用户确认；搜索结果不自动成为正文来源，也不用全网搜索补齐缺章。
- 内容提取支持已有解析规则和 Agent 指定的正文范围、排除规则。书名、作者等元信息与正文分开，导航、广告等杂质可排除；前言、后记、注释默认保留并标记。保留原始来源及排除记录，Agent 可自主检查、调整规则并重试，无法判断是否属于正文时询问用户。
- 每个任务只处理一本小说。检测到多本时暂停整理并要求用户选择，确认前不混合生成卷章或应用导入；后续追加来源也检查小说归属。
- Agent 可识别或推断卷章结构，为缺失标题拟名，并提出拆章、合章和移动段落的方案。保留提取到的正文，标明推断的结构与标题。用户可直接修改书名、卷章标题、顺序和归属，Agent 后续基于最新草稿继续处理。
- 用户可预先指定新建或更新目标，也可让 Agent 检查书库并提出建议；有匹配歧义时询问用户。新建和更新都必须展示导入方案，列出目标小说、选中章节、新增、修订、结构重组及译文清空的影响，确认后才写入书库。
- 更新支持新增章节、修订已有章节和经确认的卷章重组。原文未变化的段落即使移动也保留译文；原文被更新的段落清空全部翻译版本及当前选用。新来源缺席的旧章节继续保留，不因抓取不全或目录缺失推定删除。
- 允许部分导入，明确展示成功、失败和已知缺失章节，不将部分结果标记为完整。网址无法读取时，提示用户提供文件，在同一任务中补充并继续整理。
- 提供导入任务列表，各任务独立保存来源、已提取内容、草稿、对话和执行进度。同一时间只运行一个导入 Agent，支持暂停、切换和恢复；刷新或关闭网页后可从保存的进度继续，网页关闭期间不执行任务。
- 应用前保存撤销所需的快照，支持撤销新建或恢复更新前的卷章结构、原文和译文。只有目标小说在导入后没有后续修改时才允许整次撤销，否则阻止快照覆盖并说明原因。
- 保持现有 Web 架构和本地存储方式，不新增后端、浏览器扩展或远程浏览器服务。真实浏览器点击控制、登录接管，以及专门新增的 PDF、DOCX 解析或从图片、扫描件识别正文的 OCR 不属于本次范围。

## Capabilities

### New Capabilities

- `ai-import-workspace`: 独立导入入口、设备适配、文件与卷章预览编辑，以及绑定导入任务的月詠对话和操作记录。
- `ai-import-source-discovery`: 来源登记与 Agent 主导的两层提取工具、文件解析、相关资源发现、元信息搜索、可调整的正文清理与来源追溯、单本小说识别与确认，以及无法读取时的补充文件流程。
- `ai-import-task-lifecycle`: 多个独立导入任务的本地保存、单任务执行、暂停与恢复，以及草稿和会话在任务切换、刷新后的连续性。
- `ai-import-apply-and-undo`: 卷章整理与重组、导入目标建议、变更预览与确认、部分导入、段落翻译保留或清空、缺席章节保留，以及受后续修改保护的整次撤销。

### Modified Capabilities

无。已有网站抓取更新、通用问答和翻译任务的行为约定保持不变；本次复用其组件和适用工具，新增的导入行为由上述能力描述。

## Impact

- 页面与导航：涉及 `src/router/`、主导航组件、新的导入页面及其 Desktop / Tablet / Mobile 变体。
- 共享助手：涉及月詠消息、输入和操作记录组件，以及会话、上下文和 AI 工具的复用；向 Agent 提供来源查看、读取、资源提取与追加、元信息搜索、本地书库对照、草稿编辑及预览能力。来源登记、Agent 工具执行、草稿操作与最终书库写入需要区分。
- 业务与持久化：涉及新的导入任务、来源和草稿数据，以及现有书籍、章节、段落翻译和 IndexedDB 服务；需支持保存进度、应用导入和撤销时的后续修改检查。
- 解析与抓取：将现有抓取及代理链路和可在浏览器运行的文件解析能力封装为 Agent 可调用的工具，按调用参数执行并返回结果。具体工具接口、解析依赖、章节匹配和存储方案在设计阶段确定。
- 验证：后续实现需覆盖添加来源不触发内容抓取或解析、Agent 工具调用与资源追加、搜索用途限制、正文清理与原文保留、来源归属、分章与重组、未改原文译文保留、修订译文清空、部分导入、任务恢复和撤销保护。
