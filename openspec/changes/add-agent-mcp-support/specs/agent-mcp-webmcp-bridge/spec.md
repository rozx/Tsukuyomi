# Spec Delta

## Purpose

在浏览器运行时将共享外部 Agent 工具内核适配到 WebMCP 标准接口，使支持 WebMCP 的浏览器内置 Agent 或桥接扩展能够安全发现并调用 Tsukuyomi 的翻译与书库操作能力。

## ADDED Requirements

### Requirement: 兼容探测浏览器 WebMCP 接口
浏览器适配层 SHALL 兼容探测当前文档与运行环境中的 WebMCP 上下文对象（优先支持标准文档级模型上下文接口，并向后兼容早期导航器级模型上下文接口），在不支持该接口的普通浏览器中 MUST 静默降级而不抛出运行时错误。

#### Scenario: 原生或桥接环境存在 WebMCP 接口时识别可用状态
- **WHEN** 页面运行在提供 WebMCP 模型上下文接口的浏览器或已注入兼容桥接的环境中
- **THEN** 适配层报告运行环境支持 WebMCP 并记录接口来源类型

#### Scenario: 不支持 WebMCP 的浏览器静默降级
- **WHEN** 页面运行在未提供 WebMCP 接口的常规浏览器中
- **THEN** 应用正常启动且不产生未捕获异常，界面明确显示当前浏览器未检测到 WebMCP 支持

### Requirement: 受开关与权限驱动的动态工具注册与注销
当 WebMCP 开关处于开启且环境可用时，适配层 SHALL 将当前权限模式允许的工具集合注册到浏览器模型上下文并附带只读标记提示；当关闭开关、切换权限模式或应用卸载时，适配层 MUST 注销先前注册的工具（优先使用中止信号机制，缺省时回退到显式注销方法）。

#### Scenario: 开启 WebMCP 开关后注册可用工具
- **WHEN** 用户在支持 WebMCP 的环境中开启 WebMCP 开关
- **THEN** 适配层将当前权限模式下允许的所有工具注册到浏览器模型上下文，并按工具性质标记只读提示

#### Scenario: 切换权限模式后同步更新已注册工具
- **WHEN** 用户将权限模式从读写模式切换为仅只读模式
- **THEN** 适配层注销原有写类工具，使浏览器模型上下文中仅保留只读工具

#### Scenario: 关闭开关或热重载清理全部已注册工具
- **WHEN** 用户关闭 WebMCP 开关或运行环境触发清理生命周期
- **THEN** 适配层注销所有已注册工具，不再响应外部浏览器 Agent 的工具调用

### Requirement: WebMCP 通道暴露翻译工作流指南
由于浏览器 WebMCP 工具接口侧重工具调用而不一定提供独立 Prompt 列表端点，适配层 SHALL 在 WebMCP 通道额外暴露只读工作流指南工具，供浏览器 Agent 获取章节翻译、润色校对与导入翻译的标准工作流说明。

#### Scenario: 浏览器 Agent 读取翻译工作流指南
- **WHEN** 浏览器 Agent 通过 WebMCP 调用工作流指南工具并指定章节翻译流程
- **THEN** 适配层返回与桌面端 MCP Prompt 等价的结构化翻译规范文本

### Requirement: 统一记录 WebMCP 调用与来源标识
通过 WebMCP 通道触发的工具执行 SHALL 复用共享工具内核的权限门禁、调用活动日志与可选写操作通知，并在未显式传入来源标签时将写入译文的来源标识标记为 WebMCP 外部通道。

#### Scenario: 通过 WebMCP 写入译文并留下来源与活动记录
- **WHEN** 浏览器 Agent 通过 WebMCP 调用批量译文提交工具且未指定自定义模型名
- **THEN** 译文以 WebMCP 外部来源标识保存，且活动日志记录通道为 WebMCP 并展示执行状态与耗时
