# Spec Delta

## Purpose

为用户提供独立于设置页的一级「外部 Agent / MCP」工作台页面与导航入口，覆盖桌面、平板与手机三种设备形态，集中完成双端连接控制、客户端快捷接入配置、已暴露工具浏览以及实时调用观测。

## ADDED Requirements

### Requirement: 平行于 AI 导入与 AI 模型的一级导航入口与路由
系统 SHALL 提供独立的 `/mcp` 页面路由，并在桌面侧边栏与平板侧边导航栏中将其作为一级导航项展示在主功能区（平行于首页、书库、AI 导入与 AI 模型）；手机端保持既有核心底部栏结构，同时提供可从应用内直达 `/mcp` 页面的入口。

#### Scenario: 桌面与平板用户通过主导航进入外部 Agent 工作台
- **WHEN** 用户在桌面或平板端点击主导航栏中的「外部 Agent / MCP」入口
- **THEN** 路由切换至 `/mcp` 且该导航项保持激活高亮状态

#### Scenario: 手机端直达外部 Agent 工作台
- **WHEN** 手机端用户通过快捷入口或直接访问 `/mcp` 路由打开页面
- **THEN** 系统渲染适配移动端交互的外部 Agent 工作台页面

### Requirement: 三设备变体分派与状态保持
`/mcp` 页面 MUST 遵循应用统一的设备变体分派模式，具备独立的分派器入口、共享页面逻辑层以及桌面、平板、手机三个变体视图；运行时跨断点切换视图时 MUST 保留当前选中的客户端配置标签页、工具筛选条件与未保存的端口编辑状态。

#### Scenario: 运行时窗口尺寸跨越断点不丢失页面状态
- **WHEN** 用户在 `/mcp` 页面选中了 Pi 配置标签页并正在查看活动日志，随后缩放窗口跨越桌面与移动断点
- **THEN** 页面切换至对应设备变体渲染，且选中的配置标签页与活动日志内容保持不变

### Requirement: 连接运行控制与安全配置管理
`/mcp` 工作台 SHALL 提供清晰的运行状态与配置操作区：桌面端展示本地 MCP 服务端运行状态（运行中/已停止/报错）、启停开关、监听端口修改、Bearer Token 脱敏查看/一键复制/重新生成；浏览器端展示 WebMCP 开关与当前浏览器 WebMCP 能力检测状态（原生可用/桥接可用/未检测到）；两端均提供权限模式切换、默认译文写回模式切换与写操作通知开关。

#### Scenario: 桌面端启动本地 MCP 服务并复制凭据
- **WHEN** 用户在桌面端 `/mcp` 页面开启本地 MCP 服务端开关
- **THEN** 界面显示运行中状态与实际监听地址 `http://127.0.0.1:<port>/mcp`，并允许一键复制 Bearer Token 或重新生成令牌

#### Scenario: 浏览器端明确提示环境是否支持 WebMCP
- **WHEN** 用户在未支持 WebMCP 的常规浏览器中打开 `/mcp` 页面
- **THEN** 界面以清晰状态徽标提示未检测到 WebMCP 模型上下文接口，并提供启用说明而不展示桌面端专属端口监听开关

### Requirement: 主流 Coding Agents 一键接入配置片段
`/mcp` 工作台 SHALL 针对 Claude Code、Pi、Antigravity 以及浏览器 WebMCP 提供分组切换的接入指引与可一键复制的配置片段；桌面端配置片段 MUST 动态填入当前配置的端口与实时 Bearer Token。

#### Scenario: 复制 Claude Code 或 Pi 的即时可用配置
- **WHEN** 用户在桌面端 `/mcp` 页面切换到 Claude Code 或 Pi 标签页并点击复制按钮
- **THEN** 剪贴板写入包含当前 `http://127.0.0.1:<port>/mcp` 地址与有效 Bearer Token 的命令或 `mcp.json` 配置，并展示复制成功提示

#### Scenario: 重新生成令牌后配置片段自动同步更新
- **WHEN** 用户点击重新生成 Bearer Token
- **THEN** 所有客户端配置片段中的令牌占位立即更新为新令牌

### Requirement: 暴露工具目录与实时调用活动观测
`/mcp` 工作台 SHALL 展示当前权限模式下已对外暴露的工具列表（含只读/写入标识、简要说明与工作流模板列表），并实时展示内存态外部调用活动日志（包含时间戳、通道、工具名、参数摘要、成功或失败状态、耗时与清空日志按钮）。

#### Scenario: 权限模式切换实时反映在工具目录中
- **WHEN** 用户将权限模式从 `translate_and_edit` 切换为 `read_only`
- **THEN** 工具目录实时收窄为只读工具集合，写入类工具显示为未暴露或从可用列表移除

#### Scenario: 实时观测外部 Agent 翻译调用过程
- **WHEN** 外部 Coding Agent 连续调用拉取翻译块与提交译文工具
- **THEN** `/mcp` 页面的活动日志区域按最新优先顺序实时追加每条调用的状态与耗时，且用户可随时一键清空日志

### Requirement: 三语国际化与帮助文档同步
`/mcp` 工作台的所有可见界面文案、导航项名称、状态说明、错误提示与接入指引 MUST 同步提供简体中文、繁体中文与英文三语翻译，且帮助文档三语目录 SHALL 同步补充外部 Agent / MCP 接入与使用指南。

#### Scenario: 切换界面语言后工作台文案完整本地化
- **WHEN** 用户在简体中文、繁体中文与英文之间切换应用界面语言并访问 `/mcp`
- **THEN** 导航标题、配置项说明、接入指引与日志状态标签均按所选语言正确显示，无缺失键名或回退乱码
