# Spec Delta

## Purpose

为用户提供独立于设置页的一级「外部 Agent / MCP」工作台页面与导航入口，覆盖桌面、平板与手机三种设备形态，集中完成双端连接控制、客户端快捷接入配置、已暴露工具浏览以及实时调用观测。

## ADDED Requirements

### Requirement: 平行于 AI 导入与 AI 模型的一级导航入口与路由
系统 SHALL 提供独立的 `/mcp` 页面路由，并在桌面侧边栏与平板侧边导航栏中将其作为一级导航项展示在主功能区（平行于首页、书库、AI 导入与 AI 模型）；手机端保持既有核心底部栏结构，同时提供可从应用内直达 `/mcp` 页面的入口。

#### Scenario: 桌面与平板用户通过主导航进入外部 Agent 工作台
- **WHEN** 用户在桌面或平板端点击主导航栏中的「外部 Agent / MCP」入口
- **THEN** 路由切换至 `/mcp` 且该导航项保持激活高亮状态

#### Scenario: 手机端直达外部 Agent 工作台
- **WHEN** 手机端用户通过快捷入口或直接访问 `/mcp` 路由打开页面
- **THEN** 系统渲染适配移动端交互的外部 Agent 工作台页面

### Requirement: 三设备变体分派与状态保持
`/mcp` 页面 MUST 遵循应用统一的设备变体分派模式，具备独立的分派器入口、共享页面逻辑层以及桌面、平板、手机三个变体视图；运行时跨断点切换视图时 MUST 保留当前选中的分栏、客户端配置标签页、已展开的工具类别与未保存的端口编辑状态。

#### Scenario: 运行时窗口尺寸跨越断点不丢失页面状态
- **WHEN** 用户在 `/mcp` 页面选中了 Pi 配置标签页并正在查看活动日志，随后缩放窗口跨越桌面与移动断点
- **THEN** 页面切换至对应设备变体渲染，且选中的配置标签页与活动日志内容保持不变

### Requirement: 桌面工作台的看板布局
桌面与平板的 `/mcp` 工作台 SHALL 铺满可用空间且页面自身不滚动：页头显示服务状态、当前权限、开放的工具数量与本次会话的调用次数；页头下方的看板占满剩余高度，并按页面可用宽度分为三档——足够宽时接入、调用活动、权限与能力三栏并排；中等宽度时左栏固定为接入、右栏通过标签在其余分栏间切换；较窄时通过标签一次显示一栏。任何一档下，内容超出时 MUST 只在栏内滚动。

#### Scenario: 宽屏三栏并排
- **WHEN** 页面可用宽度足够容纳三栏
- **THEN** 接入、调用活动、权限与能力三栏并排并占满看板高度，不出现大片留白；接入栏的指南文本框占满该栏剩余高度

#### Scenario: 内容超出时只在栏内滚动
- **WHEN** 某一栏的内容高度超过可用空间（例如调用活动条目很多）
- **THEN** 只有该栏内部滚动，页头与其他栏保持不动，页面整体不滚动；调用活动栏的标题与清空按钮保持可见

#### Scenario: 中等宽度两栏
- **WHEN** 页面可用宽度不足以容纳三栏但可以容纳两栏
- **THEN** 左栏显示接入，右栏显示调用活动，并可通过标签切换为权限与写回或开放的能力

#### Scenario: 较窄宽度一次一栏
- **WHEN** 页面可用宽度只够容纳一栏
- **THEN** 页面通过顶部标签在各分栏间切换，一次显示一栏；选中的分栏在跨断点切换视图后保持

#### Scenario: 页头概览随状态变化
- **WHEN** 服务开启或关闭、权限模式变更，或收到新的外部调用
- **THEN** 页头的服务状态、权限、工具数量与调用次数随之更新，调用活动标签旁显示本次会话的调用次数

#### Scenario: 浏览器端没有连接设置
- **WHEN** 用户在浏览器版打开 `/mcp` 页面
- **THEN** 页面不显示连接设置（端口与令牌只属于桌面端本地服务）

### Requirement: 按使用顺序组织的接入流程
`/mcp` 工作台 SHALL 把接入过程组织为两个按顺序排列的步骤：先开启服务（桌面端为本地 MCP 服务端，浏览器端为 WebMCP），再把快速上手指南交给外部 Agent；客户端配置片段作为「手动添加 MCP」的可选内容默认收起，供不使用指南的用户展开；并 MUST 明确显示当前会话是否已收到外部调用。

#### Scenario: 手动添加默认收起
- **WHEN** 用户打开 `/mcp` 页面
- **THEN** 客户端配置片段默认不显示；用户展开「手动添加 MCP」后才出现，展开状态在跨断点切换视图时保留

#### Scenario: 桌面端启动本地 MCP 服务
- **WHEN** 用户在桌面端 `/mcp` 页面开启本地 MCP 服务端开关
- **THEN** 界面显示运行中状态与实际监听地址 `http://127.0.0.1:<port>/mcp`，并允许一键复制该地址

#### Scenario: 服务未运行时手动配置不可复制
- **WHEN** 桌面端本地 MCP 服务端处于停止或异常状态，且用户展开了手动添加
- **THEN** 客户端配置片段以不可用状态显示、复制操作被禁用，并提示需先开启服务

#### Scenario: 浏览器端开启 WebMCP
- **WHEN** 用户在浏览器端 `/mcp` 页面开启 WebMCP 开关
- **THEN** 界面显示已开启，并提示使用期间需保持本页打开；不展示桌面端专属的端口与令牌

#### Scenario: 页面不在安全上下文
- **WHEN** 页面不是通过 HTTPS 或 localhost 打开
- **THEN** WebMCP 开关不可开启，界面说明需要改用 HTTPS 地址访问

#### Scenario: 中继接不上时说明原因
- **WHEN** 浏览器端开启 WebMCP 后本地中继无法使用（浏览器自带旧版实现且无法替换，或运行时加载失败）
- **THEN** 界面在开启步骤下显示具体原因与处理办法

#### Scenario: 提示只保留一个标签页
- **WHEN** 用户在浏览器端查看开启步骤
- **THEN** 界面提示使用期间保持本页打开且只开一个标签页，否则 Agent 看到的工具名会带上标签页后缀

#### Scenario: 收到首次调用后显示已连通
- **WHEN** 外部 Agent 发出本次会话的第一次工具调用
- **THEN** 接入流程区域从「等待调用」变为「已连通」，并显示最近一次调用的工具与时间

### Requirement: Agent 客户端配置片段
`/mcp` 工作台 SHALL 在「手动添加 MCP」中提供可切换、可一键复制的 Agent 客户端配置与放置说明。桌面端针对 Claude Code、Pi、Antigravity 给出直连本地 MCP 服务端的配置，MUST 动态填入当前端口与实时访问令牌；浏览器端给出添加 WebMCP 本地中继的配置（Claude Code 命令与通用 JSON 两种形式），MUST 将中继限定为只接受本页来源的连接。

#### Scenario: 复制 Claude Code 或 Pi 的即时可用配置
- **WHEN** 桌面端服务运行中，用户切换到 Claude Code 或 Pi 标签页并点击复制按钮
- **THEN** 剪贴板写入包含当前 `http://127.0.0.1:<port>/mcp` 地址与有效访问令牌的命令或配置，并展示复制成功提示

#### Scenario: 重新生成令牌后配置片段自动同步更新
- **WHEN** 用户确认重新生成访问令牌
- **THEN** 桌面端所有客户端配置片段中的令牌立即更新为新令牌

#### Scenario: 浏览器端复制本地中继配置
- **WHEN** 用户在浏览器端复制客户端配置
- **THEN** 剪贴板写入启动 WebMCP 本地中继的命令或 JSON，其中把允许连接的页面来源限定为本页地址；该配置不含令牌，WebMCP 尚未开启时也可以复制

### Requirement: Agent 快速上手指南
`/mcp` 工作台 SHALL 提供一份可一键复制的 Agent 快速上手指南，用户把它粘贴给外部 Agent 即可完成接入。指南 MUST 以「首次设置」开头，让 Agent 替用户依次完成：询问并建立项目文件夹、在该文件夹内配置本 MCP 服务、把指南保存为该文件夹中的项目级说明文件、告知用户之后在该文件夹中启动即可而无需再次粘贴；随后 MUST 包含数据模型、如何了解书库现状、当前通道全部工具的清单与说明、分步工作流、必须遵守的规则与常见错误的处理方式。指南是通用内容，MUST NOT 依赖用户选择具体任务或书籍；工具清单 MUST 由实际注册的工具生成，并随通道与界面语言变化。

#### Scenario: 复制快速上手指南
- **WHEN** 用户点击复制指南
- **THEN** 剪贴板写入完整的指南文本并展示复制成功提示；服务尚未开启时同样可以复制

#### Scenario: 指南说明如何了解用户正在看什么与如何回答使用问题
- **WHEN** 外部 Agent 阅读指南中「了解现状」一节
- **THEN** 指南说明用户提到「这一段」「这一章」「这里」时先读取应用上下文，要在全书查找一个词时使用全书搜索与词频统计而不是逐章读取，用户询问如何使用本应用时先查阅内置使用文档再回答

#### Scenario: 指南给出统一修改译名的步骤
- **WHEN** 外部 Agent 需要把一个译名在全书改成另一个
- **THEN** 指南给出分步流程：先更新术语或角色的译名，统计旧译名的出现次数，以预览方式执行批量替换并检查样例，确认后写入并在还有剩余时继续，最后复查并向用户汇报；并说明删除术语、角色或记忆前必须先征得用户同意

#### Scenario: Agent 按指南完成首次设置
- **WHEN** 外部 Agent 第一次读到这份指南
- **THEN** 指南要求它询问用户项目位置并建立项目文件夹（用户无偏好时给出默认位置）、在该文件夹内以项目级方式配置本 MCP 服务、把指南保存为该文件夹的 AGENTS.md（Claude Code 另建引用它的 CLAUDE.md，文件已存在时追加为单独一节而不覆盖），并告知用户在该文件夹中重新加载后即可使用、以后无需再粘贴

#### Scenario: 已经设置过时跳过
- **WHEN** 外部 Agent 所在文件夹里已有这份指南且能看到本应用的工具
- **THEN** 指南说明可以跳过首次设置

#### Scenario: 桌面端指南包含令牌时给出提醒
- **WHEN** 用户在桌面端查看指南
- **THEN** 指南中的配置命令包含访问令牌，并提醒不要把该项目文件夹提交到公开仓库

#### Scenario: 浏览器通道的指南针对本地中继
- **WHEN** 用户在浏览器端查看指南
- **THEN** 首次设置配置的是限定本页来源的 WebMCP 本地中继；指南指出工具来自打开着的浏览器页面、如何确认页面已连接、在工具列表里看不到本页工具时如何调用，并引导 Agent 通过工作流指南工具而不是 MCP Prompt 读取完整流程

#### Scenario: 指南提醒破坏性操作需先确认
- **WHEN** 外部 Agent 阅读指南
- **THEN** 指南明确要求在应用已导入章节的正文改动或删除书籍之前先得到用户同意

### Requirement: 权限、写回策略与连接设置
`/mcp` 工作台 SHALL 以带后果说明的选项呈现三级权限模式（说明各模式允许的操作与开放的工具数量），并提供默认译文写回方式与写操作通知开关；桌面端另提供监听端口修改与访问令牌的脱敏查看、复制和重新生成。切换到允许删除书籍的权限模式与重新生成令牌 MUST 经用户再次确认后才生效。

#### Scenario: 切换到完全控制需要确认
- **WHEN** 用户选择允许删除书籍的权限模式
- **THEN** 界面先说明该模式的后果并要求确认；用户取消时权限模式保持不变

#### Scenario: 重新生成令牌需要确认
- **WHEN** 用户点击重新生成访问令牌
- **THEN** 界面提示已接入的客户端会立即失效并要求确认；用户取消时令牌保持不变

### Requirement: 开放能力概览与实时调用活动观测
`/mcp` 工作台 SHALL 按类别汇总当前权限模式下对外开放的工具（各类别数量，可展开查看工具名称、只读/写入标识与说明）以及工作流模板，并实时展示外部调用活动（时间、工具名、参数摘要或「无参数」说明、返回结果摘要、成功或失败状态与错误信息、耗时，以及清空按钮）。

#### Scenario: 权限模式切换实时反映在开放能力中
- **WHEN** 用户将权限模式从 `translate_and_edit` 切换为 `read_only`
- **THEN** 各类别的工具数量实时收窄为只读工具集合

#### Scenario: 每条记录说明传了什么、返回了什么
- **WHEN** 外部 Agent 的一次工具调用完成
- **THEN** 该条记录显示参数摘要（没有参数时明确显示无参数）与返回结果摘要；调用失败时显示错误信息

#### Scenario: 刷新页面后调用活动仍然保留
- **WHEN** 用户刷新页面或应用被重新加载
- **THEN** 之前的调用活动仍然显示；关闭标签页或用户点击清空后才消失

#### Scenario: 实时观测外部 Agent 翻译调用过程
- **WHEN** 外部 Coding Agent 连续调用拉取翻译块与提交译文工具
- **THEN** 调用活动区域按最新优先顺序实时追加每条调用的状态与耗时，且用户可随时一键清空

### Requirement: 三语国际化与帮助文档同步
`/mcp` 工作台的所有可见界面文案、导航项名称、状态说明、错误提示与接入指引 MUST 同步提供简体中文、繁体中文与英文三语翻译，且帮助文档三语目录 SHALL 同步补充外部 Agent / MCP 接入与使用指南。

#### Scenario: 切换界面语言后工作台文案完整本地化
- **WHEN** 用户在简体中文、繁体中文与英文之间切换应用界面语言并访问 `/mcp`
- **THEN** 导航标题、配置项说明、接入指引与日志状态标签均按所选语言正确显示，无缺失键名或回退乱码
