# Spec Delta

## Purpose

为外部 AI Agent 提供协议无关的精选工具内核与翻译工作流能力，涵盖书库与章节管理、分块翻译上下文打包、多版本译文写回、世界观设定维护、三级权限门禁以及调用活动观测。

## ADDED Requirements

### Requirement: 协议无关的精选工具集与上下文解析
系统 SHALL 通过统一的外部工具内核暴露应用导航、书库管理、翻译循环与世界观维护等精选工具，且所有工具 MUST 接受显式 `book_id` 参数并在缺省时回退到当前打开的书籍上下文。

#### Scenario: 显式指定目标书籍调用工具
- **WHEN** 外部 Agent 传入非当前打开书籍的 `book_id` 调用章节列表或术语查询工具
- **THEN** 系统针对该 `book_id` 返回对应书籍的数据，而不依赖用户当前浏览的页面

#### Scenario: 省略书籍标识时回退到当前上下文
- **WHEN** 用户正在打开某本书籍详情页且外部 Agent 省略 `book_id` 调用书内工具
- **THEN** 系统自动使用当前打开书籍作为目标范围并返回结果

#### Scenario: 书库尚未加载完成时调用工具
- **WHEN** 应用刚启动、书库数据尚未加载完成时外部 Agent 调用任一书籍相关工具
- **THEN** 系统返回表示尚未就绪的结构化错误，不执行任何读写

#### Scenario: 无可用书籍上下文时返回结构化错误
- **WHEN** 用户位于首页且外部 Agent 省略 `book_id` 调用依赖书籍的工具
- **THEN** 系统拒绝执行并返回包含明确错误码与提示的结构化错误响应

### Requirement: 书库查询、建书、URL 导入与结构化加章
系统 SHALL 允许外部 Agent 查询书库列表与单书卷章进度、创建新书、批量向指定卷或新卷添加章节正文，以及通过内置站点能力从 URL 导入或更新书籍。

#### Scenario: 通过纯文本或段落数组批量导入章节
- **WHEN** 外部 Agent 调用建书与批量加章工具并传入书名、卷标题与章节原文
- **THEN** 系统将新书与章节持久化到本地书库，并立即反映在书库与阅读界面中

#### Scenario: 浏览器环境遇到站点跨域限制时的降级指引
- **WHEN** 外部 Agent 在浏览器环境中调用 URL 导入工具且目标站点受浏览器跨域限制无法直接抓取
- **THEN** 系统返回结构化错误，明确提示可由 Agent 自行获取正文后通过建书与批量加章工具写入

#### Scenario: 目标站点不受内置站点能力支持
- **WHEN** 外部 Agent 调用 URL 导入工具且该 URL 不属于内置支持的站点
- **THEN** 系统返回带明确错误码的结构化错误，并给出同样的建书与批量加章降级指引

### Requirement: 检查并导入书籍更新
系统 SHALL 允许外部 Agent 检查书籍来源站点的更新并将更新导入书籍，复用应用内书籍更新能力：检查结果区分站点新增章节与正文已改动的已导入章节；导入默认只处理新增章节，应用已导入章节的正文改动 MUST 由 Agent 显式请求。

#### Scenario: 检查到新章节
- **WHEN** 外部 Agent 对一本有可用更新来源的书调用检查更新工具
- **THEN** 系统返回站点新增章节的标题与网址，以及站点日期较新但尚未比对正文的已导入章节数量，且不改动章节内容

#### Scenario: 深度检查比对已导入章节
- **WHEN** 外部 Agent 请求深度检查
- **THEN** 系统比对已导入章节的正文，返回发生改动的章节及其修订、插入、删除段落数与将被清除的译文版本数

#### Scenario: 默认只导入新章节
- **WHEN** 外部 Agent 调用导入更新工具且未请求应用正文改动
- **THEN** 系统只导入站点新增章节，并在结果中说明还有多少已导入章节按日期看已变化但未处理

#### Scenario: 显式请求后应用正文改动
- **WHEN** 外部 Agent 调用导入更新工具并显式请求应用已导入章节的正文改动
- **THEN** 系统比对并应用这些改动

#### Scenario: 限定导入范围
- **WHEN** 外部 Agent 指定要导入的章节网址，且其中包含不在本次检查结果中的网址
- **THEN** 系统拒绝执行并返回列出未知网址的结构化错误

#### Scenario: 更新来源缺失或失效
- **WHEN** 目标书籍没有可用的更新来源，或已保存的更新来源无法回放
- **THEN** 系统返回结构化错误，说明需要用户在应用内设置或修复更新来源

#### Scenario: 没有可导入的更新
- **WHEN** 外部 Agent 调用导入更新工具而站点没有新增章节
- **THEN** 系统返回已是最新的结果，不执行任何写入

### Requirement: 翻译上下文分块打包
系统 SHALL 提供按块拉取待翻译段落的工具，在单次响应中打包返回目标段落块、前文已译衔接段落、当前块命中的术语与角色设定、相关性最高的历史记忆、书级与章级特殊指令、目标语言及续翻游标。

#### Scenario: 仅拉取未翻译段落并附带完整翻译上下文
- **WHEN** 外部 Agent 请求某章节的未翻译翻译块
- **THEN** 系统按书籍分块策略切分未翻译段落，返回带段落 ID 的待翻块、前序已译衔接、命中术语、相关角色、按相关性筛选的记忆、特殊指令、目标语言以及剩余段数和下一块游标

#### Scenario: 章节全部段落均已翻译
- **WHEN** 外部 Agent 以仅未翻译模式请求已完成翻译的章节
- **THEN** 系统返回空的待翻列表、已全部完成的状态标记以及空游标

#### Scenario: 提交译文后继续拉取不跳过未翻译段落
- **WHEN** 外部 Agent 以仅未翻译模式拉取一块、提交其中部分段落的译文后再次拉取
- **THEN** 系统返回的下一块从章节中仍未翻译的最靠前段落开始，上一块中未成功写入的段落会再次出现，不会因游标而被跳过

#### Scenario: 拉取翻译上下文不影响站内任务
- **WHEN** 外部 Agent 拉取翻译块的同时站内正在翻译同一本书
- **THEN** 拉取操作不修改任何书籍数据，也不改变站内任务记录的记忆打分明细

### Requirement: 批量译文写回与多版本策略
系统 SHALL 提供批量译文提交工具，校验段落 ID 与译文完整性后持久化到本地书库并实时刷新界面；对已有译文的段落默认追加新译文版本并设为选中，同时支持显式覆盖当前版本与附带章节标题译文更新。

#### Scenario: 默认追加新译文版本并保留历史
- **WHEN** 外部 Agent 对已存在译文的段落提交新译文且未指定覆盖模式
- **THEN** 系统追加新的译文版本、将其设为该目标语言的当前选中译文、在每种语言的版本数量上限内保留既有历史版本，并返回已保存段数与本章剩余未翻段数

#### Scenario: 提交与已有版本相同的译文
- **WHEN** 外部 Agent 提交的译文与该段落同语言的某个已有版本文本完全相同
- **THEN** 系统选中该已有版本而不新增重复版本

#### Scenario: 显式覆盖当前译文版本
- **WHEN** 外部 Agent 以覆盖模式提交段落译文
- **THEN** 系统原地更新当前选中的目标语言译文并递增其修订版本，不额外增加多余历史条目，该版本的来源标识保持不变

#### Scenario: 覆盖模式下段落尚无译文
- **WHEN** 外部 Agent 以覆盖模式提交目标语言尚无选中译文的段落
- **THEN** 系统按追加方式新增译文版本并设为选中

#### Scenario: 启用原文前缀校验时拒绝错位提交
- **WHEN** 目标书籍启用了原文前缀校验且提交项缺失或前缀与原文不匹配
- **THEN** 系统拒绝对应段落写入并在响应中返回逐项失败原因与错误码

### Requirement: 外部译文来源标识与友好展示
系统 SHALL 允许外部 Agent 在提交译文时附带模型或客户端来源标签，并以可区分的外部来源标识写入译文记录；界面在展示译文历史与段落来源时 MUST 友好呈现该外部来源名称，而不是显示未知模型。

#### Scenario: 展示外部 Agent 写入的译文来源
- **WHEN** 外部 Agent 携带来源标签提交译文，用户随后打开译文历史或查看段落模型标签
- **THEN** 界面展示包含外部通道与来源标签的可读名称，且该译文记录保持与跨设备同步兼容

### Requirement: 世界观设定批量维护与混合检索
系统 SHALL 允许外部 Agent 列表查询与批量新增或更新术语和角色设定、执行关键词与语义混合的记忆检索、新增或更新记忆，以及读取或更新书籍与章节的特殊指令。

#### Scenario: 批量更新新出现的术语与角色
- **WHEN** 外部 Agent 在一次调用中提交多条新增或更新的术语与角色记录
- **THEN** 系统按名称或 ID 完成幂等创建或更新，并在响应中返回每条记录的处理结果与最终 ID

### Requirement: 三级权限门禁控制
系统 SHALL 在工具内核入口执行三级权限门禁：`read_only` 仅开放只读工具，`translate_and_edit` 开放只读、建书/加章/导入、检查并导入书籍更新、译文写回、导航及世界观维护工具但禁止删除书籍，`full` 开放包含删除书籍在内的全部工具。

#### Scenario: 权限不足时拒绝调用与隐藏不可用工具
- **WHEN** 当前权限模式为 `read_only` 且外部 Agent 请求列出工具或直接调用写回译文工具
- **THEN** 可用工具列表仅包含只读工具，且直接调用写入工具会被门禁拒绝并返回权限不足错误码

#### Scenario: 默认权限阻止删除书籍
- **WHEN** 当前权限模式为 `translate_and_edit` 且外部 Agent 尝试调用删除书籍工具
- **THEN** 系统拒绝执行并返回需要提升至完全控制权限的错误提示

### Requirement: 内置翻译工作流模板
系统 SHALL 提供覆盖章节翻译、章节润色校对以及导入并翻译的内置工作流模板，指导外部 Agent 按分块拉取、逐段对应、批量写回和设定同步的规范执行任务。

#### Scenario: 获取章节翻译工作流模板
- **WHEN** 外部 Agent 请求章节翻译工作流模板并传入书籍与章节参数
- **THEN** 系统返回包含目标书籍与章节上下文、分块循环步骤及术语记忆维护要求的结构化指导文本

### Requirement: 调用活动记录与写操作通知
系统 SHALL 记录每次外部 Agent 工具调用的时间、传输通道、工具名称、参数摘要、返回结果摘要、执行状态与耗时，记录在当前标签页会话内保留（刷新后仍在，关闭标签页后清空）且不参与跨设备同步；当启用写操作提示时，写类工具成功执行后 MUST 向用户展示轻量通知。

#### Scenario: 外部写入完成后记录活动并提示用户
- **WHEN** 外部 Agent 通过任一通道成功执行批量译文提交且写操作提示开关处于开启状态
- **THEN** 系统在活动日志中追加本次调用记录并向用户弹出包含操作摘要的轻量通知
