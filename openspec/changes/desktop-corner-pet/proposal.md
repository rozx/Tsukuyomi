## Why

翻译、润色、校对和月詠助手的过程（思考、工具调用、输出）只在任务中心与助手面板里看得到。用户收起这些面板专心阅读时，就不知道 AI 正在做什么、做到哪了，只能反复打开任务中心查看。参考 Codex Pets 的做法，在页面右下角放一只常驻的「桌宠」，在面板收起时用对话气泡实时转述进度。

## What Changes

- 桌面端（Electron 始终为桌面端）页面右下角新增「月詠桌宠」：直接使用现有的月詠圆形头像（`AssistantAvatar` 同一张图），不新增角色素材；用头像外圈颜色、转动的弧线、角标和缓慢呼吸表现「运行中 / 待查看 / 空闲打盹」等状态。平板与手机不显示。
- 桌宠上方的对话气泡转述它所跟随任务的最新进度：标题行（任务名与进度）+ 最新的「思考 / 工具 / 输出」片段。思考与输出显示流式文字的末尾；工具调用显示月詠口吻的一句话，下方小字是原始工具名与结果摘要。数据全部来自现有的 AI 任务记录，不额外调用 AI。
- 气泡可收起（单行）与展开（最近活动的小日志 + 切换任务 + 打开任务中心），收起 / 展开状态记住。
- 同时有多个任务时按固定优先级跟随一个：助手（助手面板收起时）> 正在阅读的章节 > 其他章节；当前任务结束才换，展开后可用 ‹ › 手动切换。
- 让位：任务中心打开（或固定面板展开）时不转述章节任务；助手面板打开或在导入页（右侧已有月詠）时桌宠隐藏。点击桌宠头像打开助手面板。
- 任务结束后气泡显示结果小结（完成 / 失败数，或「月詠答好了」+ 回复开头），用户打开对应面板或关掉小结后回到打盹；空闲时桌宠缩小变暗、点头打盹并飘出「zzz」常驻右下角。
- 设置 → 通用设置新增「显示月詠桌宠」开关，默认开启。

## Capabilities

### New Capabilities

- `desktop-corner-pet`: 桌面端右下角月詠桌宠——显示范围与位置、状态表现、气泡内容与收起 / 展开、多任务跟随规则、面板让位、结果小结、空闲打盹与设置开关。

### Modified Capabilities

（无）

## Impact

- **界面**：新增桌宠组件（桌面布局 `MainLayoutDesktop` 挂载，平板 / 手机布局不挂载）；助手面板打开时与其宽度联动定位；设置页通用分区新增开关。
- **状态**：新增从 `ai-processing` 任务（`thinkingMessage` / `outputContent` 及其中的工具调用标记）与任务队列推导桌宠状态的 composable，复用 `useThinkingFormatter` 的解析；任务中心暴露「是否可见」与已有的确认（acknowledge）给桌宠使用；`ui` store 记住气泡收起 / 展开；`AppSettings` 新增开关字段（导入导出与同步需透传）。
- **文案**：三语 i18n 新增工具调用的月詠口吻台词与气泡、小结、设置文案；英文保持中性表达。
- **文档**：帮助文档（系统栏与导航 / 助手相关章节）三语补充桌宠说明。
- **不涉及**：AI 导入任务、操作系统级悬浮窗、新的角色美术素材。
