# agent-mcp-tool-kernel Specification

## Purpose
为外部 AI Agent 提供协议无关的精选工具内核与翻译工作流能力，涵盖书库与章节管理、分块翻译上下文打包、多版本译文写回、世界观设定维护、三级权限门禁以及调用活动观测。

## Requirements

### Requirement: 协议无关的精选工具集与上下文解析
系统 SHALL 通过统一的外部工具内核暴露应用导航、书库管理、翻译循环与世界观维护等精选工具，且所有工具 MUST 接受显式 `book_id` 参数并在缺省时回退到当前打开的书籍上下文。

#### Scenario: 显式指定目标书籍调用工具
- **WHEN** 外部 Agent 传入非当前打开书籍的 `book_id` 调用章节列表或术语查询工具
- **THEN** 系统针对该 `book_id` 返回对应书籍的数据，而不依赖用户当前浏览的页面

#### Scenario: 省略书籍标识时回退到当前上下文
- **WHEN** 用户正在打开某本书籍详情页且外部 Agent 省略 `book_id` 调用书内工具
- **THEN** 系统自动使用当前打开书籍作为目标范围并返回结果

#### Scenario: 书库尚未加载完成时调用工具
- **WHEN** 应用刚启动、书库数据尚未加载完成时外部 Agent 调用任一书籍相关工具
- **THEN** 系统返回表示尚未就绪的结构化错误，不执行任何读写

#### Scenario: 无可用书籍上下文时返回结构化错误
- **WHEN** 用户位于首页且外部 Agent 省略 `book_id` 调用依赖书籍的工具
- **THEN** 系统拒绝执行并返回包含明确错误码与提示的结构化错误响应

### Requirement: 用户当前所在位置与选中内容
系统 SHALL 让外部 Agent 读取用户当前所在的页面、打开的书籍与章节（含翻译进度）、选中的段落及其原文与译文，以及用户在页面上划选的文字，使用户可以用「这一段」「这一章」「这里」指代内容。

#### Scenario: 用户选中了某个段落
- **WHEN** 用户打开某本书的某一章并选中一个段落，随后外部 Agent 读取应用上下文
- **THEN** 响应包含所在页面、该书与该章节的标识和标题、章节的段落数与已翻译数，以及选中段落的序号、原文与当前译文

#### Scenario: 用户在页面上划选了文字
- **WHEN** 用户在页面上划选了一段文字，随后外部 Agent 读取应用上下文
- **THEN** 响应包含这段划选的文字；没有划选时该项为空

#### Scenario: 用户不在阅读页面
- **WHEN** 用户位于书库、书籍设置的某个分栏、帮助文档或其他页面
- **THEN** 响应说明页面类型，书籍设置页带上书籍标识与分栏，帮助页带上文档标识；没有打开章节时章节与选中段落为空

### Requirement: 内置使用文档查询
系统 SHALL 允许外部 Agent 按界面语言搜索并读取内置使用文档，以便回答用户关于如何使用本应用的问题；该能力在只读权限下可用，且不要求书库已加载完成。

#### Scenario: 按关键词查找使用文档
- **WHEN** 外部 Agent 以关键词搜索使用文档
- **THEN** 系统返回标题、简介或正文包含该关键词的文档，正文命中时附带命中位置附近的片段，结果不包含更新日志

#### Scenario: 列出全部使用文档
- **WHEN** 外部 Agent 不带关键词搜索使用文档
- **THEN** 系统返回全部使用文档的标识、标题、分类与简介

#### Scenario: 读取一篇文档
- **WHEN** 外部 Agent 按标识读取一篇使用文档
- **THEN** 系统返回该文档的全文；标识不存在时返回文档不存在的结构化错误

### Requirement: 书库查询、建书、URL 导入与结构化加章
系统 SHALL 允许外部 Agent 查询书库列表与单书卷章进度、创建新书、批量向指定卷或新卷添加章节正文、调整章节顺序或把章节移到另一卷，以及通过内置站点能力从 URL 导入或更新书籍。写入章节正文时的分段规则 MUST 与站内导入一致：每一行是一个段落，空行、行首缩进与行尾空白原样保留。移动章节的逻辑 MUST 与站内同名工具共用。

#### Scenario: 通过纯文本或段落数组批量导入章节
- **WHEN** 外部 Agent 调用建书与批量加章工具并传入书名、卷标题与章节原文
- **THEN** 系统将新书与章节持久化到本地书库，并立即反映在书库与阅读界面中

#### Scenario: 浏览器环境遇到站点跨域限制时的降级指引
- **WHEN** 外部 Agent 在浏览器环境中调用 URL 导入工具且目标站点受浏览器跨域限制无法直接抓取
- **THEN** 系统返回结构化错误，明确提示可由 Agent 自行获取正文后通过建书与批量加章工具写入

#### Scenario: 目标站点不受内置站点能力支持
- **WHEN** 外部 Agent 调用 URL 导入工具且该 URL 不属于内置支持的站点
- **THEN** 系统返回带明确错误码的结构化错误，并给出同样的建书与批量加章降级指引

#### Scenario: 来源网址只接受网页地址
- **WHEN** 外部 Agent 建书或加章时给出的来源网址不是 http 或 https 地址
- **THEN** 系统拒绝该请求并返回参数错误，不写入任何内容

#### Scenario: 从网址导入只请求该站点的章节地址
- **WHEN** 书中有正文为空的章节，其来源网址不属于正在导入的站点
- **THEN** 系统不请求该地址，在响应中如实列出被忽略的章节，并且不把它们计入待抓取的章节数

#### Scenario: 分段与站内导入一致
- **WHEN** 外部 Agent 以整段文本或段落数组写入章节正文（建书时的初始章节、加章、从 URL 导入）
- **THEN** 文本的每一行成为一个段落，空行成为空段落，行首缩进与行尾空白不被修剪，Windows 换行按一行处理

#### Scenario: 调整章节顺序
- **WHEN** 外部 Agent 指定一个或多个章节，并用某一章之前、某一章之后、卷首或卷尾说明目标位置
- **THEN** 这些章节按给出的顺序作为整体移到目标位置，响应给出每一章移动前后的卷与在目标卷中的序号；章节的标题、正文与译文不变

#### Scenario: 移到另一卷或新建的卷
- **WHEN** 外部 Agent 指定目标卷、以目标卷中的章节定位，或给出新卷的标题
- **THEN** 章节移入该卷；给出新卷标题时先新建该卷再移入

#### Scenario: 移动请求有问题
- **WHEN** 章节或目标卷不存在、章节重复、定位方式互相冲突、以正在移动的章节自身定位，或来自不同卷的章节没有说明目标
- **THEN** 系统返回对应的结构化错误，不改动任何内容

#### Scenario: 位置没有变化
- **WHEN** 移动后的顺序与原来完全一样
- **THEN** 系统不写入并在响应中说明没有变化

#### Scenario: 长篇只取需要的目录
- **WHEN** 外部 Agent 查询书籍时指定只取最近若干章、只看某一卷，或只要卷的概览
- **THEN** 响应只列出指定范围内的章节，其余卷给出标题与章节数；指定的卷不存在时返回卷不存在的结构化错误；外部 Agent 还可以要求省略书籍简介

#### Scenario: 统计进度时分批读取正文
- **WHEN** 外部 Agent 读取目录并需要各章的段落数与已译数
- **THEN** 系统分批读取所列章节的正文，而不是逐章单独读取

#### Scenario: 导入后直接得到章节标识
- **WHEN** 通过 URL 导入或增量更新书籍后本次抓取到了章节正文
- **THEN** 响应列出这些章节的标识、所在卷与标题，外部 Agent 无需再读取整本目录

#### Scenario: 修改书籍信息
- **WHEN** 外部 Agent 提交某本书的作者、简介、标签或别名中的一项或多项
- **THEN** 系统只修改提交的字段（空值表示清空该字段），书名与章节不变；一项都没有提交时返回参数错误

### Requirement: 检查并导入书籍更新
系统 SHALL 允许外部 Agent 检查书籍来源站点的更新并将更新导入书籍，复用应用内书籍更新能力：检查结果区分站点新增章节与正文已改动的已导入章节；导入默认只处理新增章节，应用已导入章节的正文改动 MUST 由 Agent 显式请求。

#### Scenario: 检查到新章节
- **WHEN** 外部 Agent 对一本有可用更新来源的书调用检查更新工具
- **THEN** 系统返回站点新增章节的标题与网址，以及站点日期较新但尚未比对正文的已导入章节数量，且不改动章节内容

#### Scenario: 深度检查比对已导入章节
- **WHEN** 外部 Agent 请求深度检查
- **THEN** 系统比对已导入章节的正文，返回发生改动的章节及其修订、插入、删除段落数与将被清除的译文版本数

#### Scenario: 默认只导入新章节
- **WHEN** 外部 Agent 调用导入更新工具且未请求应用正文改动
- **THEN** 系统只导入站点新增章节，并在结果中说明还有多少已导入章节按日期看已变化但未处理

#### Scenario: 显式请求后应用正文改动
- **WHEN** 外部 Agent 调用导入更新工具并显式请求应用已导入章节的正文改动
- **THEN** 系统比对并应用这些改动

#### Scenario: 导入后返回新章节的标识
- **WHEN** 外部 Agent 导入书籍更新成功
- **THEN** 响应除了已导入的网址外，还列出对应章节的标识、所在卷与标题

#### Scenario: 限定导入范围
- **WHEN** 外部 Agent 指定要导入的章节网址，且其中包含不在本次检查结果中的网址
- **THEN** 系统拒绝执行并返回列出未知网址的结构化错误

#### Scenario: 更新来源缺失或失效
- **WHEN** 目标书籍没有可用的更新来源，或已保存的更新来源无法回放
- **THEN** 系统返回结构化错误，说明需要用户在应用内设置或修复更新来源

#### Scenario: 没有可导入的更新
- **WHEN** 外部 Agent 调用导入更新工具而站点没有新增章节
- **THEN** 系统返回已是最新的结果，不执行任何写入

#### Scenario: 有章节没能完成检查
- **WHEN** 比对已导入章节的正文时有章节抓取失败或额度用尽
- **THEN** 响应不报告「已是最新」，而是标明部分完成，带回没能检查的章节与原因，并把它们计入尚未跟上的章节数；同时有可导入内容时，检查阶段与导入阶段的失败合并返回

### Requirement: 翻译上下文分块打包
系统 SHALL 提供按块拉取待翻译段落的工具，在单次响应中打包返回目标段落块、前文已译衔接段落（本章尚无已译前文时改为上一章末尾的已译段落）、最近几章的标题译名、当前块命中的术语与角色设定、写法接近的「可能相关」术语与角色、相关性最高的历史记忆、书级与章级特殊指令、目标语言及续翻游标。术语、角色与记忆的匹配 MUST 与站内翻译任务采用同一套规则。

#### Scenario: 仅拉取未翻译段落并附带完整翻译上下文
- **WHEN** 外部 Agent 请求某章节的未翻译翻译块
- **THEN** 系统按书籍分块策略切分未翻译段落，返回带段落 ID 的待翻块、前序已译衔接、命中术语、相关角色、按相关性筛选的记忆、特殊指令、目标语言以及剩余段数和下一块游标

#### Scenario: 新章节的第一块带上一章的衔接
- **WHEN** 外部 Agent 请求一个尚无任何译文的章节的翻译块，且该章节之前还有章节
- **THEN** 响应包含上一章末尾若干已译段落的原文与译文（标明所属章节），以及之前最近几章已有译名的标题原文与译名

#### Scenario: 衔接段落跳过分隔线
- **WHEN** 作为衔接的段落中有只含符号的段落（例如章末的分隔线）
- **THEN** 这些段落不计入衔接，名额留给有内容的段落

#### Scenario: 本章已有已译前文时不带上一章
- **WHEN** 外部 Agent 请求的翻译块之前，本章已有已译段落
- **THEN** 响应使用本章的已译前文作为衔接，不再附带上一章的段落

#### Scenario: 书中术语很多时仍能带出相关记忆
- **WHEN** 书中有大量与当前块无关的术语和角色，且存在提到当前块所含术语或角色的记忆
- **THEN** 该记忆出现在响应的记忆列表中，相关性只按当前块命中的术语和角色计算

#### Scenario: 角色以姓或名单独出现
- **WHEN** 当前块中某角色只以姓或名出现（可带敬称），而角色设定里记录的是全名
- **THEN** 该角色出现在命中的角色列表中

#### Scenario: 原文写法与术语或角色名接近
- **WHEN** 当前块中有一处写法与某术语名或角色名非常接近但不完全相同
- **THEN** 该条目出现在「可能相关」列表中并带有原文里的写法，不出现在确切命中的列表中

#### Scenario: 章节全部段落均已翻译
- **WHEN** 外部 Agent 以仅未翻译模式请求已完成翻译的章节
- **THEN** 系统返回空的待翻列表、已全部完成的状态标记以及空游标

#### Scenario: 提交译文后继续拉取不跳过未翻译段落
- **WHEN** 外部 Agent 以仅未翻译模式拉取一块、提交其中部分段落的译文后再次拉取
- **THEN** 系统返回的下一块从章节中仍未翻译的最靠前段落开始，上一块中未成功写入的段落会再次出现，不会因游标而被跳过

#### Scenario: 拉取翻译上下文不影响站内任务
- **WHEN** 外部 Agent 拉取翻译块的同时站内正在翻译同一本书
- **THEN** 拉取操作不修改任何书籍数据，也不改变站内任务记录的记忆打分明细

### Requirement: 批量译文写回与多版本策略
系统 SHALL 提供批量译文提交工具，校验段落 ID 与译文完整性后持久化到本地书库并实时刷新界面；对已有译文的段落默认追加新译文版本并设为选中，同时支持显式覆盖当前版本与附带章节标题译文更新。

#### Scenario: 默认追加新译文版本并保留历史
- **WHEN** 外部 Agent 对已存在译文的段落提交新译文且未指定覆盖模式
- **THEN** 系统追加新的译文版本、将其设为该目标语言的当前选中译文、在每种语言的版本数量上限内保留既有历史版本，并返回已保存段数与本章剩余未翻段数

#### Scenario: 提交与已有版本相同的译文
- **WHEN** 外部 Agent 提交的译文与该段落同语言的某个已有版本文本完全相同
- **THEN** 系统选中该已有版本而不新增重复版本

#### Scenario: 显式覆盖当前译文版本
- **WHEN** 外部 Agent 以覆盖模式提交段落译文
- **THEN** 系统原地更新当前选中的目标语言译文并递增其修订版本，不额外增加多余历史条目，该版本的来源标识保持不变

#### Scenario: 覆盖模式下段落尚无译文
- **WHEN** 外部 Agent 以覆盖模式提交目标语言尚无选中译文的段落
- **THEN** 系统按追加方式新增译文版本并设为选中

#### Scenario: 启用原文前缀校验时拒绝错位提交
- **WHEN** 目标书籍启用了原文前缀校验且提交项缺失或前缀与原文不匹配
- **THEN** 系统拒绝对应段落写入并在响应中返回逐项失败原因与错误码

### Requirement: 读取章节段落
系统 SHALL 允许外部 Agent 按序号范围或关键词读取某一章的段落、当前译文与可选的历史版本，并支持跳过空段落与从章节末尾读取。

#### Scenario: 跳过空段落
- **WHEN** 外部 Agent 要求跳过空段落并指定条数上限
- **THEN** 响应只包含有内容的段落，条数上限只计这些段落，并给出继续读取的起点

#### Scenario: 从章节末尾读取
- **WHEN** 外部 Agent 要求从末尾读取若干段
- **THEN** 响应返回章节最后若干段，仍按阅读顺序排列，并说明之前是否还有内容

### Requirement: 全书搜索与词频统计
系统 SHALL 允许外部 Agent 在整本书或单个章节范围内，按关键词或正则表达式搜索原文与当前选用的译文，统计关键词的出现次数与章节分布，并在本地嵌入可用时按内容描述查找章节，而无需逐章读取正文。

#### Scenario: 全书搜索关键词
- **WHEN** 外部 Agent 不指定章节搜索一个关键词
- **THEN** 系统按卷章顺序返回原文或译文包含该词的段落，每条带有所在章节的标识与标题、段落序号、原文与当前译文

#### Scenario: 限定搜索范围
- **WHEN** 外部 Agent 指定只搜原文或只搜译文，或指定某个章节
- **THEN** 结果只来自指定的文本与章节；章节不存在时返回章节不存在的结构化错误

#### Scenario: 结果超过单次上限
- **WHEN** 匹配的段落多于单次返回上限
- **THEN** 响应说明还有更多结果并给出下一次调用应使用的偏移量

#### Scenario: 正则表达式无效
- **WHEN** 外部 Agent 以正则方式搜索但表达式无法解析
- **THEN** 系统返回正则无效的结构化错误，而不是空结果

#### Scenario: 可能让页面卡死的正则表达式
- **WHEN** 外部 Agent 提交的正则表达式过长，或包含「被重复的分组里又有不定次数的重复」这类写法
- **THEN** 系统在执行前拒绝并返回与正则无效相同的结构化错误，说明原因

#### Scenario: 可选的模糊匹配
- **WHEN** 外部 Agent 在全书搜索、词频统计、章节段落读取、术语或角色列表、使用文档搜索中开启模糊匹配
- **THEN** 写法与查询略有出入的内容也算命中（查询越长容许的差异越多，不足四个字时仍要求完全一致）；不开启时保持精确匹配

#### Scenario: 模糊匹配与正则互斥
- **WHEN** 外部 Agent 在全书搜索中同时开启模糊匹配与正则
- **THEN** 系统返回参数错误

#### Scenario: 批量替换不做模糊匹配
- **WHEN** 外部 Agent 执行批量替换译文
- **THEN** 只有与查找文字完全一致的地方会被替换

#### Scenario: 统计关键词出现次数
- **WHEN** 外部 Agent 提交一组关键词请求统计
- **THEN** 系统对每个关键词返回出现次数、涉及的段落数、章节数与按次数排列的章节分布；可选择统计原文或当前选用的译文

#### Scenario: 按内容描述查找章节而本地嵌入不可用
- **WHEN** 外部 Agent 请求按内容描述查找章节，但本地嵌入没有开启或模型尚未就绪
- **THEN** 系统返回说明原因的结构化错误，并提示改用关键词搜索

### Requirement: 批量替换译文
系统 SHALL 允许具备写入权限的外部 Agent 在整本书或单个章节范围内，把当前选用的译文中的指定文字替换为新文字，支持先预览再写入，并遵循与译文写回相同的多版本策略。

#### Scenario: 预览替换
- **WHEN** 外部 Agent 以预览方式请求替换
- **THEN** 系统返回将被修改的段落数、替换处数、章节分布与替换前后的样例，不写入任何内容

#### Scenario: 默认追加新版本
- **WHEN** 用户的写回方式为追加，外部 Agent 执行替换
- **THEN** 每个被修改的段落新增一个译文版本并选用，原版本保留

#### Scenario: 覆盖当前版本
- **WHEN** 外部 Agent 显式要求覆盖，或用户的写回方式为覆盖
- **THEN** 系统就地修改每个段落当前选用的译文版本，不新增版本

#### Scenario: 只替换原文包含指定词的段落
- **WHEN** 外部 Agent 同时给出原文必须包含的词
- **THEN** 只有原文包含该词的段落会被替换，其余段落即使译文包含查找文字也保持不变

#### Scenario: 超过单次段落上限
- **WHEN** 需要修改的段落多于单次上限
- **THEN** 系统只处理上限以内的段落并说明还有剩余，外部 Agent 可再次调用继续

#### Scenario: 用续传位置继续替换
- **WHEN** 一次替换因段落上限没有处理完，外部 Agent 把响应里的续传位置原样传入下一次调用
- **THEN** 系统从上次停下的段落继续，已经处理过的段落不会再被替换；即使替换内容里包含查找内容，每一处也只替换一次

#### Scenario: 续传位置无效
- **WHEN** 续传位置的格式不对、指向的章节不在本次范围内，或指向的段落已不在该章节
- **THEN** 系统返回结构化错误，不做任何替换

#### Scenario: 替换后译文为空
- **WHEN** 替换会使某个段落的译文变成空白
- **THEN** 系统跳过该段落并在响应中报告跳过的数量

### Requirement: 外部译文来源标识与友好展示
系统 SHALL 允许外部 Agent 在提交译文时附带模型或客户端来源标签，并以可区分的外部来源标识写入译文记录；界面在展示译文历史与段落来源时 MUST 友好呈现该外部来源名称，而不是显示未知模型。

#### Scenario: 展示外部 Agent 写入的译文来源
- **WHEN** 外部 Agent 携带来源标签提交译文，用户随后打开译文历史或查看段落模型标签
- **THEN** 界面展示包含外部通道与来源标签的可读名称，且该译文记录保持与跨设备同步兼容

### Requirement: 世界观设定批量维护与混合检索
系统 SHALL 允许外部 Agent 列表查询、批量新增或更新、按标识批量删除术语和角色设定，执行关键词与语义混合的记忆检索、分页列出全部记忆、新增、更新或按标识批量删除记忆，以及读取或更新书籍与章节的特殊指令。新增或更新术语、角色、记忆的工具说明 MUST 取自站内对应工具与规则的同一份文字。凡是外部工具与站内工具功能对应、且站内说明里写有使用原则的（何时该用、先查什么后查什么、内容该怎么写），外部工具的说明 MUST 由功能概述加站内说明原文组成，其中提到的工具名与参数写法换成外部的说法。

#### Scenario: 工具说明写明何时该建条目
- **WHEN** 外部 Agent 读取新增或更新术语、角色、记忆的工具说明
- **THEN** 说明包含与站内相同的要求：只为作品特有的术语建条目且每个术语只留一个译名，人名放角色表而不放术语表，角色以全名为主名称且不自动生成带敬语的别名，记忆只记可复用的翻译决定而不记剧情与世界观

#### Scenario: 使用原则在站内与外部一致
- **WHEN** 外部 Agent 读取搜索记忆、读写特殊指令、检索章节、统计词频、修改书籍信息、搜索使用文档、删除术语或记忆等工具的说明
- **THEN** 其中关于使用原则的文字与站内对应工具的说明相同（例如先查术语与角色、没有记录时再查记忆；章节级指令覆盖书籍级同类指令），只有工具名与参数写法是外部的

#### Scenario: 站内说明修改后外部说明同步变化
- **WHEN** 站内某个工具的说明被修改，且该工具在对应表中有外部工具
- **THEN** 外部工具的说明随之变化，不需要另行维护

#### Scenario: 批量更新新出现的术语与角色
- **WHEN** 外部 Agent 在一次调用中提交多条新增或更新的术语与角色记录
- **THEN** 系统按名称或 ID 完成幂等创建或更新，并在响应中返回每条记录的处理结果与最终 ID

#### Scenario: 给出标识时只按标识确定目标
- **WHEN** 外部 Agent 更新术语或角色时给出了条目标识，而名称与另一个已有条目相同
- **THEN** 系统只把给出标识的条目作为目标并报告名称冲突，另一个条目不被修改；标识不存在时该项报告失败，不退回按名称匹配

#### Scenario: 设定很多时分页与精简输出
- **WHEN** 外部 Agent 列出术语或角色时指定条数、偏移量或精简输出
- **THEN** 响应按指定范围返回并给出总数与是否还有更多；精简输出只包含标识、名称与译名（角色另带别名）；不指定条数时返回全部

#### Scenario: 主动搜索记忆
- **WHEN** 外部 Agent 以包含多个关键词的查询搜索记忆
- **THEN** 系统返回所有有命中的记忆，按相关度从高到低排列并带上分数，至多返回指定条数；完全没有命中的记忆不返回

#### Scenario: 批量删除术语、角色或记忆
- **WHEN** 外部 Agent 提交一组术语、角色或记忆的标识请求删除
- **THEN** 系统删除存在的条目并逐项返回处理结果，不存在的标识报告为未找到且不影响其余条目；已有译文不受影响

#### Scenario: 分页列出全部记忆
- **WHEN** 外部 Agent 请求列出某本书的记忆
- **THEN** 系统按创建时间从新到旧分页返回摘要与总数，说明是否还有更多；仅在请求时附带正文

### Requirement: 三级权限门禁控制
系统 SHALL 在工具内核入口执行三级权限门禁：`read_only` 仅开放只读工具，`translate_and_edit` 开放只读、建书/加章/导入、修改书籍信息、检查并导入书籍更新、译文写回与批量替换、导航及世界观维护（含删除术语、角色与记忆）工具但禁止删除书籍，`full` 开放包含删除书籍在内的全部工具。

#### Scenario: 权限不足时拒绝调用与隐藏不可用工具
- **WHEN** 当前权限模式为 `read_only` 且外部 Agent 请求列出工具或直接调用写回译文工具
- **THEN** 可用工具列表仅包含只读工具，且直接调用写入工具会被门禁拒绝并返回权限不足错误码

#### Scenario: 默认权限允许删除设定条目
- **WHEN** 当前权限模式为 `translate_and_edit` 且外部 Agent 调用删除术语、角色或记忆的工具
- **THEN** 系统执行删除；同样的调用在 `read_only` 下被拒绝并返回权限不足错误码

#### Scenario: 默认权限阻止删除书籍
- **WHEN** 当前权限模式为 `translate_and_edit` 且外部 Agent 尝试调用删除书籍工具
- **THEN** 系统拒绝执行并返回需要提升至完全控制权限的错误提示

### Requirement: 内置翻译工作流模板
系统 SHALL 提供覆盖章节翻译、章节润色校对以及导入并翻译的内置工作流模板，指导外部 Agent 按分块拉取、逐段对应、批量写回和设定同步的规范执行任务。翻译与润色校对模板 MUST 附带翻译规则，且规则正文 MUST 与站内翻译、润色、校对任务使用同一份文字（标点与引号、保持格式、日语敬语、数据管理、记忆管理），仅工具名称与阶段限制换成外部的说法。

#### Scenario: 获取章节翻译工作流模板
- **WHEN** 外部 Agent 请求章节翻译工作流模板并传入书籍与章节参数
- **THEN** 系统返回包含目标书籍与章节上下文、分块循环步骤及术语记忆维护要求的结构化指导文本

#### Scenario: 模板附带与站内相同的翻译规则
- **WHEN** 外部 Agent 请求章节翻译或润色校对的工作流模板
- **THEN** 模板包含与站内任务相同的规则正文；其中不出现站内专有的阶段名称与工具名称，而是使用外部工具的名称

#### Scenario: 模板的步骤顺序与站内任务一致
- **WHEN** 外部 Agent 读取翻译工作流模板
- **THEN** 步骤按「准备 → 翻译并提交 → 复核」排列，准备与复核的清单取自站内翻译任务规划阶段与复核阶段的待办文字，只有提交工具换成外部的名字；润色与校对模板只有准备清单，没有复核清单

#### Scenario: 站内规则更新后模板同步变化
- **WHEN** 站内翻译任务的规则文字被修改
- **THEN** 外部工作流模板与快速上手指南中的对应规则随之变化，无需另行维护

### Requirement: 调用活动记录与写操作通知
系统 SHALL 记录每次外部 Agent 工具调用的时间、传输通道、工具名称、参数摘要、返回结果摘要、执行状态与耗时，记录在当前标签页会话内保留（刷新后仍在，关闭标签页后清空）且不参与跨设备同步；当启用写操作提示时，写类工具成功执行后 MUST 向用户展示轻量通知。

#### Scenario: 外部写入完成后记录活动并提示用户
- **WHEN** 外部 Agent 通过任一通道成功执行批量译文提交且写操作提示开关处于开启状态
- **THEN** 系统在活动日志中追加本次调用记录并向用户弹出包含操作摘要的轻量通知
