# agent-mcp-webmcp-bridge Specification

## Purpose
在浏览器运行时把共享外部 Agent 工具内核通过 WebMCP 接口暴露出去，并借助 WebMCP 本地中继让用户电脑上的本地 Agent（如 Claude Code、Cursor）使用这些工具，不依赖浏览器的实验开关。

## Requirements

### Requirement: 按需提供页面 WebMCP 运行时
浏览器端在用户开启 WebMCP 时 SHALL 按需加载页面 WebMCP 运行时，使页面上存在可注册工具的模型上下文接口；该运行时 MUST NOT 进入应用主包，且 MUST 只允许本页来源通过页面级传输连接。页面不在安全上下文（非 HTTPS 且非 localhost）时 MUST NOT 加载运行时，并明确告知用户无法开启。

#### Scenario: 开启 WebMCP 后页面具备模型上下文接口
- **WHEN** 用户在安全上下文的浏览器页面中开启 WebMCP
- **THEN** 页面按需加载运行时并具备模型上下文接口，无需用户开启任何浏览器实验开关

#### Scenario: 未开启时不加载运行时
- **WHEN** 用户从未开启 WebMCP
- **THEN** 应用不加载页面运行时，也不向页面注入任何中继相关内容

#### Scenario: 页面不在安全上下文
- **WHEN** 页面不是通过 HTTPS 或 localhost 打开
- **THEN** WebMCP 开关不可开启，界面说明原因；应用正常运行且不产生未捕获异常

#### Scenario: 浏览器自带旧版 WebMCP 实现
- **WHEN** 浏览器开启了旧版的 WebMCP 实验功能，其自带接口返回的工具信息无法被本地中继使用
- **THEN** 开启 WebMCP 时应用在本页改用内置运行时，使工具仍能经中继被本地 Agent 发现和调用，且不产生大量告警；无法改用时不加载运行时，并在界面说明需要关闭该实验功能或升级浏览器

#### Scenario: 运行时加载失败
- **WHEN** 页面 WebMCP 运行时加载或初始化失败
- **THEN** 界面提示刷新页面后重试，应用其余功能不受影响

### Requirement: 通过本地中继向本地 Agent 暴露工具
开启 WebMCP 时，浏览器端 SHALL 接入用户电脑上运行的 WebMCP 本地中继，使本地 Agent 经该中继发现并调用本页注册的工具；中继所需的浏览器端文件 MUST 随应用分发而不是从第三方 CDN 加载，并与所依赖的中继包版本保持一致。

#### Scenario: 本地 Agent 经中继调用本页工具
- **WHEN** 用户已在 Agent 客户端中添加本地中继并在页面开启 WebMCP，本地 Agent 列出并调用工具
- **THEN** Agent 能看到本页当前权限允许的工具并调用成功，调用结果写回应用且界面实时更新

#### Scenario: 页面关闭或刷新
- **WHEN** 用户关闭或刷新页面
- **THEN** 本页的工具从中继中消失；页面重新打开并处于开启状态时自动重新接入

### Requirement: 受开关与权限驱动的动态工具注册与注销
当 WebMCP 开关处于开启时，适配层 SHALL 将当前权限模式允许的工具集合注册到页面模型上下文并附带只读标记提示；当关闭开关、切换权限模式或应用卸载时，适配层 MUST 注销先前注册的工具（优先使用中止信号机制，缺省时回退到显式注销方法），关闭开关时还 MUST 断开与本地中继的连接并清理页面运行时。

#### Scenario: 开启 WebMCP 开关后注册可用工具
- **WHEN** 用户开启 WebMCP 开关
- **THEN** 适配层先接通运行时与中继，再将当前权限模式下允许的所有工具注册到页面模型上下文，并按工具性质标记只读提示

#### Scenario: 切换权限模式后同步更新已注册工具
- **WHEN** 用户将权限模式从读写模式切换为仅只读模式
- **THEN** 适配层注销原有写类工具，使页面模型上下文中仅保留只读工具

#### Scenario: 关闭开关或热重载清理全部已注册工具
- **WHEN** 用户关闭 WebMCP 开关或运行环境触发清理生命周期
- **THEN** 适配层先注销所有已注册工具，再断开中继并清理页面运行时，不再响应外部调用

### Requirement: 浏览器通道暴露翻译工作流指南
由于经中继连接的 Agent 只能使用工具而没有独立的 Prompt 列表，适配层 SHALL 在浏览器通道额外暴露只读工作流指南工具，供 Agent 获取章节翻译、润色校对与导入翻译的标准工作流说明。

#### Scenario: Agent 读取翻译工作流指南
- **WHEN** Agent 通过浏览器通道调用工作流指南工具并指定章节翻译流程
- **THEN** 适配层返回与桌面端 MCP Prompt 等价的结构化翻译规范文本

### Requirement: 统一记录浏览器通道调用与来源标识
通过浏览器通道触发的工具执行 SHALL 复用共享工具内核的权限门禁、调用活动日志与可选写操作通知，并在未显式传入来源标签时将写入译文的来源标识标记为 WebMCP 外部通道。

#### Scenario: 经浏览器通道写入译文并留下来源与活动记录
- **WHEN** Agent 经浏览器通道调用批量译文提交工具且未指定自定义模型名
- **THEN** 译文以 WebMCP 外部来源标识保存，且活动日志记录通道为 WebMCP 并展示执行状态与耗时
