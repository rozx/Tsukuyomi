# ⚙️ 设置使用指南

本文档仅说明当前版本已实现的设置能力，按设置页的选项卡组织。

> 自 v0.10.1 起，设置从弹窗改为独立路由页 `/settings`。在桌面/平板端会显示返回按钮，在移动端则整合进底部 Tab 栏。

---

## 📌 打开与关闭

- 入口：左侧导航栏 **设置** 或直接访问 `/settings`。
- 关闭/返回：点击页面左上角的返回按钮返回上一页。
- 设置页会记住你上次打开的选项卡。

---

## 🧭 选项卡总览

当前设置页包含以下选项卡：

1. AI 模型
2. 代理设置（仅浏览器版显示）
3. API Keys
4. 同步设置
5. 本地嵌入
6. 爬虫设置
7. 导入/导出

> 在 Electron 桌面版中，不显示“代理设置”选项卡。移动端强制禁用本地嵌入，相关选项会标灰。

---

## 1) 🤖 AI 模型

用于配置“任务默认模型”。

### 支持的默认任务

- 翻译
- 校对和润色
- 术语翻译 / 章节摘要
- 助手

### 选择规则（当前实现）

- 下拉框只显示：
  - 已启用的模型；
  - 且该模型在对应任务上被标记为支持默认任务。
- 每个任务都可以选择 `未设置`。
- 如果已选模型后续被禁用或不再支持该任务，设置会自动清空。

---

## 2) 🌐 代理设置（仅浏览器版）

用于配置“爬虫与网络工具”的代理行为。

### 基础开关

- **启用代理**：开启后，爬虫和网络工具会优先走代理。
- **自动切换代理服务**：请求失败时按顺序尝试其他代理。
- **自动添加映射**：自动切换成功后，将该代理写入对应网站映射。

### 默认代理与代理 URL

- 可从“选择代理服务”下拉中选择。
- 代理 URL 支持模板：`...{url}`。
- 当选择了列表中的代理服务时，URL 输入框会被锁定为对应项。

### 代理列表管理

- 添加代理（名称、URL、可选描述）
- 编辑代理
- 删除代理
- 测试代理（测试目标为 `https://www.duckduckgo.com`）
- 拖拽排序（影响优先级）

### 网站-代理映射

- 可为网站单独配置代理列表（按优先级顺序）。
- 每个网站最多配置 **3** 个代理。
- 支持启用/禁用单条映射。
- 支持在映射编辑弹窗中调整代理顺序。

### 重要说明

- 该选项卡只在非 Electron 环境显示。
- 即使关闭代理，浏览器版对部分内置站点仍会走应用内 `/api/...` 路径。
- 浏览器版 AI 模型请求使用独立的默认 CORS 代理逻辑，不受此处“代理 URL”直接控制。

## 3) 🔑 API Keys

当前该选项卡仅提供：

- **Tavily 搜索 API Key**（用于助手网络搜索能力）

交互行为：

- 点击“保存”后写入本地设置。
- 清空后保存可移除该 Key。
- 界面会显示“已配置 / 未配置”状态。

## 4) 🔄 同步设置（GitHub Gist）

用于配置并执行 Gist 同步。

### 基础配置

- 启用 Gist 同步
- GitHub 用户名
- GitHub Personal Access Token
- Gist ID（可选，留空可在上传时创建）

### 操作按钮

- **验证 Token**
- **上传到 Gist**
- **从 Gist 下载**（未填 Gist ID 时不可用）

### 自动同步

- 可启用“自动同步”。
- 同步间隔范围：**1~1440 分钟**。
- 自动同步会先用条件请求检查远端是否有变化。远端无变化时不消耗 GitHub API 配额，可以放心设置较短的同步间隔。

### 增量同步与并发冲突处理

从 v0.10.1 起，同步采用基于 **manifest（清单）** 的增量策略：

- **只上传变化的内容**：编辑一本书后触发同步，仅该书与清单文件会被上传；其他书籍、AI 模型、封面、记忆库都不会被重复推送。
- **选择性下载**：远端有更新时，只反序列化并合并发生变化的条目，未变更的数据不会被重新处理。
- **多设备并发保护**：上传前会再次检查远端是否被其他设备修改。如发现并发写入，自动重新拉取合并后重试（最多 3 次）。超过后会提示“其他设备正在频繁写入，请稍后再试”。
- **删除跨端传播**：manifest 中保留墓碑（tombstones）记录，在 A 设备上删除的条目不会被 B 设备重新推回。
- **头部待同步提示**：Header 会显示当前待同步变更的数量，点击同步按钮旁的小 Popover 可以查看每一项的具体修改。徽标覆盖书籍、AI 模型、封面、应用设置、**记忆库条目**以及跨端删除墓碑（自 v0.11.1 起补齐记忆变更）。

### 🧹 强制推送模式（Force Push）

用于"远端数据损坏"或"设备迁移"场景，把远端清空后用本地数据**完全覆盖**：

- 位置：同步设置 → 强制推送开关（默认关闭）。
- 启用后下一次上传会跳过 manifest 比对，以本地数据为准整体重写 Gist。
- 操作具有破坏性，请务必先在接收设备备份，并确保其他设备暂不触发自动同步。

> 💡 **多设备用户注意**：Manifest 架构涉及 Gist 文件结构调整。建议在所有已登录同一账户的设备上同步升级客户端后再触发同步。首次从旧布局同步时会自动执行一次性迁移（读取旧布局 → 合并本地数据 → 以新布局重写 Gist），迁移失败时本地数据保持不变，下次同步会自动重试。

### 修订历史

启用且有 Gist ID 时可查看修订历史：

- 刷新历史
- 展开单个修订查看文件变更
- 恢复到指定修订

> 自 v0.11.1 起，从修订历史恢复**完整支持** manifest 新布局：AI 模型、封面历史、记忆库都会随修订快照一并还原，不再只恢复书籍主体。若修订来自旧版本聚合布局，会自动回退到旧解析路径。

### 删除 Gist

- 可执行“删除当前 Gist”（需确认）。

### 数据恢复与同步覆盖行为（当前实现）

- **版本修订级别恢复**：从单次网络修订版恢复时，会先清空本地书籍、AI 模型、封面历史，再全量应用远端备份的数据。
- **本地误删软恢复**：在开启同步功能且存在云端备份记录时，如果本地无意间删除了数据并在同步前找回，系统通常会弹出“已删除项同步处理”对话框供选择。
- 此时恢复对话框提供了针对（书籍、模型配置、封面和记忆库 Memory）的高级恢复交互，不仅能恢复数据，还能覆盖当前的删除行为记录防止从云端错误清除。

## 5) 🧬 本地嵌入

用于配置**本地向量检索**，为记忆库的语义检索和章节 `query_chapter` 工具提供支持。

### 总开关

- **启用本地嵌入**（默认关闭）：开启后会按需下载嵌入模型并在后台生成向量索引。
- 关闭时：嵌入队列自动停止、相关 UI 隐藏，AI 不再暴露 `query_chapter` 工具，翻译提示词也会移除对应引导。
- **移动端强制禁用**：Quasar 检测到移动平台时会锁定此开关为关闭，避免浏览器 WASM 内存限制导致崩溃。

### 嵌入模型与运行设备

- 默认模型：`gte-multilingual-base`（约 300M 参数的多语言编码器，自动缓存到浏览器）。
- 优先 **WebGPU + q4f16 量化**运行，无 WebGPU 支持时自动回退到 **WASM + q8**。
- 仅在启用后且曾经缓存过模型时才会自动预热，首次开启需下载模型（约 300MB+），请耐心等待。

### 记忆注入

- 最低相关度阈值：低于此分数的记忆不会被注入翻译上下文（默认 0.38）。
- 字符预算：单次注入的最大字符数（默认 2000）。
- 可在对应面板查看分数分布和实时测试检索结果。

### 本地向量索引弹窗

- 展示每本书的章节/记忆向量记录数。
- 支持**批量重算**、单书重建、测试查询对话框（可直接输入文本查看相似度最高的章节）。
- 嵌入队列进行中时会显示进度横幅，可暂停或继续。

## 7) 💾 导入/导出

### 导出资料

导出为本地 JSON 文件，文件名格式：

- `tsukuyomi-settings-YYYY-MM-DD.json`

导出数据包含（当前实现）：

- AI 模型
- 书籍（含章节内容）
- 封面历史
- Memory
- 同步配置
- 应用设置

### 导入资料

- 支持文件类型：`.json`、`.txt`（内容需为可解析 JSON）。

导入行为（按当前实现）：

- AI 模型：有数据时先清空再导入。
- 书籍：有数据时先清空再导入。
- 封面历史：有数据时先清空再导入。
- Memory：按书籍逐条创建（不会先全量清空）。
- 应用设置：执行设置导入逻辑。
- 同步配置：有数据时覆盖当前同步配置。

> 导入不是“按字段精细选择”的流程；操作前建议先导出备份。

## ❓ 常见问题

### Q1：为什么桌面版看不到“代理设置”？

A：代理设置选项卡只在浏览器版显示。

### Q2：API Keys 里为什么没有 OpenAI / Gemini Key？

A：模型 API Key 在“AI 列表”中的模型编辑弹窗内配置，不在这里。

### Q3：导入后数据不符合预期怎么办？

A：先确认导入文件结构与内容；建议始终先导出一份当前本地备份，再执行导入。

### Q4：同步按钮可用但下载按钮灰色？

A：通常是未填写 Gist ID，或当前处于同步中。
