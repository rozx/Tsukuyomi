# 📚 章节管理

本页说明书籍详情页中「卷 / 章节」相关的实际功能与行为。

## 📖 基本结构

- **卷（Volume）**：用于组织章节。
- **章节（Chapter）**：必须隶属于某个卷。

左侧「目录」区域支持：新建、编辑、删除、折叠/展开、拖拽调整章节顺序。

## ➕ 新建卷

1. 在左侧「目录」点击 **新卷**。
2. 输入卷标题。
3. 点击添加。

当前实现行为：

- 新卷会追加到卷列表末尾。
- 新建卷时仅填写标题；卷译名可在后续「编辑卷」中设置。

## ➕ 新建章节

1. 点击 **新章节**。
2. 在弹窗中选择所属卷并填写章节标题。
3. 点击添加。

当前实现行为：

- 若当前书没有任何卷，无法新建章节，会提示先创建卷。
- 新建章节会追加到所选卷末尾。
- 新建弹窗仅包含「所属卷 + 章节标题」，不在此处录入章节正文或章节译名。

## ✏️ 编辑卷

在卷标题右侧点击编辑按钮，可修改：

- 卷标题（原文）
- 卷译名（可选）

显示时会按当前显示规则渲染卷标题（是否显示译名取决于当前标题数据）。

## ✏️ 编辑章节

在章节右侧点击编辑按钮，可修改：

- 章节标题（原文）
- 章节译名（可选）
- 所属卷（可将章节移动到其他卷）
- 章节级特殊指令：翻译 / 润色 / 校对

说明：

- 通过编辑弹窗修改所属卷时，章节会被移动到目标卷末尾。
- 章节级特殊指令会覆盖书籍级同类指令，仅作用于该章节。

## 🗑️ 删除卷

在卷右侧点击删除按钮并确认后删除。

当前实现行为：

- 删除卷时会同时删除该卷下全部章节。
- 删除操作不可撤销（确认弹窗会明确提示）。

## 🗑️ 删除章节

在章节右侧点击删除按钮并确认后删除。

当前实现行为：

- 章节从所属卷中移除。
- 删除操作不可撤销。

## 🔄 拖拽章节排序

章节支持拖拽：

- **同卷重排**：调整章节在卷内顺序。
- **跨卷移动**：拖拽到其他卷中的目标位置。

拖拽反馈：

- 被拖拽章节会半透明。
- 目标章节或目标卷列表会显示拖拽高亮样式。

## 📂 卷折叠 / 展开

- 点击卷标题左侧箭头可折叠或展开该卷章节列表。
- 系统会按书籍维度记住卷展开状态（保存在本地 UI 状态中）。

## 👀 列表提示

- 当前选中章节会高亮。
- 章节悬停时显示编辑/删除按钮。
- 若章节存在摘要，标题右侧显示信息图标，悬停可查看摘要预览。

## 🔄 检查更新与从网站导入

「检查更新」和「从网站导入」共用同一个**同步工作区**：按书籍记录的**来源配方**回放目录，列出变化，由你确认后才写入书库。

入口：

- **桌面 / 平板更新当前书籍**：书籍详情侧栏 **SETTINGS → 检查更新**，在主工作区以面板显示（路由 `/books/:id/settings/update`）。
- **手机更新当前书籍**：书籍概览的「检查更新」按钮，以全屏页面打开，顶栏返回书籍概览。
- **新建书籍**：首页 / 书库的「从网站导入」，或新建书籍对话框里的「从网站获取」，都会进入 `/books/new/web`。先输入小说目录网址并点「检查」；带 `?url=` 进入时会自动检查。编辑书籍对话框里的「从网站获取」会直接进入本书的检查更新。

工作区内容：

- **来源**：引擎（内置站点或通用网页配方）、目录网址、清理规则数、已跳过数，可随时「重新检查」。内置站点的旧书没有保存过配方时，会按站点规则自动推断。
- **汇总**：新章节、有更新、未检查、已跳过、失败的数量。
- **新章节**：默认勾选，按目标卷分组。点「更改目标卷」可以改放到已有卷，或输入名称新建卷；每章可以预览来源正文。
- **有更新**：显示改动 / 新增 / 删除的段落数和**将清空的译文版本数**，点「查看差异」逐段对比。有更新的章节**从不自动勾选**；更新会替换原文，原文被修订的段落会清空译文，未变化的段落保留译文。
- **深度检查**：快速检查只比对内置站点里更新日期较新的章节，其余已导入章节显示为「未检查」。点「深度检查」会逐章抓取比对，带进度、可随时取消，已完成的结果保留。
- **大面积差异提示**：已比对的章节里超过一半显示有更新时，会提示可能是站点改版或配方过期，请先看几章差异再决定。
- **跳过**：不想导入的章节（例如人物介绍）可以点跳过，之后的检查仍归入「已跳过」，也可以随时取消跳过。

应用：

1. 勾选后点「应用到书籍」（新建时为「应用并创建书籍」），先看确认摘要：新增章数、更新章数、将清空的译文版本数、会新建的卷。
2. 书籍正被翻译等任务占用时会拒绝应用并说明占用的任务；确认后书籍又被修改时，会重新计算并要求再次确认。
3. 部分章节抓取失败时，其余章节照常写入，失败的章节列在「失败」里，可以单独重试。
4. 应用成功后可在本次会话内撤销（应用栏或通知里的撤销）；书籍已有后续修改时无法撤销。新建书籍应用后会跳转到新书。

无法回放的情况：

- **不是内置站点的网址**：新建时会提示需要 AI 导入，点「交给 AI 导入器」会创建一个导入任务并登记该网址，然后跳到导入工作台（不会自动开始，由你决定何时运行）。
- **书籍没有配方或配方失效**（例如目录无法复现已导入章节、需要登录）：会显示原因，并提供「用 AI 导入器建立配方 / 修复配方」。点击会打开这本书的修复任务（已有未完成的就直接打开），预设好目标书和目录来源，不会自动运行。修复后的配方通过自测、应用导入后，这里就能重新检查更新。此时不显示任何章节列表或应用按钮。
- 通过 AI 导入器从网站导入的书，导入时会记录配方，之后同样可以在这里检查更新。详见 [AI 导入工作台](/help/import-guide) 的「更新配方」。
- 当前版本关闭 AI 导入时，这些入口会隐藏；内置站点的新建与检查更新照常可用。

## ❓ 常见问题

### 为什么点了「新章节」却不能添加？

当前书还没有卷。请先创建至少一个卷。

### 删除卷会怎样？

会连同该卷下所有章节一起删除，且无法撤销。

### 能拖拽卷顺序吗？

当前实现仅支持「章节拖拽」，不支持卷拖拽排序。
