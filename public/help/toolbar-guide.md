# 🛠️ 系统栏与导航

Tsukuyomi 在不同设备上采用不同的系统栏（System Bar）布局，但功能集合一致：**导航 / AI 思考 / 同步 / 消息 / 右栏面板**。本文按设备变体逐一说明各栏的位置与入口。

> v0.12.1 起桌面端整体迁移到工作台（Workbench）语言，左/右栏改成图标轨道、聊天与翻译进度独立面板、批量嵌入面板从顶栏改放到右栏；平板与移动端继续沿用 chip-based sysbar。功能本身没有删减。

---

## 🖥️ 桌面端布局

桌面端（`useResponsiveLayout` 判定为 `desktop` 或 Electron 强制 desktop）由四个区域组成：

```
+------------------------------------------------------------+
|  Sysbar (AppHeader): brand | AI | Sync | Notifications     |
+--------+------------------------------------------+--------+
|        |                                          |        |
| Left   |          Workspace (route content)       | Right  |
| rail   |                                          | rail   |
|        |                                          |        |
+--------+------------------------------------------+--------+
|  Footer (AppFooter): version | repo link                   |
+------------------------------------------------------------+
```

### 1) 顶部 Sysbar（`AppHeader`）

chip 风格的状态栏，从左到右：

- **侧栏开关（`☰`）** — 展开 / 收起左栏图标轨道。
- **品牌** — Logo + 应用名 + Moonlit Translator 副标题。
- **AI 思考过程**
  - 图标 ✨，无任务时显示「AI 思考」。
  - 有任务时变为 pill 状态，显示「AI 思考中 / 处理中」并加载动画点。
  - 点击打开思考面板：进行中任务（模型 / 类型 / 状态 / 用时）、思考消息、最近完成 10 条、停止 / 清空操作。
- **同步状态** — 图标 + 状态 chip，状态见下表：

| 状态 | 显示 | 说明 |
|:-----|:-----|:-----|
| 未启用 | 云图标「同步」 | 未配置 Gist 或未开启自动同步 |
| 未同步 | 云图标「未同步」 | 已启用但本地与远端尚未对齐 |
| 已同步 | 云✓「已同步 · 5m / 2h」 | 显示距下次同步的倒计时 |
| 待同步变更 | ↑「N 项变更」 | 检测到本地有未上传的变更（含书籍 / AI 模型 / 封面 / 设置 / 记忆 / 删除墓碑） |
| 同步中 | spinner「同步中」 | 正在执行 push / pull / merge |

  点击进入同步面板：上传 / 下载 / 详情，可看最后同步时间、下次同步时间、远端统计、阶段百分比。下载按钮在未启用、同步中、缺 Gist ID 时不可用。

- **消息历史** — 🔔，点击查看 toast 历史；未读角标超过 99 显示 `99+`。可按严重程度筛选（错误 / 警告 / 成功 / 信息），单条删除或清空，部分操作支持撤销。

> **批量摘要按钮已移除**（v0.12 起 AI 章节摘要功能撤回，由 `query_chapter` 工具按需检索原文取代）。

### 2) 左栏图标轨道（`AppSideMenu`）

默认是窄轨道，只显示图标；鼠标悬停或按 `☰` 展开成完整菜单。

主要导航：

- 🏠 **首页** — `/`
- 📚 **书籍列表** — `/books`
- ✨ **AI列表** — `/ai`

辅助导航（轨道底部）：

- ⚙️ **设置** — `/settings`
- ❓ **帮助** — `/help`

### 3) 右栏图标轨道（`AppRightPanelDesktop`）

固定宽度 + 拖拽 resize 手柄；展开后显示当前激活面板。轨道入口：

- 💬 **AI 助手** — 对应 `AppChatPanelDesktop`，包含会话列表、消息流、输入区、上下文（书籍 / 章节 / 段落）、待办、上下文用量进度条。
- 📊 **翻译进度** — 对应 `AppProgressPanelDesktop`，显示翻译 / 润色 / 校对任务进度条；活跃任务数量以 tab 数字角标显示，开始新任务时面板自动切到该任务，可在面板内取消。
- 🧬 **向量索引**（仅书籍详情页路由显示） — 打开 `BatchEmbeddingsPanel` 抽屉，查看本书章节 / 记忆嵌入统计（已嵌入 / 总数 / stale）、批量重算、测试查询、暂停 / 继续。**依赖本地嵌入开启**，详见 [本地嵌入](/help/local-embedding)。

> 切换轨道入口会自动激活对应面板；未激活面板**不挂载**任何 watcher，避免跨面板的副作用。

### 4) 底部 Footer（`AppFooter`）

显示版本号与 GitHub 链接（GitHub 图标）。Electron 桌面版会用同样的 footer。

## 📱 平板端布局

平板端（`tablet` 断点）使用紧凑型 sysbar：

```
+--------------------------------------------------------+
|  TabletSysBar: brand | version | AI | Sync | Notify    |
+--------------------------------------------------------+
|                                                        |
|              Workspace (route content)                 |
|                                                        |
+--------------------------------------------------------+
```

### Sysbar 结构

- **左侧**：品牌名 + 版本号（`v0.12.1`）。
- **右侧 chips**：AI 思考过程 / 同步状态 / 消息历史 — 各项行为与桌面端一致，只是 chip 文字更紧凑（如「AI 思考中 → AI 思考过程」，「N 项变更 / 已同步 / 同步中」）。

### 导航与右栏

- 主导航走 Quasar 抽屉（点击 sysbar 左侧的菜单图标），包含首页 / 书籍 / AI / 设置 / 帮助。
- 右栏由独立的「聊天 / 进度」开关控制（路由进入书籍详情页时按需展开），交互细节与桌面端一致，只是没有图标轨道。

### 关于本地嵌入入口

平板端**没有**专用的「向量索引」按钮：物理移动设备 UA 会强制锁住本地嵌入；如果是桌面浏览器缩到平板宽度，则可以在**设置 → 本地嵌入**配置开关，但批量嵌入抽屉仅在桌面布局下渲染。

## 📲 移动端布局

移动端（`mobile` 断点）使用极简 sysbar + 主体内容：

```
+----------------------------------+
|  MobileSysBar:                   |
|  logo | AI | Sync | Help         |
+----------------------------------+
|                                  |
|     Route content (full width)   |
|                                  |
+----------------------------------+
```

### Sysbar 结构

- **左侧**：Logo + 应用名 + 版本号。
- **右侧 chips**：
  - AI 思考过程
  - 同步状态
  - 消息历史
  - **帮助**（移动端独有 chip，直接跳到 `/help`）

> 移动端导航主要靠主页快捷入口、底部抽屉与路由 push；没有左栏轨道。`useResponsiveLayout()` 判定为 `mobile` 时，本地嵌入功能（含 `query_chapter` 工具）会被禁用，避免浏览器 WASM 内存上限触发崩溃。

## 🔁 跨设备一致的状态语义

不论哪个变体，下列状态来源都是同一份 `useSystemBar()`：

- 待同步变更数（含书籍 / AI 模型 / 封面 / 设置 / 记忆增删改 / 墓碑删除）。
- 距下次同步的倒计时（启用自动同步时）。
- 当前 AI 任务标签（思考中 / 处理中 / 等）。
- 消息历史未读条数。

修改同步配置 / 主动触发同步 / 暂停队列 / 清空消息历史等操作，会立即在三个变体的 sysbar 同步刷新。

## ❓ 常见问题

**Q: 桌面端为什么找不到「批量摘要」按钮？**
A: 章节摘要功能已在 v0.12 移除。AI 现在通过 `query_chapter` 工具按需对原文做语义检索，不再需要预生成摘要。

**Q: 桌面端右栏的「向量索引」按钮去哪了？**
A: 该按钮仅在书籍详情页路由（`/books/:id` 及其子路由）下出现，且依赖本地嵌入开启。请先在**设置 → 本地嵌入**启用功能；详见 [本地嵌入](/help/local-embedding)。

**Q: 同步按钮一直显示「同步中」？**
A: 检查 Gist 配置、网络连通性与 Token 权限；点开 sysbar 上的消息历史 🔔 查看具体错误日志。

**Q: AI 思考面板为空？**
A: 当前可能没有任务记录或已被清空。开始任何翻译 / 润色 / 校对任务都会留下记录。

**Q: 平板端把窗口拉大后变成了桌面布局，为什么本地嵌入仍然灰显？**
A: 物理移动设备的 UA 标识不会因窗口尺寸改变而消失。本地嵌入按 UA 判定（避免移动设备 WASM 崩溃），与窗口宽度无关。
