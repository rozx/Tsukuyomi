# 📖 书籍详情页概览

书籍详情页（路由 `/books/:id`）是单本书的核心工作区。所有翻译、术语 / 角色 / 记忆维护、导出、与 AI 互动都集中在这里。

> v0.12.1 起桌面端整体调整：侧栏宽度收紧、SETTINGS 入口收纳为可折叠分组、删除冗余的「返回」与「目录」副标题（顶栏 breadcrumb 替代）；翻译进度面板移到全局右栏的「翻译进度」入口，跨页面均可访问。本指南按设备变体描述。
>
> v0.12 起 **AI 章节摘要功能已移除**：AI 不再为每章预生成摘要，而是在需要时通过 `query_chapter` 工具按语义检索原文（依赖[本地嵌入](/help/local-embedding)）。

## 🖥️ 桌面端布局

```
+------------------------------------------------+
|  Workbench Header (book title + breadcrumb)    |
+--------------+---------------------------------+
|              |                                 |
|  Sidebar     |   Workspace                     |
|              |   (chapter content / settings)  |
|  BOOK card   |                                 |
|   cover      |   - ChapterToolbar              |
|   + stats    |   - SearchToolbar               |
|              |   - ChapterContentPanel         |
|  SETTINGS    |     or TerminologyPanel /       |
|   - Translation |     CharacterSettingPanel /  |
|   - Terms    |        MemoryPanel /            |
|   - Chars    |        BookUpdatePanel          |
|   - Memory   |                                 |
|   - Update   |                                 |
|              |                                 |
|  Catalog     |                                 |
|   volumes    |                                 |
|   + chapters |                                 |
|              |                                 |
+--------------+---------------------------------+
```

### 侧栏（左）

侧栏从上到下分为三部分：

#### 1) BOOK — 书籍卡

显示封面 + 标题 + 卷 / 章 / 字数三联统计。点击任意位置即可打开 `BookDialog` 编辑书籍信息（标题、作者、简介、标签、封面、别名、Web URL、书籍级特殊指令）。

#### 2) SETTINGS — 可折叠分组

展开 / 折叠按钮控制是否显示文字标签：

- **展开态**：显示 `SETTINGS` eyebrow + 收起按钮，5 个项以图标 + 文字呈现：
  - ⚙️ 翻译设置 → 进入书籍级翻译设置面板，管理显示规则、任务分块与本书模型覆盖
  - 🔖 术语设置 → 进入 `TerminologyPanel`
  - 👥 角色设置 → 进入 `CharacterSettingPanel`
  - 🗄 记忆管理 → 进入 `MemoryPanel`
  - ⬇ 检查更新 → 进入 `BookUpdatePanel`，从在线源抓取并增量合并章节
- **折叠态**（默认）：5 个图标按钮 + 1 个 chevron 展开按钮。

折叠状态由 `ui.bookSettingsMenuExpanded` 持久化，跨会话保留偏好。

#### 3) 目录 — 卷 / 章节列表

- **新建**：「+ 新卷」「+ 新章节」按钮位于目录顶部。
- **卷展开 / 折叠**：点击卷名旁的箭头切换。
- **拖拽排序**：章节支持跨卷拖拽。
- **章节标题翻译**：每章可独立设置翻译标题。
- **章节级特殊指令**：在章节项上下文菜单或编辑弹窗中维护。

> 桌面端 BOOK 卡片下方的「返回」按钮已被移除。回到书籍列表请用顶部 sysbar 的 breadcrumb，或左栏的「书籍列表」入口。

### 工作区（右）

工作区根据当前选中状态切换显示内容：

| 选中项 | 显示内容 |
|:-------|:---------|
| 一个章节 | `ChapterContentPanel`（按编辑模式渲染） |
| 「翻译设置」 | `BookTranslationSettingsPanel`（书籍级设置、分块大小与模型覆盖） |
| 「术语设置」 | `TerminologyPanel` |
| 「角色设置」 | `CharacterSettingPanel` |
| 「记忆管理」 | `MemoryPanel` |
| 「检查更新」 | `BookUpdatePanel`（内嵌小说抓取器） |

进入设置面板时，工作区顶部会显示「Translation / Terms / Characters / Memory / Update」eyebrow + 名称 + 图标的上下文标签。

## 📱 平板端布局

平板端与桌面端共享侧栏 + 工作区结构，但有几个差异：

- **侧栏可收起**：默认展开，工具栏右上角有按钮收起为窄轨道；通过 `ctx.isTabletSidebarOpen` 控制。
- **章节工具栏使用 `ChapterToolbarTablet`**：紧凑版，把次要操作收纳到溢出菜单。
- **目录使用 `VolumesListTablet`**：单列卡片样式，触屏点击区域更大。
- **SETTINGS 折叠状态与桌面端共享**：在桌面端展开后切到平板端，平板侧的菜单也是展开态。

## 📲 移动端布局

移动端没有同时可见的侧栏与工作区，而是通过 `ctx.workspaceMode` 在两个全屏视图间切换：

| `workspaceMode` | 显示 |
|:----------------|:-----|
| `'catalog'` | 全屏目录（书籍卡 + 章节列表） |
| `'reader'` | 全屏章节内容 |

切换路径：

- 主路由进入时默认 `'catalog'`，点击章节进入 `'reader'`。
- 阅读时点击工具栏左侧的「目录」按钮回到 `'catalog'`。

> 移动端 SETTINGS 不在侧栏渲染（节省空间）— 术语 / 角色 / 记忆通过子路由 `/books/:id/settings/(terms|characters|memory)` 进入对应专用页面。

> 移动端不新增「翻译设置」侧栏路由态：书籍级翻译设置位于阅读器齿轮底部抽屉的「全局设置」页签；「检查更新」仍从书籍概览以底部抽屉 / 对话框打开。桌面 / 平板则使用侧栏路由面板。

> 移动端**不渲染**右栏轨道与「向量索引」面板。物理移动设备的本地嵌入会被强制禁用，AI 仍可使用关键词 + 时间衰减信号自动注入记忆，但 `query_chapter` 工具不暴露。

## ✨ 核心能力（跨变体）

下列能力在所有设备变体上都可用：

### 1) 章节结构管理

- 新建、编辑、删除卷与章节。
- 章节拖拽排序（含跨卷）。
- 章节标题翻译、章节级特殊指令、章节信息维护。

### 2) 三种编辑模式

`useEditMode` 提供三种模式（默认 `translation`）：

| 模式 | 用途 |
|:-----|:-----|
| **原始文本（`original`）** | 编辑章节的原始日文文本，编辑会覆盖现有段落与翻译；保存 / 取消 / 备份机制由 composable 管理 |
| **翻译模式（`translation`）** | 段落级原文 / 译文操作，是默认工作模式 |
| **预览模式（`preview`）** | 面向阅读的译文预览；未翻译段落会以提示样式呈现 |

### 3) 段落与章节操作

- 段落级：重译、润色、校对、添加翻译版本（每段支持多版本切换）。
- 章节级：全章翻译 / 润色 / 校对，或仅翻译未翻译段落。
- 点击工具栏的术语 / 角色 / 记忆按钮（带使用计数徽章）打开本章对应面板，复核一致性。

### 4) 搜索与快捷键

桌面端 `ChapterToolbar` 保留以下快捷键：

| 快捷键 | 功能 |
|:-------|:-----|
| `Ctrl+F` | 打开 / 关闭查找 |
| `Ctrl+H` | 打开 / 关闭替换 |
| `F3` / `Shift+F3` | 下一个 / 上一个匹配 |
| `Esc` | 关闭搜索工具栏 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+Shift+C` | 复制本章已翻译文本 |

撤销 / 重做按钮上会显示具体的操作描述（如「撤销: 翻译第 12 段」）。

### 5) 导出能力

章节工具栏的「导出」菜单支持：

- **格式**：原文 / 译文 / 双语
- **目标**：复制到剪贴板 / 导出 JSON / 导出 TXT

支持以单章为单位导出，也可在书籍列表页针对整本书批量导出。

### 6) AI 上下文检索

- **`search_memories` 工具**：AI 可按自然语言搜索记忆库，命中的条目临时注入翻译上下文。
- **`query_chapter` 工具**（依赖本地嵌入开启）：AI 可按自然语言搜索本书章节内容（包括标题型、剧情型、人物型 query），无需用户预先生成章节摘要。

详见 [AI 翻译功能](/help/book-details-translation) 与 [本地嵌入](/help/local-embedding)。

## 🚀 基本使用流程

1. 在主页 / 书籍列表选中一本书进入。
2. 在侧栏目录中选择章节，或点开 SETTINGS 维护翻译设置 / 术语 / 角色 / 记忆及检查更新。
3. 在工具栏选择编辑模式（一般是默认的「翻译模式」）。
4. 进行段落翻译与修订；可用搜索替换批量改译文。
5. 通过术语 / 角色 / 记忆按钮（带使用计数）随时复核一致性。
6. 完成后用导出菜单输出章节，或在书籍列表页批量导出。

## ℹ️ 与全局 sysbar 的关系

- 顶部 sysbar（[详见此处](/help/toolbar-guide)）提供 AI 思考过程、同步状态、消息历史等全局入口，跨页面始终可见。
- 桌面端右栏的「**翻译进度**」入口随时显示当前翻译 / 润色 / 校对的任务进度条，开始新任务时面板自动切到该任务。
- 桌面端右栏的「**向量索引**」入口仅在书籍详情页路由下出现，需要本地嵌入开启。
