# 🏠 书籍库与主页（Library & Home）

主页（路由 `/`）是 Tsukuyomi 的工作台首页，用于总览项目状态并快速进入常用流程。所有数据默认存储在浏览器 **IndexedDB**，可选 GitHub Gist 同步。

> v0.12.1 起，主页桌面端改用工作台（Workbench）语言：「继续阅读」hero + 紧凑型指标条 + 快捷操作；平板端为 hero 卡 + 5 项 stat 网格 + 最近编辑；移动端保持单列 stat + 最近编辑 + 快捷操作。下文按设备变体逐个说明。

---

## 🖥️ 桌面端

桌面端主页由四个区块组成：

```
+--------------------------------------------------------+
|  DesktopWorkbenchHeader (title + metrics)              |
+--------------------------------------------------------+
|  Continue Reading hero (most recent book)              |
+--------------------------------------------------------+
|  Quick actions (4 cards)                               |
+--------------------------------------------------------+
|  Recently edited (6 cards)                             |
+--------------------------------------------------------+
```

### 1) 工作台 Header + Metrics

顶部头部使用统一的 `DesktopWorkbenchHeader`，与书籍列表 / AI 模型 / 设置等其他工作页视觉对齐：

- 标题：「欢迎回来」（无任务时）/「工作台正在运行」（有 AI 任务时）。
- 副标题：上次停留的书籍提示（若有），以及当前是否有进行中任务的状态。
- **Metrics 条**（`DesktopWorkbenchMetrics`）：5 项关键指标，从左到右：

| Metric | 含义 |
|:-------|:-----|
| 📚 书籍 | 当前书籍总数 |
| 📑 章节 | 全部书籍章节总数 |
| 📝 字数 | 章节内容字数总和（异步计算） |
| 🏷️ 术语 | 术语库条目总数 |
| ⭐ 收藏 | 收藏书籍数 |

### 2) 继续阅读 Hero

最近正在翻译 / 阅读的书籍以大封面卡形式置顶，包含：

- **Eyebrow**：`Continue Reading`。
- **状态**：「正在翻译」（pill + 加载点）/「更新于 YYYY-M-D」（无任务时）。
- **标题 + 作者**。
- **统计**：章节数、字数（异步加载时显示骨架）、收藏标记（如已收藏）。
- **主 CTA**：进入书籍详情页（继续翻译 / 查看进度）。
- **次 CTA**：「打开书库」回到 `/books`。

无书籍时（首次启动或全部删除后）hero 不显示，只保留 Metrics + 快捷操作。

### 3) 快捷操作

4 张卡片（响应式网格）：

| 卡片 | 行为 |
|:-----|:-----|
| ➕ **添加书籍** | 弹出 BookDialog 手动创建：标题、作者、简介、标签、封面、别名、Web URL、书籍级特殊指令 |
| 🌐 **从网站导入** | 通过 URL 抓取 — 支持 `ncode.syosetu.com`、`novel18.syosetu.com`、`kakuyomu.jp`、`syosetu.org`；支持章节勾选、增量识别 |
| 📚 **打开书库** | 跳转到书籍列表页 `/books` |
| 🤖 **AI 设置** | 跳转到 AI 模型管理页 `/ai`，配置可用模型与任务路由 |

### 4) 最近编辑

按 `lastEdited` 倒序展示最近 **6 本**书籍卡片：

- 封面、标题、作者、章节数、字数。
- 点击任一卡片进入书籍详情页。
- 任何写操作（编辑章节、生成翻译、修改术语等）都会更新 `lastEdited`，自动上浮到前列。

## 📱 平板端

平板端主页采用 hero + 紧凑指标 + 操作 + 最近列表的卡片化布局：

### Hero 双卡

- 上次停留的书籍以**继续阅读卡**呈现：标题、作者、章节数 + 「更新于 X」副线、CTA「继续翻译」。
- 若有进行中 AI 任务，旁边再叠一张**正在翻译卡**：spinner + 「正在翻译」状态、CTA「查看进度」。
- 无书籍时 hero 区域省略。

### 5 项 Stat 网格

紧凑横排 5 个指标，**与桌面端 Metrics 同源**，但用更大图标 + 数值的卡片样式：

- 📚 总书籍 · 📑 总章节 · 📝 总字数 · 🏷️ 术语 · ⭐ 收藏

### 最近编辑

与桌面端相同的最近 6 本书逻辑，使用平板尺寸的卡片排版。

### 快捷操作

继续保留「添加书籍 / 从网站导入 / 打开书库 / AI 设置」4 个入口，但在卡片底部条状排布，节省垂直空间。

## 📲 移动端

移动端主页采用单列卡片堆叠，照顾窄屏滚动：

```
+----------------------+
|  Stat grid (2x2)     |
|  Books / Chapters    |
|  Words / Starred     |
+----------------------+
|  Recently edited     |
|  (single-column)     |
+----------------------+
|  Quick actions       |
|  + Add book          |
|  + Import from URL   |
+----------------------+
```

### Stat 网格（4 项）

移动端不显示「术语」指标（窄屏空间优先），保留：

- 📚 书籍 · 📑 章节 · 📝 字数 · ⭐ 收藏

### 最近编辑

最近 6 本书的单列卡片列表，一屏滚 2-3 张，封面缩略图 + 标题 + 作者。

### 快捷操作

移动端只保留两个核心入口：

- ➕ **添加书籍**（PrimeVue primary）
- 🌐 **从网站导入**（outlined）

如需访问书库 / AI 设置 / 设置页，请使用顶部 sysbar 的导航或主菜单抽屉。

> 移动端会强制禁用本地嵌入功能（避免 WASM 内存崩溃）。AI 翻译、术语 / 角色 / 记忆等核心功能完全可用，但「按语义自动注入记忆」「`query_chapter` 检索原文」等语义功能会自动降级为关键词 + 时间衰减。

## 🔄 数据备份与同步

不论哪个变体，主页都不直接管理同步：

- **手动备份**：在**设置 → 导入/导出**点击「导出资料」生成 `tsukuyomi-settings-YYYY-MM-DD.json`。
- **GitHub Gist 同步**：在**设置 → 数据同步**配置 Gist Token 与 ID 即可启用，状态显示在顶部 sysbar 的「同步」chip 上（详见 [系统栏与导航](/help/toolbar-guide)）。

## 📚 路由速查

| 路径 | 说明 |
|:-----|:-----|
| `/` | 主页（本指南） |
| `/books` | 书籍列表页 |
| `/books/:id` | 书籍详情页（默认进入翻译模式） |
| `/books/:id/settings/(terms\|characters\|memory)` | 书籍详情页中切到对应设置面板 |
| `/ai` | AI 模型管理 |
| `/settings` | 应用设置 |
| `/help/:docId?` | 帮助页（本文件即来自此处） |

> 这些路径在所有设备变体上一致，dispatcher 会根据当前设备变体加载对应的桌面 / 平板 / 移动模板。

## ❓ 常见问题（FAQ）

**Q: 网站导入失败怎么办？**
A: 先核对 URL 与网络连通性；Web 端可在**设置 → 代理设置**配置代理；查看 sysbar 的消息历史 🔔 看具体错误日志。

**Q: 可以一次性导出全部数据吗？**
A: 可以。**设置 → 导入/导出**的「导出资料」会打包 AI 模型、书籍（含章节内容）、封面历史、记忆、同步配置、应用设置。

**Q: 字数统计为什么不更新？**
A: 字数是后台异步计算。批量导入大量章节后请稍等，进度条结束后会刷新。

**Q: 桌面端主页没有 hero，怎么回事？**
A: 还没创建任何书籍。添加第一本书后 hero 自动出现。

**Q: 桌面端的 Metrics 数字和平板 / 移动端不一致？**
A: 三个变体使用同一份 store 数据，刷新时机也一致。如果出现跨变体差异通常是缓存未刷新；切换路由再回来即可。
