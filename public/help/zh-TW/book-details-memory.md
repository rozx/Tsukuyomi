# 記憶管理 {#book-details-memory-section-1}

記憶管理功能幫助您記錄書籍的關鍵資訊、劇情要點和重要設定，為 AI 翻譯提供更豐富的上下文，確保翻譯的連貫性和準確性。

記憶正文和摘要跨書籍目標語言共享，不會因介面或目標切換而翻譯、刪除或清空向量。檢索的術語、角色及別名詞元使用原名和本次目標譯名，不借用其他語言。章節參考預覽與實際注入復用相同的純讀取選擇器；目標、正文、標題或實體名稱變化後預覽會刷新，舊結果不會覆蓋新語言。

## 🧠 什麼是記憶 {#book-details-memory-section-2}

記憶是關於書籍的重要資訊片段，用於存儲 AI 翻譯時需要的大塊上下文，如世界觀設定、劇情要點、角色關係演變等。

**記憶的用途**：

- 🌍 記錄世界觀設定和規則
- 📖 儲存重要的劇情發展
- 💡 存儲關鍵的背景資訊
- ⚠️ 記錄翻譯時需要注意的事項

## 📋 記憶的結構 {#book-details-memory-section-3}

每條記憶包含以下資訊：

**核心內容**：

- 📝 **內容**: 記憶的詳細內容（必填）
- 🤖 **摘要**: AI 自動生成的內容摘要

**元資料**：

- 📅 **建立時間**: 記憶建立的時間
- 🕘 **最後訪問時間**: 用於時間衰減評分
- 🧬 **語義向量**: 本地嵌入模型生成的多維向量（用於語義檢索）

## 🚪 訪問記憶管理面板 {#book-details-memory-section-4}

**操作步驟**：

1. 📑 在書籍詳情頁的左側邊欄
2. ⚙️ 找到"設定菜單"區域
3. 🖱️ 點選"記憶管理"按鈕
4. 📋 右側會顯示記憶管理面板

**面板佈局**：

- 🛠️ **頂部工具欄**: 添加記憶、搜索、篩選（僅未向量化）、重新向量化、匯入/匯出
- 📊 **進度橫幅**: 嵌入隊列活躍時顯示向量化進度和暫停/繼續按鈕
- 📇 **記憶列表**: 顯示所有記憶的卡片（每張卡片右上角有向量狀態徽章）
- 📄 **記憶詳情**: 點選記憶查看和編輯詳細內容

## 添加記憶 {#book-details-memory-section-5}

### 手動添加 {#book-details-memory-section-6}

**操作步驟**：

1. 在記憶管理面板
2. 點選"添加記憶"按鈕
3. 在彈出的對話框中填寫：
   - **摘要**: 記憶的簡短描述（必填，用於 AI 檢索）
   - **內容**: 記憶的詳細內容（必填）
4. 點選"儲存"按鈕

**填寫建議**：

- **內容詳細**: 提供足夠的細節幫助 AI 理解
- **一個概念一條記憶**: 每條記憶應該是一個完整的概念
- **長度適中**: 建議控制在 200-500 字

### 記憶內容示例 {#book-details-memory-section-7}

**世界觀設定**：

```
本世界的魔法分為五大元素：火、水、風、土、雷。
每個魔法師只能掌握其中一種元素。
魔法的強度與魔法師的精神力成正比。
```

**劇情要點**：

```
主角在第15章發現自己是失蹤多年的王子。
這個秘密只有老管家知道，他一直在暗中保護主角。
```

**翻譯注意事項**：

```
本作中"夜明け"不翻譯為"黎明"，而應翻譯為"曙光"，
因為作者在後記中解釋這個詞有特殊的象徵意義。
```

## 編輯記憶 {#book-details-memory-section-8}

### 修改記憶內容 {#book-details-memory-section-9}

**操作步驟**：

1. 在記憶列表中找到要編輯的記憶
2. 點選記憶卡片
3. 在彈出的對話框中修改資訊
4. 點選"儲存"按鈕

**可修改內容**：

- 記憶的內容
- 隨時補充和完善記憶

### 更新記憶 {#book-details-memory-section-10}

**隨劇情更新**：

- 新資訊揭露時更新內容
- 伏筆實現後添加註釋
- 設定擴展時補充細節

## 匯入與匯出 {#book-details-memory-section-11}

### 匯出記憶 {#book-details-memory-section-12}

- 點選工具欄的"匯出"按鈕
- 將當前記憶庫匯出為 JSON 檔案

### 匯入記憶 {#book-details-memory-section-13}

- 點選工具欄的"匯入"按鈕
- 選擇 JSON 格式的記憶檔案
- 系統會自動合併新舊記憶

## 刪除記憶 {#book-details-memory-section-14}

**操作步驟**：

1. 在記憶列表中找到要刪除的記憶
2. 點選記憶卡片旁的"刪除"按鈕
3. 在確認對話框中確認刪除

**刪除影響**：

- 刪除後不可恢復
- AI 翻譯時不再參考該記憶
- 建議刪除前確認不再需要

## 三信號智能檢索 {#book-details-memory-section-15}

翻譯時系統自動從記憶庫中選擇最相關的記憶注入 AI 上下文，無需手動關聯。

### 評分公式 {#book-details-memory-section-16}

每條記憶的相關度得分（0 ~ 1.0）由三個信號加權計算。權重隨嵌入是否可用自動切換：

**嵌入可用（語義主導）**：

| 信號           | 權重 | 說明                                                                                                          |
| :------------- | :--- | :------------------------------------------------------------------------------------------------------------ |
| **語義相似度** | 0.85 | 記憶向量與當前翻譯內容的余弦相似度，先經絕對置信度校准（floor 0.30 / full 0.65）再乘批內對比度門控與 RRF 排名 |
| **關鍵詞匹配** | 0.10 | 當前章節中出現的術語/角色名在記憶文本中的命中比例                                                             |
| **時間衰減**   | 0.05 | 最近訪問的記憶得分更高（30 天半衰期指數衰減）                                                                 |

**嵌入不可用 / 關閉（關鍵詞 fallback）**：

| 信號           | 權重 | 說明 |
| :------------- | :--- | :--- |
| **關鍵詞匹配** | 0.75 | 同上 |
| **時間衰減**   | 0.25 | 同上 |

> 語義信號使用「絕對置信度 × 批內對比度」校准：原始余弦低於 0.30 視為無語義證據；候選數 ≥ 4 時中等相似度還需比本批中位數高出 0.08 才能拿到完整對比度置信度，避免「整批都無關卻仍被 RRF 抬成滿分」。

### 字符預算 {#book-details-memory-section-17}

系統按得分從高到低填充，字符預算（預設 2000 字符）包含記憶區域標題、ID、摘要和換行。超出剩餘預算的記憶會被跳過；異常備援也遵守此上限。低於最低相關度閾值（預設 0.30）的記憶不會被正常篩選選中。

### 語義檢索 {#book-details-memory-section-18}

在**設定 → 本地嵌入**中開啟"啟用本地嵌入"後，系統會使用本地嵌入模型為每條記憶生成 768 維語義向量。這使得 AI 能夠理解記憶的語義含義，而不僅僅是關鍵詞匹配。原理與排查請見獨立文檔：[本地嵌入](/help/local-embedding)。

- **預設模型**：`onnx-community/gte-multilingual-base`（305M 參數多語言 BERT encoder，覆蓋中 / 日 / 英等 70+ 語言）；本應用使用完整 768 維向量並 L2 歸一化，CLS pooling 與官方示例一致，v0.14.3 起取消非對稱 query 前綴。
- **長記憶分段嵌入**：v0.14.3 起，單條記憶的"摘要 + 內容"按段落和句末標點切成 ≤1200 字的短段分別嵌入並穩健聚合，避免長記憶被截斷後語義漂移。
- **下載體積**：WebGPU q4f16 ~465MB，WASM int8 ~340MB（按所選後端自動決定）；首次下載後瀏覽器快取自動復用。
- **完全本地運行**，不消耗 API 額度；優先使用 WebGPU，回退到 WASM。
- **移動端強制禁用**本地嵌入（瀏覽器 WASM 記憶體限制），但關鍵詞匹配和時間衰減信號仍然生效。
- 即使不啟用本地嵌入，關鍵詞匹配和時間衰減信號仍會工作，系統會自動使用**退化評分權重**保證記憶依然有參考價值。

## 記憶搜索與篩選 {#book-details-memory-section-19}

### 混合搜索 {#book-details-memory-section-20}

在記憶面板頂部的搜索框中輸入查詢文本，系統會同時使用關鍵詞匹配和語義相似度（啟用語義檢索時）對記憶進行排序，返回最相關的結果。

**搜索範圍**: 記憶內容 + 摘要

### 篩選功能 {#book-details-memory-section-21}

- **僅顯示未向量化**: 篩選出尚未生成語義向量的記憶，便於檢查向量化覆蓋情況
- **清除篩選**: 一鍵清除搜索詞和篩選條件

## 記憶在翻譯中的應用 {#book-details-memory-section-22}

### 自動注入 {#book-details-memory-section-23}

翻譯時，系統自動完成以下流程：

1. **提取實體**: 掃描當前翻譯文本中出現的術語和角色名
2. **三信號打分**: 對所有記憶計算語義相似度 + 關鍵詞命中率 + 時間衰減
3. **字符預算填充**: 按得分從高到低選擇記憶，直到達到字符預算上限
4. **注入上下文**: 將選中的記憶作為 `【相關記憶】` 注入 AI 翻譯提示詞

### 預覽參考記憶 {#book-details-memory-section-24}

在書籍詳情頁的工具欄中，點選"參考記憶"按鈕可以預覽當前章節會使用哪些記憶，以及每條記憶的三信號得分。預覽結果會在切換章節時自動更新。

預覽不更新記憶訪問時間、書籍修改序號或執行評分記錄。評分失敗時，預覽與真實注入統一回退最近 15 條；只在實際注入發佈本次評分記錄，避免預覽干擾運行中任務。

### AI 工具搜索 {#book-details-memory-section-25}

AI 在翻譯過程中也可以主動調用 `search_memories` 工具，用自然語言查詢搜索記憶庫。搜索同樣使用關鍵詞 + 語義混合檢索。

## 最佳實踐 {#book-details-memory-section-26}

### 建立記憶庫的時機 {#book-details-memory-section-27}

**推薦流程**：

1. **閱讀第一章後**: 記錄基本世界觀設定
2. **每完成一卷**: 總結重要劇情和設定
3. **翻譯前**: 完善關鍵記憶
4. **翻譯中**: 遇到重要資訊及時記錄

### 記憶的粒度 {#book-details-memory-section-28}

**避免過細**：

- 不要記錄每個細節
- 專注於真正重要的資訊
- 一條記憶應該是一個完整的概念

**避免過粗**：

- 不要把太多資訊塞在一條記憶中
- 不同主題應該分開記錄
- 便於後續查找和使用

**推薦粒度**：

- 一條記憶 = 一個設定/事件/概念
- 長度控制在 200-500 字
- 包含必要的細節，去除無關資訊

### 記憶的更新 {#book-details-memory-section-29}

**定期審核**：

- 每完成一卷審核一次
- 刪除過時或無用的記憶
- 補充新的重要資訊
- 合併重復的記憶

**保持準確**：

- 及時更新過期資訊
- 修正錯誤的理解
- 補充遺漏的細節

### 記憶與其他功能的配合 {#book-details-memory-section-30}

**與術語庫配合**：

- 術語庫記錄名詞的翻譯 → 翻譯時自動作為關鍵詞匹配信號
- 記憶庫解釋名詞的含義和背景 → 當術語名出現在記憶摘要/內容中時自動關聯

**與角色設定配合**：

- 角色設定記錄人物的基本資訊 → 角色名和別名自動作為關鍵詞匹配信號
- 記憶庫記錄角色的關鍵經歷和發展

**分工建議**：

- 基本資訊 → 術語庫、角色設定
- 背景故事、劇情要點 → 記憶庫
- 翻譯規範、注意事項 → 術語庫、記憶庫

## 常見問題 {#book-details-memory-section-31}

### 記憶太多會影響性能嗎？ {#book-details-memory-section-32}

- 系統通過字符預算和相關度閾值控制每次注入的記憶數量
- 單本書最多 500 條記憶
- 全量記憶有 60 秒快取，不會頻繁讀取資料庫
- 語義向量化在背景異步執行，不阻塞翻譯

### 如何組織大量記憶？ {#book-details-memory-section-33}

1. 保持每條記憶的獨立性（一個概念一條記憶）
2. 使用混合搜索快速查找
3. 定期整理和歸檔
4. 利用"僅顯示未向量化"篩選檢查覆蓋情況

### 記憶和章節向量索引有什麼區別？ {#book-details-memory-section-34}

- **章節向量索引**（自動）：啟用本地嵌入後，系統會為每個章節的段落以及"章節標題 + 首段"建立多向量索引，AI 可通過 `query_chapter` 工具按自然語言搜索章節內容，用作即時上下文。
- **記憶庫**（手動）：您手動錄入的跨章節重要資訊（世界觀、伏筆、翻譯注意事項等），由 AI 通過 `search_memories` 工具檢索或通過三信號評分自動注入翻譯。

建議：

- 章節向量索引用於獲取"書內其他章節中的相關段落"。
- 記憶庫用於記錄長期、概括性、跨章節的資訊，它們不適合通過檢索原文獲得。

### 如何決定什麼資訊值得記錄？ {#book-details-memory-section-35}

詢問自己以下問題：

1. 這個資訊在後續章節會被引用嗎？
2. 理解這個資訊對翻譯有幫助嗎？
3. 這是一個容易忘記但重要的細節嗎？
4. AI 可能會誤解或翻譯錯誤嗎？

如果任何一個問題的答案是"是"，就值得記錄。
