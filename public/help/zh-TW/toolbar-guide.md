# 🛠️ 系統欄與導航 {#toolbar-guide-section-1}

Tsukuyomi 在不同設備上採用不同的系統欄（System Bar）佈局，但功能集合一致：**導航 / 任務中心 / 同步 / 月詠助手 / 訊息**。本文按設備變體逐一說明各欄的位置與入口。

> v0.12.1 起桌面端整體遷移到工作台（Workbench）語言，左欄改成圖標軌道；平板與移動端繼續沿用 chip-based sysbar。章節任務的進度統一在頂部的「任務中心」查看（原右欄「翻譯進度」與「AI 思考」入口已合併）。桌面右側圖標欄與平板書庫頁、書籍詳情頁的右側直向欄已移除：月詠助手從頂部系統欄打開，向量化進度與操作併入任務中心的「背景 · 向量化」區。

---

## 🖥️ 桌面端佈局 {#toolbar-guide-section-2}

桌面端（`useResponsiveLayout` 判定為 `desktop` 或 Electron 強制 desktop）由四個區域組成：

```
+------------------------------------------------------------+
|  Sysbar (AppHeader): brand | Tasks | Sync || 月詠 | Notify  |
+--------+------------------------------------------+--------+
|        |                                          |        |
| Left   |          Workspace (route content)       | 月詠   |
| rail   |                                          | (open) |
|        |                                          |        |
+--------+------------------------------------------+--------+
|  Footer (AppFooter): version | repo link                   |
+------------------------------------------------------------+
```

右側的月詠助手面板只在打開時出現；關閉時工作區延伸到視窗右邊緣。

### 1) 頂部 Sysbar（`AppHeader`） {#toolbar-guide-section-3}

chip 風格的狀態欄，從左到右：

- **側欄開關（`☰`）** — 展開 / 收起左欄圖標軌道。
- **品牌** — Logo + 應用名 + Moonlit Translator 副標題。
- **任務中心**
  - 閒置時是一個安靜的圖標「任務」。
  - 有章節任務執行時顯示執行數和整體進度條；同時有排隊項目時顯示執行數、排隊數和分段進度條（已完成 / 執行中 / 未開始）。
  - 只有助手對話等其他 AI 活動時顯示「AI 處理中」和脈衝圓點；佇列暫停時顯示「已暫停 · N 排隊」；一批任務結束後顯示完成與失敗數，直到開啟任務中心或清除已完成項目。
  - 新任務開始時 chip 只會閃動提示，不會自動彈出面板。
  - 只有背景向量化在執行時同樣顯示脈衝圓點，不計入執行數和進度條；向量化被暫停或因同步掛起時不顯示。
  - 點選開啟任務中心：章節任務依「進行中 / 排隊中 / 已完成」分組，點選任務項目查看詳情（思考、工具調用和輸出），可停止、重試、拖曳排序、暫停或繼續佇列；啟用本地嵌入時下方有「背景 · 向量化」區（見下文 [背景向量化](/help/toolbar-guide#toolbar-guide-section-10)），再下方「其他 AI 活動」列出助手對話、單段落任務等。可以固定成可移動、可調整大小的懸浮面板，或收起成迷你進度條。詳見 [任務佇列與任務中心](/help/book-details-translation#book-details-translation-section-9)。
- **同步狀態** — 圖標 + 狀態 chip，狀態見下表：

| 狀態       | 顯示                    | 說明                                                                         |
| :--------- | :---------------------- | :--------------------------------------------------------------------------- |
| 未啟用     | 雲圖標「同步」          | 未配置 Gist 或未開啟自動同步                                                 |
| 未同步     | 雲圖標「未同步」        | 已啟用但本地與遠端尚未對齊                                                   |
| 已同步     | 雲✓「已同步 · 5m / 2h」 | 顯示距下次同步的倒計時                                                       |
| 待同步變更 | ↑「N 項變更」           | 檢測到本地有未上傳的變更（含書籍 / AI 模型 / 封面 / 設定 / 記憶 / 刪除墓碑） |
| 同步中     | spinner「同步中」       | 正在執行 push / pull / merge                                                 |

點選打開「同步狀態」面板：顯示「最後同步時間」「下次同步時間」、「待同步變更」列表和「遠端資料」統計（書籍 / AI 模型數量）。同步進行中會顯示「整體進度」百分比與進度條，百分比只增不減；進度條下方是目前階段：「準備本機資料」/「下載中」/「上傳中」/「套用中」/「合併中」/「儲存同步狀態」。面板底部是「同步」按鈕；開啟「強制推送本機資料到遠端（覆寫遠端）」開關後，按鈕變為「強制推送到遠端」。未啟用 Gist 同步、同步進行中或正在恢復已刪除項目時按鈕不可用。

- **月詠** — 💬，位於分隔線之後，點選打開 / 關閉右側的月詠助手面板，面板打開時按鈕高亮。在 AI 匯入頁，匯入助手對話固定顯示，按鈕保持高亮、點選不會關閉它。
- **訊息紀錄** — 🔔，點選查看 toast 歷史；未讀角標超過 99 顯示 `99+`。可按嚴重程度篩選（錯誤 / 警告 / 成功 / 資訊），單條刪除或清空，部分操作支持撤銷。

視窗較窄時（Electron 沒有最小視窗寬度），系統欄依序收起文字：先隱藏品牌副標題，再隱藏同步倒計時，最後各按鈕只留圖標（任務中心改為只顯示執行 / 排隊數字），不會橫向溢出。

> **批量摘要按鈕已移除**（v0.12 起 AI 章節摘要功能撤回，由 `query_chapter` 工具按需檢索原文取代）。

### 2) 左欄圖標軌道（`AppSideMenu`） {#toolbar-guide-section-4}

預設是窄軌道，只顯示圖標；按 `☰` 展開成完整選單，展開後還會顯示「導覽」分組和「收藏小說」列表。

主要導航：

- 🏠 **首頁** — `/`
- 📚 **書籍列表** — `/books`
- 📥 **AI 匯入** — `/import`
- ✨ **AI 列表** — `/ai`
- 🔗 **外部 Agent** — `/mcp`

輔助導航（軌道底部）：

- ⚙️ **設定** — `/settings`
- ❓ **說明** — `/help`
- 📣 **回報問題** — 開啟 GitHub 的新增 Issue 頁面，並預先填入目前的版本號與執行環境（桌面版用系統瀏覽器開啟）

### 3) 右側助手面板（`AppRightPanelDesktop`） {#toolbar-guide-section-5}

右側不再常駐圖標欄。點選頂部系統欄的「月詠」按鈕打開助手面板：面板停靠在右側、擠窄工作區（不會蓋在內容上），可拖曳左邊緣調整寬度；面板上的關閉按鈕或再次點選「月詠」都會把它收起，收起後右側不佔任何寬度。

- 💬 **月詠（聊天助手）** — 對應 `AppChatPanelDesktop`，包含會話列表、訊息流、輸入區、上下文（書籍 / 章節 / 段落）、待辦、上下文用量進度條。月詠是應用內 AI 助手化身（月下學者人格）。
- 面板關閉時在閱讀頁對段落使用「複製原文至助手」或「解釋選取文字」，會自動打開面板並把內容填進輸入框。

> 在 AI 匯入頁（`/import`），右側固定顯示匯入助手對話面板，不能收起。

### 4) 底部 Footer（`AppFooter`） {#toolbar-guide-section-6}

顯示版本號與 GitHub 鏈接（GitHub 圖標）。Electron 桌面版會用同樣的 footer。

Electron 桌面版在版本號右側額外顯示**更新徽標**（v0.16.1 起，Web 版不顯示）：

- `latest`（✓）：已檢查且當前為最新版本；尚未完成檢查時不顯示。
- `vX.X.X · NN%`：發現新版本，正在背景下載。
- `vX.X.X available`：新版本已下載，點選即彈出確認，重新啟動並更新；若有任務或儲存未完成，會以提示說明原因。
- `updating…`：正在檢查任務與儲存狀態並準備重啟。

詳見 [設定說明 · 關於](/help/settings-guide)。

### 5) 月詠桌寵 {#toolbar-guide-desk-pet}

僅桌面端（含 Electron）：頁面右下角常駐一隻月詠桌寵，用現有的月詠頭像表示。任務中心或助手面板收合時，它在頭像上方的氣泡裡轉述翻譯、潤色、校對任務和助手回覆的進度，資料來自任務本身的紀錄，不額外呼叫 AI。平板與手機不顯示。

- **頭像狀態**：執行中外圈為薄藍色、呼吸發光並有轉動的弧線，月詠埋頭左右輕搖，角標是正在執行的任務數；任務結束後小結未查看時外圈變綠，月詠隔幾秒開心地蹦一下，角標為 ✓；有失敗時外圈變紅、搖搖頭，角標為失敗數；閒置時縮小變暗、點頭打瞌睡並飄出「zzz」，滑鼠移上去會醒來。系統開啟「減少動態效果」時所有動畫都停下，只保留顏色與角標。
- **點頭像**：任何狀態下點頭像都會打開右側助手面板，直接和月詠對話。
- **氣泡內容**：標題列是章節標題與段落進度（或「助手」），下面是最新一段活動，用標籤區分「思考」（思考文字的末尾）、「工具」（月詠口吻的一句話，小字附工具名與執行狀態）與「輸出」（譯文或回覆的末尾）。
- **收合與展開**：點氣泡右上角的箭頭切換。收合只顯示最新一段；展開顯示最近 8 段的小日誌，底部有「開啟任務中心」，有多個任務時可用 ‹ › 切換。收合 / 展開會被記住。
- **跟隨哪個任務**：助手（助手面板收合時）優先，其次是正在閱讀的章節，再其次是其他章節；目前任務結束才換，手動切換的任務保持到它結束。
- **讓位**：任務中心開啟（或固定面板展開）時不再轉述章節任務；右側已經有月詠時（助手面板打開，或在匯入頁）桌寵隱藏，收合面板或離開匯入頁後回來。
- **結果小結**：章節任務結束後顯示「「第 N 話」譯完了」或完成數與失敗數，助手回覆完成顯示「月詠答好了」與回覆開頭。點小結開啟任務中心（或助手面板），點「知道了」關閉；關閉章節小結會同時清除任務中心 chip 的完成提示，開啟任務中心也視為已查看。
- **閒置**：沒有任務時縮在右下角打盹，點擊打開助手面板。

在 **設定 → 一般設定 → 月詠桌寵** 中可以關閉。

## 📱 平板端佈局 {#toolbar-guide-section-7}

平板端（`tablet` 斷點）使用緊湊型 sysbar + 左側導航軌道，頁面右側沒有直向工具軌道，內容延伸到視窗右邊緣：

```
+--------------------------------------------------------+
|  TabletSysBar: [list] brand | Tasks | Sync || 月詠 | 🔔 |
+------+-------------------------------------------------+
| Nav  |                                                 |
| rail |           Workspace (route content)             |
|      |                                                 |
+------+-------------------------------------------------+
```

### Sysbar 結構 {#toolbar-guide-section-8}

- **左側**：書庫頁的「書籍列表」開關、書籍詳情頁的「目錄」開關（只在這兩個頁面出現，其他頁面不佔位置），然後是品牌名 + 目前版本號。直向寬度不夠時品牌文字以省略號截斷。
- **右側 chips**：任務中心 / 同步狀態，分隔線之後是月詠 / 通知 — 各項行為與桌面端一致，只是 chip 更緊湊，月詠只顯示圖標；同步 chip 顯示「同步」「同步中」「N 項變更」或「已同步」。任務中心同樣可以固定成懸浮面板。

### 導航與助手 {#toolbar-guide-section-9}

- **左側導航軌道**（`TabletNavRail`）：頂部 Logo（返回首頁），主導航為首頁 / 書庫 / AI 匯入 / AI 模型 / 外部 Agent，底部固定回報問題 / 說明 / 設定。
- **列表 / 目錄開關**：在頂部 sysbar 最左側。直向時列表或目錄以疊層打開，點選外側即可關閉，按鈕同步變為收合狀態；橫向時打開會擠窄內容區。
- **月詠**：所有平板頁面都能從頂部 sysbar 的「月詠」按鈕打開，面板從右側滑入，點選遮罩或再次點選按鈕關閉（遮罩不覆蓋頂部 sysbar）。AI 匯入頁橫向時匯入助手常駐停靠，按鈕保持高亮、點選無效；直向時按鈕照常開關從右側滑入的匯入助手。

### 背景向量化（任務中心） {#toolbar-guide-section-10}

向量化不再有單獨的按鈕或抽屜。本地嵌入實際可用時，任務中心在「其他 AI 活動」上方顯示「背景 · 向量化」區，三種佈局（桌面 / 平板的彈出層與固定面板、手機底部抽屜）內容一致；本地嵌入關閉時整個區不出現。

- **區頭**：待處理總數與「暫停向量化」/「繼續向量化」按鈕，點選標題可折疊（預設折疊，狀態會記住）。雲端同步期間顯示「同步中，稍後繼續」，同步結束後佇列自動繼續；同步期間點了暫停的，結束後保持暫停。
- **佇列行**：正在處理的類型與數量（「本書 章節 ×N」，處理別的書時顯示「其他書籍 · …」和該書書名）、剩餘時間；閒置時顯示「佇列閒置」或「待處理 N」。
- **舊版向量**：模型版本升級後有舊向量時顯示「舊版向量：N 個章節 / N 條記憶」，點「重建」加入佇列。
- **書籍詳情頁**：顯示目前書名、「補齊缺失」按鈕，以及「章節向量」「記憶向量」兩條「已嵌入 X / Y」進度。「⋯」選單裡有「重建本書章節向量」「測試向量查詢」「嵌入設定」。
- **其他頁面**：只顯示全域佇列狀態，並提示「開啟一本書後可補齊或重建該書的向量」。

模型後端（WebGPU / WASM）與模型版本在 **設定 → 本機嵌入** 的模型分組裡查看。

本地嵌入是否可用由**設備 UA** 判定（`isMobileDevice()`），與視窗寬度無關：手機、平板等行動裝置上始終停用；桌面瀏覽器縮窄到平板或手機寬度時，只要在**設定 → 本機嵌入**中開啟，仍可正常使用。詳見 [本地嵌入](/help/local-embedding)。

## 📲 移動端佈局 {#toolbar-guide-section-11}

移動端（`mobile` 斷點）使用極簡 sysbar + 主體內容 + 底部標籤列：

```
+----------------------------------------+
|  MobileSysBar:                         |
|  logo | Tasks | Sync | 🔔 | Help       |
+----------------------------------------+
|                                        |
|      Route content (full width)        |
|                                        |
+----------------------------------------+
|  MobileTabBar: Home | Library | Chat   |
|                AI | Settings           |
+----------------------------------------+
```

### Sysbar 結構 {#toolbar-guide-section-12}

- **左側**：Logo + 應用名 + 版本號。
- **右側 chips**：
  - 任務中心（有任務時顯示執行與排隊數；點選後以底部抽屜開啟，點選任務項目進入全螢幕詳情；手機上不能固定或收起）
  - 同步狀態（同步中 / 有變更 / 已同步時顯示「同步中」「N 項變更」「已同步」）
  - 通知
  - **說明**（移動端獨有 chip，直接跳到 `/help`）

> 移動端主導航在底部標籤列：首頁 / 書庫 / 月詠 / AI 模型 / 設定；月詠以底部抽屜打開，沒有左欄軌道。本地嵌入（含 `query_chapter` 的語意檢索）按設備 UA 判定，在手機等行動裝置上被停用，避免瀏覽器 WASM 記憶體上限觸發崩潰；桌面瀏覽器縮到手機寬度不受影響。

## 🔁 跨設備一致的狀態語義 {#toolbar-guide-section-13}

不論哪個變體，下列狀態來源都是同一份 `useSystemBar()`：

- 待同步變更數（含書籍 / AI 模型 / 封面 / 設定 / 記憶增刪改 / 墓碑刪除）。
- 距下次同步的倒計時（啟用自動同步時）。
- 任務中心狀態（執行 / 排隊數量、整體進度、暫停狀態）。
- 訊息紀錄未讀條數。

修改同步配置 / 主動觸發同步 / 暫停隊列 / 清空訊息紀錄等操作，會立即在三個變體的 sysbar 同步刷新。

## ❓ 常見問題 {#toolbar-guide-section-14}

**Q: 桌面端為什麼找不到「批量摘要」按鈕？**
A: 章節摘要功能已在 v0.12 移除。AI 現在通過 `query_chapter` 工具按需對原文做語義檢索，不再需要預生成摘要。

**Q: 「向量索引」按鈕去哪了？**
A: 向量化的進度與操作已併入頂部「任務中心」的「背景 · 向量化」區，任何頁面都能查看；補齊、重建與測試查詢需要先開啟對應的書。請先在**設定 → 本機嵌入**啟用功能；行動裝置上無法啟用。詳見 [本地嵌入](/help/local-embedding)。

**Q: 右側的圖標欄去哪了？**
A: 已移除。月詠助手改從頂部系統欄的「月詠」按鈕打開；平板書庫頁的書籍列表開關、書籍詳情頁的目錄開關移到了頂部 sysbar 最左側。

**Q: 同步按鈕一直顯示「同步中」？**
A: 檢查 Gist 配置、網路連通性與 Token 權限；點開 sysbar 上的訊息紀錄 🔔 查看具體錯誤紀錄。

**Q: 原來的「AI 思考」和「翻譯進度」入口去哪了？**
A: 兩者已合併為頂部的「任務中心」。點選任務中心裡的章節任務即可查看進度、思考與輸出；助手對話、單段落任務等在任務中心下方的「其他 AI 活動」中。

**Q: 任務中心為空？**
A: 目前可能沒有任務記錄或已被清除。開始任何翻譯、潤色、校對任務都會在這裡出現。

**Q: 平板端把視窗拉大後變成了桌面佈局，為什麼本地嵌入仍然灰顯？**
A: 物理移動設備的 UA 標識不會因視窗尺寸改變而消失。本地嵌入按 UA 判定（避免移動設備 WASM 崩潰），與視窗寬度無關。
