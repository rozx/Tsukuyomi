# 🛠️ 系統欄與導航 {#toolbar-guide-section-1}

Tsukuyomi 在不同設備上採用不同的系統欄（System Bar）佈局，但功能集合一致：**導航 / AI 思考 / 同步 / 訊息 / 右欄面板**。本文按設備變體逐一說明各欄的位置與入口。

> v0.12.1 起桌面端整體遷移到工作台（Workbench）語言，左/右欄改成圖標軌道、聊天與翻譯進度獨立面板、批量嵌入面板從頂欄改放到右欄；平板與移動端繼續沿用 chip-based sysbar。功能本身沒有刪減。

---

## 🖥️ 桌面端佈局 {#toolbar-guide-section-2}

桌面端（`useResponsiveLayout` 判定為 `desktop` 或 Electron 強制 desktop）由四個區域組成：

```
+------------------------------------------------------------+
|  Sysbar (AppHeader): brand | AI | Sync | Notifications     |
+--------+------------------------------------------+--------+
|        |                                          |        |
| Left   |          Workspace (route content)       | Right  |
| rail   |                                          | rail   |
|        |                                          |        |
+--------+------------------------------------------+--------+
|  Footer (AppFooter): version | repo link                   |
+------------------------------------------------------------+
```

### 1) 頂部 Sysbar（`AppHeader`） {#toolbar-guide-section-3}

chip 風格的狀態欄，從左到右：

- **側欄開關（`☰`）** — 展開 / 收起左欄圖標軌道。
- **品牌** — Logo + 應用名 + Moonlit Translator 副標題。
- **AI 思考過程**
  - 圖標 ✨，無任務時顯示「AI 思考」。
  - 有任務時變為 pill 狀態，顯示「AI 思考中 / 處理中」並載入動畫點。
  - 點選打開思考面板：進行中任務（模型 / 類型 / 狀態 / 用時）、思考訊息、最近完成 10 條、停止 / 清空操作。
- **同步狀態** — 圖標 + 狀態 chip，狀態見下表：

| 狀態       | 顯示                    | 說明                                                                         |
| :--------- | :---------------------- | :--------------------------------------------------------------------------- |
| 未啟用     | 雲圖標「同步」          | 未配置 Gist 或未開啟自動同步                                                 |
| 未同步     | 雲圖標「未同步」        | 已啟用但本地與遠端尚未對齊                                                   |
| 已同步     | 雲✓「已同步 · 5m / 2h」 | 顯示距下次同步的倒計時                                                       |
| 待同步變更 | ↑「N 項變更」           | 檢測到本地有未上傳的變更（含書籍 / AI 模型 / 封面 / 設定 / 記憶 / 刪除墓碑） |
| 同步中     | spinner「同步中」       | 正在執行 push / pull / merge                                                 |

點選進入同步面板：上傳 / 下載 / 詳情，可看最後同步時間、下次同步時間、遠端統計、階段百分比。下載按鈕在未啟用、同步中、缺 Gist ID 時不可用。

- **訊息歷史** — 🔔，點選查看 toast 歷史；未讀角標超過 99 顯示 `99+`。可按嚴重程度篩選（錯誤 / 警告 / 成功 / 資訊），單條刪除或清空，部分操作支持撤銷。

> **批量摘要按鈕已移除**（v0.12 起 AI 章節摘要功能撤回，由 `query_chapter` 工具按需檢索原文取代）。

### 2) 左欄圖標軌道（`AppSideMenu`） {#toolbar-guide-section-4}

預設是窄軌道，只顯示圖標；滑鼠懸停或按 `☰` 展開成完整菜單。

主要導航：

- 🏠 **首頁** — `/`
- 📚 **書籍列表** — `/books`
- ✨ **AI列表** — `/ai`

輔助導航（軌道底部）：

- ⚙️ **設定** — `/settings`
- ❓ **幫助** — `/help`

### 3) 右欄圖標軌道（`AppRightPanelDesktop`） {#toolbar-guide-section-5}

固定寬度 + 拖曳 resize 手柄；展開後顯示當前激活面板。軌道入口：

- 💬 **月詠（聊天助手）** — 對應 `AppChatPanelDesktop`，包含會話列表、訊息流、輸入區、上下文（書籍 / 章節 / 段落）、待辦、上下文用量進度條。月詠是應用內 AI 助手化身（月下學者人格）。
- 📊 **翻譯進度** — 對應 `AppProgressPanelDesktop`，顯示翻譯 / 潤色 / 校對任務進度條；活躍任務數量以 tab 數字角標顯示，開始新任務時面板自動切到該任務，可在面板內取消。
- 🧬 **向量索引**（僅書籍詳情頁路由顯示） — 打開 `BatchEmbeddingsPanel` 抽屜，查看本書章節 / 記憶嵌入統計（已嵌入 / 總數 / stale）、批量重算、測試查詢、暫停 / 繼續。**依賴本地嵌入開啟**，詳見 [本地嵌入](/help/local-embedding)。

> 切換軌道入口會自動激活對應面板；未激活面板**不掛載**任何 watcher，避免跨面板的副作用。

### 4) 底部 Footer（`AppFooter`） {#toolbar-guide-section-6}

顯示版本號與 GitHub 鏈接（GitHub 圖標）。Electron 桌面版會用同樣的 footer。

Electron 桌面版在版本號右側額外顯示**更新徽標**（v0.16.1 起，Web 版不顯示）：

- `latest`（✓）：已檢查且當前為最新版本；尚未完成檢查時不顯示。
- `vX.X.X · NN%`：發現新版本，正在背景下載。
- `vX.X.X available`：新版本已下載，點選即彈出確認，重啟並更新；若有任務或儲存未完成，會以提示說明原因。
- `updating…`：正在檢查任務與儲存狀態並準備重啟。

詳見 [設定說明 · 關於](/help/settings-guide)。

## 📱 平板端佈局 {#toolbar-guide-section-7}

平板端（`tablet` 斷點）使用緊湊型 sysbar：

```
+--------------------------------------------------------+
|  TabletSysBar: brand | version | AI | Sync | Notify    |
+--------------------------------------------------------+
|                                                        |
|              Workspace (route content)                 |
|                                                        |
+--------------------------------------------------------+
```

### Sysbar 結構 {#toolbar-guide-section-8}

- **左側**：品牌名 + 版本號（`v0.12.1`）。
- **右側 chips**：AI 思考過程 / 同步狀態 / 訊息歷史 — 各項行為與桌面端一致，只是 chip 文字更緊湊（如「AI 思考中 → AI 思考過程」，「N 項變更 / 已同步 / 同步中」）。

### 導航與右欄 {#toolbar-guide-section-9}

- 主導航走 Quasar 抽屜（點選 sysbar 左側的菜單圖標），包含首頁 / 書籍 / AI / 設定 / 幫助。
- 右欄由獨立的「聊天 / 進度」開關控制（路由進入書籍詳情頁時按需展開），交互細節與桌面端一致，只是沒有圖標軌道。

### 關於本地嵌入入口 {#toolbar-guide-section-10}

平板端**沒有**專用的「向量索引」按鈕：物理移動設備 UA 會強制鎖住本地嵌入；如果是桌面瀏覽器縮到平板寬度，則可以在**設定 → 本地嵌入**配置開關，但批量嵌入抽屜僅在桌面佈局下渲染。

## 📲 移動端佈局 {#toolbar-guide-section-11}

移動端（`mobile` 斷點）使用極簡 sysbar + 主體內容：

```
+----------------------------------+
|  MobileSysBar:                   |
|  logo | AI | Sync | Help         |
+----------------------------------+
|                                  |
|     Route content (full width)   |
|                                  |
+----------------------------------+
```

### Sysbar 結構 {#toolbar-guide-section-12}

- **左側**：Logo + 應用名 + 版本號。
- **右側 chips**：
  - AI 思考過程
  - 同步狀態
  - 訊息歷史
  - **幫助**（移動端獨有 chip，直接跳到 `/help`）

> 移動端導航主要靠主頁快捷入口、底部抽屜與路由 push；沒有左欄軌道。`useResponsiveLayout()` 判定為 `mobile` 時，本地嵌入功能（含 `query_chapter` 工具）會被禁用，避免瀏覽器 WASM 記憶體上限觸發崩潰。

## 🔁 跨設備一致的狀態語義 {#toolbar-guide-section-13}

不論哪個變體，下列狀態來源都是同一份 `useSystemBar()`：

- 待同步變更數（含書籍 / AI 模型 / 封面 / 設定 / 記憶增刪改 / 墓碑刪除）。
- 距下次同步的倒計時（啟用自動同步時）。
- 當前 AI 任務標籤（思考中 / 處理中 / 等）。
- 訊息歷史未讀條數。

修改同步配置 / 主動觸發同步 / 暫停隊列 / 清空訊息歷史等操作，會立即在三個變體的 sysbar 同步刷新。

## ❓ 常見問題 {#toolbar-guide-section-14}

**Q: 桌面端為什麼找不到「批量摘要」按鈕？**
A: 章節摘要功能已在 v0.12 移除。AI 現在通過 `query_chapter` 工具按需對原文做語義檢索，不再需要預生成摘要。

**Q: 桌面端右欄的「向量索引」按鈕去哪了？**
A: 該按鈕僅在書籍詳情頁路由（`/books/:id` 及其子路由）下出現，且依賴本地嵌入開啟。請先在**設定 → 本地嵌入**啟用功能；詳見 [本地嵌入](/help/local-embedding)。

**Q: 同步按鈕一直顯示「同步中」？**
A: 檢查 Gist 配置、網路連通性與 Token 權限；點開 sysbar 上的訊息歷史 🔔 查看具體錯誤紀錄。

**Q: AI 思考面板為空？**
A: 當前可能沒有任務記錄或已被清空。開始任何翻譯 / 潤色 / 校對任務都會留下記錄。

**Q: 平板端把視窗拉大後變成了桌面佈局，為什麼本地嵌入仍然灰顯？**
A: 物理移動設備的 UA 標識不會因視窗尺寸改變而消失。本地嵌入按 UA 判定（避免移動設備 WASM 崩潰），與視窗寬度無關。
