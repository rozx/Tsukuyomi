# 🛠️ 系統欄與導航 {#toolbar-guide-section-1}

Tsukuyomi 在不同設備上採用不同的系統欄（System Bar）佈局，但功能集合一致：**導航 / AI 思考 / 同步 / 訊息 / 右欄面板 / 向量索引**。本文按設備變體逐一說明各欄的位置與入口。

> v0.12.1 起桌面端整體遷移到工作台（Workbench）語言，左/右欄改成圖標軌道、聊天與翻譯進度獨立面板；平板與移動端繼續沿用 chip-based sysbar。「向量索引」入口在三種佈局下都可用：桌面右欄、平板書籍詳情頁側軌、手機頂部 sysbar。

---

## 🖥️ 桌面端佈局 {#toolbar-guide-section-2}

桌面端（`useResponsiveLayout` 判定為 `desktop` 或 Electron 強制 desktop）由四個區域組成：

```
+------------------------------------------------------------+
|  Sysbar (AppHeader): brand | AI | Sync | Notifications     |
+--------+------------------------------------------+--------+
|        |                                          |        |
| Left   |          Workspace (route content)       | Right  |
| rail   |                                          | rail   |
|        |                                          |        |
+--------+------------------------------------------+--------+
|  Footer (AppFooter): version | repo link                   |
+------------------------------------------------------------+
```

### 1) 頂部 Sysbar（`AppHeader`） {#toolbar-guide-section-3}

chip 風格的狀態欄，從左到右：

- **側欄開關（`☰`）** — 展開 / 收起左欄圖標軌道。
- **品牌** — Logo + 應用名 + Moonlit Translator 副標題。
- **AI 思考過程**
  - 圖標 ✨，無任務時顯示「AI 思考」。
  - 有任務時變為 pill 狀態，顯示「AI 思考中」或「AI 處理中」並帶脈衝圓點。
  - 點選打開思考面板：進行中任務（模型 / 類型 / 狀態 / 用時）、思考訊息、最近完成 10 條、停止 / 清空操作。
- **同步狀態** — 圖標 + 狀態 chip，狀態見下表：

| 狀態       | 顯示                    | 說明                                                                         |
| :--------- | :---------------------- | :--------------------------------------------------------------------------- |
| 未啟用     | 雲圖標「同步」          | 未配置 Gist 或未開啟自動同步                                                 |
| 未同步     | 雲圖標「未同步」        | 已啟用但本地與遠端尚未對齊                                                   |
| 已同步     | 雲✓「已同步 · 5m / 2h」 | 顯示距下次同步的倒計時                                                       |
| 待同步變更 | ↑「N 項變更」           | 檢測到本地有未上傳的變更（含書籍 / AI 模型 / 封面 / 設定 / 記憶 / 刪除墓碑） |
| 同步中     | spinner「同步中」       | 正在執行 push / pull / merge                                                 |

點選打開「同步狀態」面板：顯示「最後同步時間」「下次同步時間」、「待同步變更」列表和「遠端資料」統計（書籍 / AI 模型數量）。同步進行中會顯示「整體進度」百分比與進度條，百分比只增不減；進度條下方是目前階段：「準備本機資料」/「下載中」/「上傳中」/「套用中」/「合併中」/「儲存同步狀態」。面板底部是「同步」按鈕；開啟「強制推送本機資料到遠端（覆寫遠端）」開關後，按鈕變為「強制推送到遠端」。未啟用 Gist 同步、同步進行中或正在恢復已刪除項目時按鈕不可用。

- **訊息紀錄** — 🔔，點選查看 toast 歷史；未讀角標超過 99 顯示 `99+`。可按嚴重程度篩選（錯誤 / 警告 / 成功 / 資訊），單條刪除或清空，部分操作支持撤銷。

> **批量摘要按鈕已移除**（v0.12 起 AI 章節摘要功能撤回，由 `query_chapter` 工具按需檢索原文取代）。

### 2) 左欄圖標軌道（`AppSideMenu`） {#toolbar-guide-section-4}

預設是窄軌道，只顯示圖標；按 `☰` 展開成完整選單，展開後還會顯示「導覽」分組和「收藏小說」列表。

主要導航：

- 🏠 **首頁** — `/`
- 📚 **書籍列表** — `/books`
- 📥 **AI 匯入** — `/import`
- ✨ **AI 列表** — `/ai`

輔助導航（軌道底部）：

- ⚙️ **設定** — `/settings`
- ❓ **說明** — `/help`

### 3) 右欄圖標軌道（`AppRightPanelDesktop`） {#toolbar-guide-section-5}

右欄收起時是一條圖標軌道；點選入口會展開對應面板（寬度可拖曳調整），面板上的關閉按鈕會把它收回軌道。軌道入口：

- 💬 **月詠（聊天助手）** — 對應 `AppChatPanelDesktop`，包含會話列表、訊息流、輸入區、上下文（書籍 / 章節 / 段落）、待辦、上下文用量進度條。月詠是應用內 AI 助手化身（月下學者人格）。
- 📊 **翻譯進度** — 對應 `AppProgressPanelDesktop`，顯示翻譯 / 潤色 / 校對任務進度條；活躍任務數量以數字角標顯示，開始新任務時面板自動切到該任務，可在面板內取消。
- ⚡ **向量索引**（僅書籍詳情頁，且本地嵌入實際可用時顯示） — 打開「本機向量索引」面板，詳見下文 [關於本地嵌入入口](/help/toolbar-guide#toolbar-guide-section-10)。

> 切換軌道入口會自動激活對應面板；未激活面板**不掛載**任何 watcher，避免跨面板的副作用。在 AI 匯入頁（`/import`），右欄固定顯示匯入助手對話面板。

### 4) 底部 Footer（`AppFooter`） {#toolbar-guide-section-6}

顯示版本號與 GitHub 鏈接（GitHub 圖標）。Electron 桌面版會用同樣的 footer。

Electron 桌面版在版本號右側額外顯示**更新徽標**（v0.16.1 起，Web 版不顯示）：

- `latest`（✓）：已檢查且當前為最新版本；尚未完成檢查時不顯示。
- `vX.X.X · NN%`：發現新版本，正在背景下載。
- `vX.X.X available`：新版本已下載，點選即彈出確認，重新啟動並更新；若有任務或儲存未完成，會以提示說明原因。
- `updating…`：正在檢查任務與儲存狀態並準備重啟。

詳見 [設定說明 · 關於](/help/settings-guide)。

## 📱 平板端佈局 {#toolbar-guide-section-7}

平板端（`tablet` 斷點）使用緊湊型 sysbar + 左側導航軌道；書籍列表與書籍詳情頁右側另有直向工具軌道：

```
+--------------------------------------------------------+
|  TabletSysBar: brand | version | AI | Sync | Notify    |
+------+------------------------------------------+------+
| Nav  |                                          | Side |
| rail |        Workspace (route content)         | rail |
|      |                                          |      |
+------+------------------------------------------+------+
```

### Sysbar 結構 {#toolbar-guide-section-8}

- **左側**：品牌名 + 目前版本號。
- **右側 chips**：AI 思考過程 / 同步狀態 / 通知 — 各項行為與桌面端一致，只是 chip 更緊湊：閒置時顯示「AI 思考過程」，有任務時顯示「AI 思考中」；同步 chip 顯示「同步」「同步中」「N 項變更」或「已同步」。

### 導航與右欄 {#toolbar-guide-section-9}

- **左側導航軌道**（`TabletNavRail`）：頂部 Logo（返回首頁），主導航為首頁 / 書庫 / AI 匯入 / AI 模型，底部固定說明 / 設定。
- **右側工具軌道**（`TabletSideRail`，書籍列表與書籍詳情頁）：列表 / 目錄開關、月詠、翻譯進度（帶任務數角標）；書籍詳情頁在本地嵌入可用時還會顯示「向量索引」按鈕。
- 月詠與翻譯進度以浮層面板從右側滑入，點選遮罩即可關閉，交互細節與桌面端一致。

### 關於本地嵌入入口 {#toolbar-guide-section-10}

「向量索引」按鈕在三種佈局下都有入口，只在**書籍詳情頁**（`/books/:id` 及其子路由）且本地嵌入**實際可用**時顯示：

- 桌面：右欄圖標軌道（⚡）。
- 平板：書籍詳情頁右側工具軌道。
- 手機：頂部 sysbar 最左側的 chip。

點選打開「本機向量索引」面板。面板只在主佈局中掛載一份：桌面與平板以右側抽屜打開，手機以底部抽屜打開；視窗斷點切換時面板保持打開，切換到另一本書或本地嵌入變為不可用時自動關閉。面板內容：

- 頂部狀態：「就緒」/「模型載入中」/「載入失敗」/「未就緒」/「已停用」。
- 「章節向量」：「已嵌入 X / Y」、待處理數量與進度條，提供「補齊缺失」和「全部重算」。
- 「記憶向量」：同樣顯示嵌入進度，提供「補齊缺失」。
- 偵測到舊版向量時顯示「Embedding 空間已升級」橫幅，可點「立即重建」。
- 「測試向量查詢」：用自然語言檢索本書章節或記憶。
- 底部顯示模型、後端與隊列狀態，可「暫停」/「恢復」嵌入隊列。

本地嵌入是否可用由**設備 UA** 判定（`isMobileDevice()`），與視窗寬度無關：手機、平板等行動裝置上始終停用；桌面瀏覽器縮窄到平板或手機寬度時，只要在**設定 → 本機嵌入**中開啟，仍可正常使用。詳見 [本地嵌入](/help/local-embedding)。

## 📲 移動端佈局 {#toolbar-guide-section-11}

移動端（`mobile` 斷點）使用極簡 sysbar + 主體內容 + 底部標籤列：

```
+----------------------------------------+
|  MobileSysBar:                         |
|  logo | Vectors | AI | Sync | 🔔 | Help |
+----------------------------------------+
|                                        |
|      Route content (full width)        |
|                                        |
+----------------------------------------+
|  MobileTabBar: Home | Library | Chat   |
|                AI | Settings           |
+----------------------------------------+
```

### Sysbar 結構 {#toolbar-guide-section-12}

- **左側**：Logo + 應用名 + 版本號。
- **右側 chips**：
  - **向量索引**（⚡，僅書籍詳情頁且本地嵌入可用時顯示，打開底部抽屜）
  - AI 思考過程（有任務時顯示「AI 思考中」）
  - 同步狀態（同步中 / 有變更 / 已同步時顯示「同步中」「N 項變更」「已同步」）
  - 通知
  - **說明**（移動端獨有 chip，直接跳到 `/help`）

> 移動端主導航在底部標籤列：首頁 / 書庫 / 月詠 / AI 模型 / 設定；月詠與翻譯進度以底部抽屜打開，沒有左欄軌道。本地嵌入（含 `query_chapter` 的語意檢索）按設備 UA 判定，在手機等行動裝置上被停用，避免瀏覽器 WASM 記憶體上限觸發崩潰；桌面瀏覽器縮到手機寬度不受影響。

## 🔁 跨設備一致的狀態語義 {#toolbar-guide-section-13}

不論哪個變體，下列狀態來源都是同一份 `useSystemBar()`：

- 待同步變更數（含書籍 / AI 模型 / 封面 / 設定 / 記憶增刪改 / 墓碑刪除）。
- 距下次同步的倒計時（啟用自動同步時）。
- 當前 AI 任務標籤（思考中 / 處理中 / 等）。
- 訊息紀錄未讀條數。

修改同步配置 / 主動觸發同步 / 暫停隊列 / 清空訊息紀錄等操作，會立即在三個變體的 sysbar 同步刷新。

## ❓ 常見問題 {#toolbar-guide-section-14}

**Q: 桌面端為什麼找不到「批量摘要」按鈕？**
A: 章節摘要功能已在 v0.12 移除。AI 現在通過 `query_chapter` 工具按需對原文做語義檢索，不再需要預生成摘要。

**Q: 「向量索引」按鈕去哪了？**
A: 該按鈕僅在書籍詳情頁路由（`/books/:id` 及其子路由）下出現，且依賴本地嵌入實際可用：桌面在右欄軌道，平板在書籍詳情頁右側工具軌道，手機在頂部 sysbar。請先在**設定 → 本機嵌入**啟用功能；行動裝置上無法啟用。詳見 [本地嵌入](/help/local-embedding)。

**Q: 同步按鈕一直顯示「同步中」？**
A: 檢查 Gist 配置、網路連通性與 Token 權限；點開 sysbar 上的訊息紀錄 🔔 查看具體錯誤紀錄。

**Q: AI 思考面板為空？**
A: 當前可能沒有任務記錄或已被清空。開始任何翻譯 / 潤色 / 校對任務都會留下記錄。

**Q: 平板端把視窗拉大後變成了桌面佈局，為什麼本地嵌入仍然灰顯？**
A: 物理移動設備的 UA 標識不會因視窗尺寸改變而消失。本地嵌入按 UA 判定（避免移動設備 WASM 崩潰），與視窗寬度無關。
