# 📥 AI 匯入工作台 {#import-guide-section-1}

把小說網址或檔案交給月詠，告訴她要匯入哪些內容。她會讀取正文、整理卷章，你檢查後再把小說放進書庫。

整個過程是：**添加來源 → 與月詠對話 → 檢查草稿 → 確認匯入**。看到「可預覽」時，小說還沒有進入書庫；完成最後的「確認匯入」才會寫入。

## 開始前 {#import-guide-section-2}

先在 [AI 模型配置](/help/ai-models-guide) 中，為「助手」指定預設模型。匯入工作台使用這個模型與月詠對話、整理小說。

然後打開「AI 匯入」（路由 `/import`）：

| 設備 | 入口                                                                            |
| :--- | :------------------------------------------------------------------------------ |
| 桌面 | 左側圖標欄「AI 匯入」                                                           |
| 平板 | 左側圖標欄「AI 匯入」，任務列表在工作台的「任務」標籤頁中                       |
| 手機 | 側邊菜單「AI 匯入」，打開任務後預設進入「對話」；底部欄「月詠」按鈕也可切回對話 |

桌面和平板的月詠對話在右側，工作區中間有「來源」「卷章草稿」「匯入方案」。手機對應的分區叫「來源」「草稿」「方案」。下文使用桌面的名稱。

## 第一次使用：把一本 EPUB 匯入書庫 {#import-guide-section-3}

手邊有一本 EPUB 時，可以照著下面走一遍。網址、TXT 和 Markdown 的具體說法見後面的例子。

### 1. 新建任務，添加檔案 {#import-guide-section-4}

點選「新任務」；空白頁面上也可以點「新建匯入任務」。一個任務整理一本小說，同一本書的多個檔案可以放在一起。

切到「來源」，在「添加來源」區域點「選擇檔案」，選中 EPUB；也可以直接把檔案拖進這個區域。添加成功後，來源會顯示「尚未讀取」，這是正常狀態。發送需求後，月詠才開始讀取。

### 2. 告訴月詠要做什麼 {#import-guide-section-5}

在對話中發送，例如：

> 請把這個 EPUB 匯入為一本新小說。按書中的目錄分卷分章，保留序言和後記。整理好後告訴我有沒有缺章。

接下來，對話里會出現讀取來源、提取正文、整理草稿等操作。月詠識別出書名後會給任務命名；你也可以直接修改頂部的任務名稱，手動起的名稱會保留。

如果月詠問「這幾個檔案屬於哪一本書」或讓你選擇作品，在對話里回答後她才會繼續。暫時想停下來，可以點任務頂部的「暫停」。

### 3. 檢查書名、目錄和正文 {#import-guide-section-6}

等本輪整理完成，打開「卷章草稿」。建議按下面的順序檢查：

1. 在「基本資訊」看書名、作者、簡介和標籤是否正確；「匯入到」應是「新建小說」。這些字段可以直接修改。
2. 如果下面出現「元資訊候選」，先核對內容，再點「採用」。這裡的元資訊就是作者、簡介、封面、標籤等書籍資料。
3. 查看卷章標題和順序。章節前的勾選框決定是否匯入；不需要的內容可以取消勾選，標題可直接編輯，也可以上移、下移或移到其他卷。
4. 點選章節旁的眼睛圖標「檢查正文」。至少抽查第一章、中間一章和最後一章，確認開頭、結尾都在，正文沒有混入目錄或導航文字。長章節可點「顯示更多」繼續查看。

發現問題時，可以直接在對話里說明，例如：

> 第二卷的第 3 章開頭混進了目錄。請檢查這一章，把目錄去掉，保留正文。其他章節先不要改。

月詠會讀取你已經做過的草稿修改。若同時修改導致版本衝突，重新載入最新草稿後再繼續。

### 4. 生成匯入方案 {#import-guide-section-7}

打開「匯入方案」，點「生成匯入方案」。如果月詠已經生成過，直接檢查即可。月詠仍在運行或等待回答時，需要先等本輪結束、暫停，或回答問題。

方案會列出這次將寫入書庫的內容。重點看：

- 頂部是「新建《書名》」還是「更新《書名》」，目標是否正確。
- 有多少章將匯入，是否標著「部分匯入」，缺失範圍是否符合預期。
- 新增、修訂、移動和刪除段落的數量是否合理。
- 更新已有小說時，會不會清空譯文，以及會清空多少個版本。

如果顯示「待處理」，按下方提示選擇章節對應關係或確認替換。若生成方案後又改了草稿，會顯示「已過時」，點「重新生成」後再檢查。目標小說有了新修改時，也需要重新生成方案。

### 5. 確認並打開小說 {#import-guide-section-8}

方案顯示「可以匯入」後，點「確認匯入」。彈出的「確認匯入到書庫」視窗會再次列出目標書籍、章數和譯文影響；核對後，再點一次「確認匯入」。

看到「已匯入」後，點「打開小說」即可進入書籍詳情，開始閱讀或翻譯。

新書的目標語言在真正確認寫入時取當前介面語言，不取任務開始或方案預覽時的語言。更新已有書籍保持其原目標。之後可在書籍翻譯設定中改為簡中、繁中或英文；原文不限語言，同一本書可包含多種語言。

## 換一種來源時，可以這樣操作 {#import-guide-section-9}

### 從小說網站匯入 {#import-guide-section-10}

在「來源」里粘貼小說目錄網址，點「添加網址」。網址只支持 http／https，也可以添加單章頁面。然後發送：

> 請匯入這個目錄里的第一卷，按網站順序排列。先不要匯入第二卷。整理後列出沒有取得正文的章節。

月詠會檢查目錄並抽查章節，再批量提取。同一批最多 500 章；章節更多時需要分批處理。目錄里發現的章節鏈接會顯示為「月詠發現」的來源，無需逐章手動粘貼。

需要登錄、人機驗證或完全依賴腳本顯示正文的網站，可能無法讀取。此時把缺失章節儲存為檔案，添加到同一個任務，再告訴月詠檔案對應哪幾章。已取得的正文會保留。

### 把整本 TXT 拆成章節 {#import-guide-section-11}

添加 TXT 後，告訴月詠檔案中的標題長什麼樣。例如標題是獨立一行的「第一章 出發」，可以發送：

> 這份 TXT 是一本完整小說。請按獨立一行的「第一章 出發」這類標題拆章，章名保留完整標題。開頭的簡介和序言先單獨列出來，供我選擇是否匯入。

月詠會預覽拆章結果，再整理到草稿。檢查時留意章數、重復標題、空章，以及第一章之前的內容。尚未歸類的內容會保留為預設未勾選的草稿章，想保留序言時記得勾選。

標題規則複雜時，可以給出幾行真實示例，讓月詠調整匹配規則；也支持正則表達式。每次拆章最多處理 500 章。

### 按 Markdown 標題分卷分章 {#import-guide-section-12}

添加 Markdown 檔案後，可以發送：

> 一級標題是卷名，二級標題是章名。請按這個層級整理，保留章節中的正文和段落順序。

拆章會識別 Markdown 標題層級，忽略程式碼塊里的類似標題。卷標題的層級需要比章標題更高，例如一級為卷、二級為章。

### 匯入多個檔案或整個資料夾 {#import-guide-section-13}

點選「選擇檔案」可一次多選。出現「選擇資料夾」按鈕時，也可以一次添加整個資料夾；沒有這個按鈕時用多選檔案即可。HTML 檔案也可以作為來源。

添加後說明這些檔案的關係，例如：

> 這些檔案都是同一本書，檔案名開頭的數字是章節順序。請合成一本新小說。無法確定順序的章節先問我。

如果裡面混有多部作品，需要先選定本任務處理哪一本，再繼續整理。其他擴展名的檔案也會嘗試按內容解析，能否讀取以處理結果為準。

## 繼續整理草稿 {#import-guide-section-14}

### 去掉雜質、統一章名 {#import-guide-section-15}

在對話里說清處理範圍和要改的內容，例如：

> 刪除第一卷每章中單獨一行的「返回目錄」，其他文字保持原樣。

> 去掉已選章節標題末尾的「某某小說網」，保留章節編號和章名。

正文清理支持刪除匹配片段或整行，卷章標題支持批量替換。月詠會先查看預覽中的命中數量和前後示例，再應用到草稿；每批最多 500 項。可以在對話的操作詳情中核對結果。正文清理用於去除來源里的雜質，不會生成新的小說正文。

如果草稿在預覽後發生變化，需要重新預覽。整理完後還要重新生成匯入方案，才會按新草稿匯入。

### 補作者、簡介、封面和標籤 {#import-guide-section-16}

書名、作者、簡介和標籤可以在「基本資訊」中直接填寫。輸入標籤後按回車添加，重復項和首尾空白會自動清理。網站或 EPUB 中的標籤也可以提取到候選中。

需要月詠聯網查資料時，在 [設定](/help/settings-guide) 配置 Tavily API Key，或保持預設開啟的 Firecrawl 回退（無需 Key），再發送：

> 請查找這本書的作者、簡介和封面，列出出處供我核對。

月詠找到的資訊會顯示在「元資訊候選」中，點「採用」才進入草稿；有「匯入時寫入書庫」選項的字段，還可以選擇是否寫入。沒配置搜索也可以繼續匯入正文，資料手動填寫即可。

搜索只補書籍資料，不會替你尋找缺章正文。需要使用某個網頁的正文時，請把該網址添加到「來源」。

### 刪除來源、刪除草稿的區別 {#import-guide-section-17}

刪除來源會一並移除它派生出的來源入口，但已經生成的草稿章節和已儲存的正文引用仍會保留。若還要繼續抓取這個來源，需要重新添加。

只是不想匯入某章，可以取消它前面的勾選。確定要從草稿移除時，用章節旁的「刪除草稿章節」；要重新整理整本書，可用「清空卷章」。這些操作修改的是本任務的草稿。

## 給書庫里已有的小說補章 {#import-guide-section-18}

添加新章節的網址或檔案，在「卷章草稿 → 基本資訊 → 匯入到」中選擇已有小說，再告訴月詠要補什麼。例如：

> 這些檔案是書庫中《書名》的第 11～15 章。請補到這本書里，檢查有沒有重復章節，原有章節保留。

月詠也可能給出目標小說建議，需要你點「採用建議」。出現「確認更新這本小說」或章節匹配提示時，先核對書名和章節對應關係。

生成方案後，尤其要檢查「新建」還是「更新」以及譯文影響。更新遵循以下規則：

- 原文不變的段落保留所有語言的譯文與選用，移到其他章節時也一樣。
- 原文修訂的段落會清空該段所有語言的譯文版本與選用，方案會列出受影響的完整版本數量。
- 新來源沒有包含的舊章節會保留，不會因為這次沒提供而被刪除。

例如，只提供第 11～15 章時，原有第 1～10 章會保留。如果某章原文確實修訂，先查看變化再決定是否匯入。

### 先匯入成功的部分 {#import-guide-section-19}

有幾章讀不到時，可以告訴月詠：

> 先整理已經成功取得的章節，列出缺失章節。這次我只匯入成功的部分。

方案會標記「部分匯入」，說明已取得的範圍和缺失章節；目錄總數尚未覈實時也會說明完整性未確認。核對範圍後可以確認匯入。

之後把缺失檔案補進同一個任務，說明對應章節，再檢查目標仍是同一本小說。補齊時，已匹配且未變化的章節不會重復匯入，已有譯文也會保留。

## 網站連載有新章時，怎麼繼續更新 {#import-guide-section-20}

網站匯入中出現的「更新配方」，記錄的是這本書的目錄地址、正文位置和清理方式。儲存後，下次可以直接在書籍詳情的「檢查更新」里查看新章，不必重新整理整本書。

例如，這次從網站匯入了前 20 章。之後網站發佈第 21 章，就打開書籍詳情的「檢查更新」，檢查並選擇新章，再確認應用。具體操作見 [章節管理與檢查更新](/help/book-details-chapters)。

### 匯入前看「更新配方」的狀態 {#import-guide-section-21}

月詠會用本任務已經儲存的目錄頁和章節頁試讀，確認這套方法能得到與草稿一致的正文。這裡的「自測」使用已儲存頁面，不會重新訪問網站。

- 顯示「新增」或「替換」：確認匯入時會一起儲存配方。「可復現」表示已經驗證過的章節數。
- 顯示「保留原有」：繼續使用書籍之前的配方。
- 顯示「已失效」：先看原因。可以讓月詠按當前草稿修正，再重新生成方案；也可以只匯入章節，這次不寫入失效配方，原有配方保持不變。

比如生成配方後，又從草稿中刪掉了每章末尾的導航文字，原來的提取方式可能與草稿不一致。可以告訴月詠：

> 我剛清理了每章末尾的導航文字，請把同樣的清理規則記入更新配方，重新自測並生成方案。

有配方的目錄中，已進入草稿但被取消勾選的章節會記為「已跳過」，以後檢查更新不再把它們當作新章；從未進入草稿的目錄章節不會因此被跳過。儲存配方時，目錄地址也會放到書籍來源網址的第一位。

### 需要重建或修復配方時 {#import-guide-section-22}

在書籍的「檢查更新」里點「用 AI 匯入器建立配方」或「用 AI 匯入器修復配方」。工作台會打開這本書未完成的修復任務，沒有則新建，並填好目標書籍、目錄來源和問題說明。

檢查輸入框里的說明後發送，月詠才開始處理。修復後仍要檢查方案並確認匯入；即使沒有新章，也可以只更新配方。

### 哪些來源不能這樣更新 {#import-guide-section-23}

配方要求網站目錄與匯入章節一一對應。把一張網頁拆成多章、把多章合在一起，或整卷正文都放在一頁的來源，無法生成這種配方。少數有意手工修改的章節可以保留為「固定正文」，最多佔 20%。

小説家になろう、カクヨム、ハーメルン等內置站點會使用站點目錄規則，正文仍按本次匯入方式驗證。撤銷匯入時，配方和來源網址也會一起恢復。

## 暫停、繼續和撤銷 {#import-guide-section-24}

### 下次再整理 {#import-guide-section-25}

點選任務頂部的「暫停」，等待狀態變為「已暫停」，已完成的提取和草稿修改會保留。回來後在任務列表打開原任務，點「繼續整理」或「繼續執行」，也可以直接發送新的要求。

刷新或關閉頁面後，任務不會自動運行，也不會自動匯入。來源、草稿、對話和待回答的問題儲存在當前設備，匯入工作台需要保持打開才能執行，不能在另一台設備續跑。任務本身不參與雲同步，確認匯入後的書籍可以正常同步。

執行檢查點儲存啟動時的介面語言，暫停、重啟後繼續以及壓縮續跑沿用該語言；舊檢查點未儲存語言時按簡中恢復。介面切換只影響新執行，匯入最終新建書籍的目標仍按真正寫入時的介面語言決定。

同一時間只運行一個匯入任務，其他標籤頁也共用這個限制。切到另一個任務時，如果提示已有任務運行，先暫停原任務。

長對話接近模型上下文視窗時會自動壓縮：保留最近的對話，較早部分合併為摘要；有待執行的工具調用時不會壓縮。也可點對話標題欄的「壓縮對話上下文」按鈕手動總結全部可總結內容。已儲存的來源和草稿不靠聊天記錄儲存。

### 匯入後撤銷 {#import-guide-section-26}

打開原任務的「匯入方案」，在底部「匯入記錄」找到這次操作，點「撤銷」，再在對話框中確認「撤銷匯入」。

- 如果這次新建了小說，撤銷會刪除該小說及正文。
- 如果這次更新了小說，撤銷會恢復匯入前的資料、卷章、原文、所有語言譯文及選用。

開始新的翻譯、編輯、同步下載或再次匯入後，書籍已有後續修改，就不能整次撤銷；只打開查看不影響。書籍已刪除或記錄已撤銷時也不可用，介面會顯示原因。

刪除匯入任務會清除來源、對話、提取結果和撤銷記錄，已匯入的小說仍在書庫，但之後不能再通過該任務撤銷。

## 遇到這些提示時 {#import-guide-section-27}

| 看到的情況                     | 下一步                                                                                                                   |
| :----------------------------- | :----------------------------------------------------------------------------------------------------------------------- |
| 來源顯示「尚未讀取」           | 在對話中發送匯入要求，或點「繼續整理」。添加來源後不會立即讀取。                                                         |
| 顯示「已檢查」，還沒有正文     | 月詠已檢查頁面或檔案結構，繼續整理才會提取章節。                                                                         |
| 顯示「已提取」                 | 內容已經儲存；到「卷章草稿」檢查章數、順序和正文，再生成方案。                                                           |
| 來源顯示「已排除」             | 該來源不參與本次匯入。若仍需要它，在對話中說明要使用哪份來源。                                                           |
| 「處理失敗」或章節「提取失敗」 | 查看錯誤原因。臨時讀取失敗可以讓月詠只重試失敗章節；登錄或驗證頁面請改為補充檔案。                                       |
| 「等待回答」                   | 到對話區回答月詠的問題，回答後才會繼續。                                                                                 |
| 「可預覽」，書庫卻找不到小說   | 打開「匯入方案」，生成或檢查方案，再點「確認匯入」。                                                                     |
| 「完整性未確認」               | 已發現的章數不一定是全書總數。讓月詠繼續核對目錄，或按部分匯入檢查並確認。                                               |
| 「確認匯入」不可用             | 先看方案頂部提示：等待整理結束、回答問題、處理待處理項，或為過時方案點「重新生成」。顯示「無變化」則沒有需要寫入的內容。 |
| 目標小說正忙                   | 等該書的翻譯、潤色、校對或助手寫入結束。即使已點停止，也要等收尾儲存完成，再重試匯入或撤銷。                             |
| 提示存儲失敗                   | 先按錯誤提示恢復存儲；恢復前不要關閉頁面，最新進度可能尚未儲存。                                                         |
| 資料庫升級被其他頁面阻塞       | 關閉其他打開本應用的標籤頁，再刷新。                                                                                     |

匯入或撤銷寫入期間，同一本書的新翻譯任務會暫時無法開始，完成後即可繼續；其他書籍和只讀操作不受影響。

瀏覽器需要支持跨標籤頁鎖（Web Locks），否則無法運行匯入、確認匯入或撤銷。桌面應用使用同一資料目錄時只允許一個實例，再次啟動會切回已有視窗。

檔案超過處理上限時，請拆成較小檔案後添加。缺少背景線程的環境會使用更低的處理上限；超限會明確報錯，不會把截斷正文當作完整結果。
