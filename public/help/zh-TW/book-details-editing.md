# ✏️ 內容編輯與搜索替換 {#book-details-editing-section-1}

本頁說明章節內容區的編輯行為、段落操作和快捷鍵（以當前實現為準）。

> **關於長章節性能**：章節內容區採用**虛擬滾動**——只渲染當前可視視窗內的段落，配套**自定義滾動條**。數百上千段的長章節滾動、編輯、搜索都保持流暢，記憶體佔用與章節長度解耦。正在編輯的段落即使滾出可視區域，未儲存草稿也會被暫存，滾回來不會丟失。

## 🧭 三種編輯模式 {#book-details-editing-section-2}

可在章節工具欄切換：

1. **原文編輯**（鉛筆圖標）
2. **翻譯模式**（語言圖標）
3. **譯文預覽**（眼睛圖標）

預設模式為**翻譯模式**。

## 📝 原文編輯模式 {#book-details-editing-section-3}

### 進入方式 {#book-details-editing-section-4}

- 點選工具欄「原文編輯」按鈕後，自動進入整章原文編輯狀態。

### 編輯與儲存 {#book-details-editing-section-5}

- 章節原文在一個大文本框中編輯。
- 點選**儲存**後，系統會按換行重新生成段落。

段落處理規則（當前實現）：

- 新文本按行拆分為段落；
- 與原段落同索引位置比較：
  - 文本未變：保留該段所有語言的翻譯與選用；
  - 文本變更：清空該段所有語言的翻譯與選用；
- 新增行會生成新段落（無翻譯）；
- 被移除的舊段落隨之移除。

### 一鍵格式化（去除多餘空行） {#book-details-editing-section-6}

原文編輯工具欄提供**「格式化」按鈕**，用於清理從網頁 / PDF 粘貼進來的原文里堆積的多餘空行：

- **減一行規則**：每段連續空行減少一行（2 個空行 → 1 個、6 個 → 5 個），保留段落間的相對間距，大段留白不會被壓扁成單空行；
- **首尾空行整段去掉**；
- **識別全角空格**：僅含全角空格（U+3000）的"看不見的空行"也會被當作空行清理；
- **防連按**：編輯框記住上次格式化結果，連按兩次不會過度刪除；
- **可撤銷**：格式化後可用 `Ctrl+Z` 撤銷回格式化前的內容。

> 格式化只整理空行，不改動正文行內容（不動行首縮進 / 行尾空格）。

### 取消編輯 {#book-details-editing-section-7}

- 點選**取消**，放棄本次原文修改並回到翻譯模式。
- 章節切換時，如仍在原文編輯，狀態會被重置。

## 🌐 翻譯模式（段落級編輯） {#book-details-editing-section-8}

### 基本交互 {#book-details-editing-section-9}

- 每段顯示原文與書籍當前目標語言的選用譯文；缺譯文時回退原文，不借用其他語言；
- 可直接編輯當前目標譯文；表單打開後若書籍目標已改變，應重新打開再儲存，避免跨語言寫入；
- 回車儲存，Shift+Enter 換行，Esc 取消本次編輯；
- 段落可顯示術語/角色高亮。

### 段落右鍵菜單 {#book-details-editing-section-10}

右鍵段落可打開上下文菜單，包含：

- 解釋選中文本（僅當段落原文有選中內容時顯示）
- 校對段落
- 潤色段落
- 重新翻譯
- 複製原文到助手
- 翻譯歷史（僅當該段存在歷史版本時顯示）

### 翻譯歷史 {#book-details-editing-section-11}

- 歷史對話框最多顯示最近 5 條版本；
- 可從歷史中切換當前使用版本。

版本帶語言歸屬。其他語言歷史可供查看，不能選入當前目標槽；選擇、編輯、刪除只影響所屬語言。切換書籍目標後恢復該語言自己的選用。複製、搜索替換及章節匯出使用當前目標選用，缺失處保留原文；英文譯文不強制改為中文標點，原文回退也不執行譯文規範化。

## 👁️ 譯文預覽模式 {#book-details-editing-section-12}

- 以閱讀視圖顯示譯文為主；
- 未翻譯段會顯示「未翻譯」標記並展示原文；
- 適合快速通讀與審閱。

## 🔍 搜索與替換 {#book-details-editing-section-13}

### 打開與關閉 {#book-details-editing-section-14}

- `Ctrl+F`：打開/關閉搜索欄；
- `Ctrl+H`：打開或切換替換區域；
- `Esc`：關閉搜索欄（搜索欄打開時）。

### 搜索 {#book-details-editing-section-15}

- 在搜索框中輸入後會定位匹配段落；
- `F3` / `Shift+F3` 或按鈕可在匹配項間切換。

### 替換 {#book-details-editing-section-16}

- 可替換當前匹配或全部匹配；
- 替換基於“原始譯文文本”執行（不是顯示層格式化後的文本）；
- 進行“全部取代”時會記錄復原點，可用撤銷恢復。

## ↩️ 撤銷 / 重做 {#book-details-editing-section-17}

- `Ctrl+Z`：撤銷（非輸入框場景）
- `Ctrl+Y` 或 `Ctrl+Shift+Z`：重做（非輸入框場景）

當前實現限制：

- 歷史最多保留 50 條；
- 切換章節會清空當前章節編輯歷史。

## ⌨️ 章節頁常用快捷鍵 {#book-details-editing-section-18}

| 快捷鍵                | 功能                           |
| --------------------- | ------------------------------ |
| `Ctrl+F`              | 打開/關閉搜索                  |
| `Ctrl+H`              | 打開/關閉替換區域              |
| `F3`                  | 下一個匹配（搜索打開時）       |
| `Shift+F3`            | 上一個匹配（搜索打開時）       |
| `Esc`                 | 關閉搜索欄（搜索打開時）       |
| `Ctrl+Shift+C`        | 複製當前章節所有已翻譯文本     |
| `Ctrl+Z`              | 撤銷（非輸入框）               |
| `Ctrl+Y/Ctrl+Shift+Z` | 重做（非輸入框）               |
| `↑/↓`                 | 翻譯模式下段落導航（跳過空段） |
| `Enter`               | 翻譯模式下開始編輯選中段落     |

說明：

- 段落方向鍵導航僅在**翻譯模式**生效；
- 若焦點在輸入框中，大部分全域快捷鍵不會接管；
- 部分彈層（如下拉/菜單/對話框）中會保留方向鍵預設行為。
