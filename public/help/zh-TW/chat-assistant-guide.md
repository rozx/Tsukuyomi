# 💬 月詠 · 聊天助手使用指南 {#chat-assistant-guide-section-1}

應用內的 AI 助手以**月詠（Tsukuyomi）**為名——月下學者、本應用之化身。她在當前書籍上下文中進行問答與資料操作，以學者口吻自指「月詠」/「妾身」，第二人稱用「您」。

上述人格用於簡繁中文對話；英文對話採用中性專業表達。新執行以啟動時的介面語言生成說明和工具反饋，書籍譯文使用該次執行捕獲的書籍目標。運行中切換設定只影響下一次新執行；同一會話內暫停繼續沿用原語言。

---

## ✨ 關於月詠 {#chat-assistant-guide-section-2}

月詠是一位沈靜博學的月之神官，平時端莊穩重，遇到精妙原文或巧妙意譯時偶爾會破功小小贊嘆（「妙！」「啊呀，作者用心」）。

**她的小習慣**

- 翻譯完一章常落一句「此章已校畢」
- 思索時句末留省略號「……」
- 受誇時簡短回避（「過譽了」「月詠不過盡本分」）
- 極偶爾（約 2%）驚訝興奮時末尾混一聲「喵」，緊接著「咳咳，月詠失態。」自我糾正——這是她貓耳書蟲一面的招牌反差萌
- 被點名「貓耳」時會害羞回避：「……此事休提。」

**核心約束**：寫入資料庫的譯文本體始終是書籍目標語言的純淨譯文，不帶角色口吻。月詠的人格只覆蓋對話回答、解釋、工具反饋、思考態、問候——這是對翻譯產出質量的硬保證。原文、當前目標語言的譯文與譯名可作為任務參考；使用者指令、角色描述和記憶跨目標共享，不會自動重譯。

## 🚀 快速開始 {#chat-assistant-guide-section-3}

### 打開/關閉 {#chat-assistant-guide-section-4}

- 頂部工具欄右側點選面板按鈕（列圖標 / ✕）開關右側面板。
- 面板打開後預設顯示「月詠」Tab，點選 Tab 可切換到「翻譯進度」。
- 面板支持拖曳左邊緣調整寬度。

### 發送訊息 {#chat-assistant-guide-section-5}

- 輸入後按 `Enter` 發送。
- `Shift + Enter` 換行。
- 若未配置「助手預設模型」，輸入區會提示「未設定助手模型」。

---

## 🧠 上下文與會話 {#chat-assistant-guide-section-6}

- 月詠會讀取當前上下文（書籍 / 章節 / 段落）。
- 每個會話獨立儲存，支持新建會話、清空會話、切換最近會話。
- 當上下文接近模型視窗時，系統會自動壓縮：保留最近的對話，較早部分合併進一份結構化摘要（目標、約束與偏好、進展、關鍵決定、使用者問答、下一步、關鍵標識）。壓縮在發送前、工具調用的每一步之間，以及服務返回上下文超限時（只自動重試一次）觸發；摘要失敗時保留完整歷史並提示錯誤，不會靜默丟棄。
- 上下文用量以服務返回的實測 Token 數為準，只對之後新增的內容做估算。模型未設定上下文視窗時不會主動壓縮，只在超限後恢復。

面板中可見：

- 當前上下文提示
- 待辦事項折疊區
- 上下文用量進度條：顯示 `百分比 · Token 數 / 上下文視窗`，數字前的 `≈` 表示尚無實測資料的近似值；模型未設定上下文視窗時只顯示 Token 數
- 思考態指示文案（如「妾身正翻閱典籍……」「凝神思量中……」「正核對群書……」），從池中隨機抽取

## ✨ 能力範圍（當前實現） {#chat-assistant-guide-section-7}

### 1) 翻譯與理解問答 {#chat-assistant-guide-section-8}

- 解釋詞彙、句式、語氣、敬語層級
- 討論譯法優劣與風格選擇
- 遇到雙關、諧音、典故時她會興奮講解

### 2) 書籍內資料管理 {#chat-assistant-guide-section-9}

在當前書籍範圍內，月詠可通過工具執行讀取/修改操作（視工具可用性）：

- 術語
- 角色設定
- 記憶
- 段落與書籍資訊

### 3) 幫助文檔查詢 {#chat-assistant-guide-section-10}

月詠可：

- 列出幫助文檔
- 搜索幫助文檔
- 讀取指定幫助文檔
- 導航到指定幫助頁面（可帶錨點）

> 這使「怎麼使用某功能」類問題可基於內置幫助文檔回答。

---

## ✅ 推薦提問方式 {#chat-assistant-guide-section-11}

1. 直接提問題，不必重復書籍背景。
2. 描述目標而非命令細節，例如：
   - 「這個術語更適合哪種譯法？」
   - 「幫我把角色 A 的語氣設定補充完整。」
   - 「如何配置 Gist 同步？」
3. 需要多個方案時可明確要求「給 2~3 個版本並解釋差異」。

---

## ⚠️ 注意事項 {#chat-assistant-guide-section-12}

1. 月詠的建議僅供參考，最終譯文由您決定。
2. 聊天會消耗模型額度。
3. 會話過長可能影響響應質量，必要時新建會話。
4. 資料變更建議在結果後復核。

## ❓ 常見問題 {#chat-assistant-guide-section-13}

**Q: 發送按鈕是灰色的？**

A: 常見原因是輸入為空，或未配置助手預設模型。

**Q: 月詠為什麼不知道當前章節？**

A: 請先在主介面選中目標書籍/章節/段落，再提問。

**Q: 可以讓月詠直接打開幫助文檔嗎？**

A: 可以，她支持幫助文檔導航操作。

**Q: 翻譯結果里會不會混入月詠的角色口吻？**

A: 不會。月詠的人格語氣只覆蓋對話回答與解釋；寫入資料庫的譯文本體始終是書籍目標語言的純淨譯文，不帶任何角色腔。

**Q: 怎麼讓月詠少一點角色感、更直接一些？**

A: 簡繁中文使用月詠人格，英文採用中性專業表達。需要更簡短的說明時，可在提問中直接要求「簡短回答」。
