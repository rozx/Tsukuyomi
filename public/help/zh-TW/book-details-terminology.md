# 術語管理 {#book-details-terminology-section-1}

術語管理功能幫助您維護專有名詞、人名、地名等的翻譯一致性，確保整本書的翻譯質量。

## 📚 什麼是術語庫 {#book-details-terminology-section-2}

術語庫是書籍特定的專有名詞翻譯對照表，包括：

**常見術語類型**：

- 👤 **人名**: 角色名稱的翻譯
- 🗺️ **地名**: 地點、國家、城市等
- 📦 **專有名詞**: 組織名稱、技能名稱、物品名稱等
- 💡 **特殊概念**: 世界觀相關的特定術語
- 🎌 **文化詞彙**: 特定文化背景的詞彙

## 📋 術語的結構 {#book-details-terminology-section-3}

每個術語包含以下資訊：

- 📝 **名稱**: 原文中的術語（必填）
- 🔄 **翻譯**: 當前書籍目標語言的譯名
- 📄 **描述**: 額外的說明資訊（可選）

簡中、繁中、英文譯名分別儲存。切換目標後顯示對應譯名，沒有時保持空白，不借用另一語言或原名；原名仍在名稱字段顯示。儲存空譯名只清空當前槽，保留實體與其他語言。打開編輯後若目標改變，請重新打開表單。描述跨目標共享，不自動翻譯。

## 🚪 訪問術語管理面板 {#book-details-terminology-section-4}

**操作步驟**：

1. 📑 在書籍詳情頁的左側邊欄
2. ⚙️ 找到"設定菜單"區域
3. 🖱️ 點選"術語設定"按鈕
4. 📋 右側會顯示術語管理面板

**面板佈局**：

- 🛠️ **頂部工具欄**: 添加術語、批量操作、匯入/匯出、搜索

- 📇 **術語列表**: 顯示所有術語的卡片
- 📄 **術語詳情**: 點選術語查看和編輯詳細資訊

## 添加術語 {#book-details-terminology-section-5}

### 手動添加 {#book-details-terminology-section-6}

**操作步驟**：

1. 在術語管理面板
2. 點選"添加術語"按鈕
3. 在彈出的對話框中填寫：
   - **名稱**: 原文中的術語（必填）
   - **翻譯**: 對應的翻譯
   - **描述**: 額外的說明資訊（可選）
4. 點選"儲存"按鈕

**填寫建議**：

- **名稱準確**: 必須與原文完全一致
- **翻譯統一**: 使用規範的翻譯
- **描述詳細**: 添加必要的說明，如讀音、含義等

### 使用翻譯功能 {#book-details-terminology-section-7}

在術語編輯對話框中：

- 名稱輸入框右側有翻譯按鈕
- 點選可以自動翻譯術語
- 翻譯結果會填入"翻譯"字段

## 編輯術語 {#book-details-terminology-section-8}

### 修改術語資訊 {#book-details-terminology-section-9}

**操作步驟**：

1. 在術語列表中找到要編輯的術語
2. 點選術語卡片
3. 在彈出的對話框中修改資訊
4. 點選"儲存"按鈕

### 修改影響 {#book-details-terminology-section-10}

**術語修改後**：

- 修改不會自動更新已翻譯的內容
- 新的翻譯會使用更新後的術語
- 建議使用搜索替換功能更新舊譯文

**更新已翻譯內容**：

1. 修改術語後
2. 使用章節的搜索替換功能
3. 搜索舊譯文，替換為新譯文
4. 或者重新翻譯相關章節

## 刪除術語 {#book-details-terminology-section-11}

**操作步驟**：

1. 在術語列表中找到要刪除的術語
2. 點選術語卡片旁的"刪除"按鈕
3. 在確認對話框中確認刪除

**刪除影響**：

- 刪除操作可在短時間內通過右下角通知撤銷，過期後不可恢復
- 已翻譯的內容不會自動更改
- AI 翻譯時不再使用該術語

刪除整個術語作用於所有語言，書內刪除記錄長期保留並優先於遲到離線編輯。明確撤銷會恢復可見內容並生成新身份，保留舊身份刪除記錄，避免後續同步再次刪除恢復項。

## 批量操作 {#book-details-terminology-section-12}

### 批量刪除 {#book-details-terminology-section-13}

**操作步驟**：

1.  點選工具欄的"批量"按鈕進入批量模式
2.  勾選要刪除的術語（支持全選）
3.  點選"刪除"按鈕
4.  在確認對話框中確認
5.  點選"取消"按鈕退出批量模式

## 匯入與匯出 {#book-details-terminology-section-14}

### 匯出術語 {#book-details-terminology-section-15}

- 點選工具欄的"匯出"按鈕
- 將當前術語庫匯出為 JSON 檔案
- 用於備份或遷移

### 匯入術語 {#book-details-terminology-section-16}

- 點選工具欄的"匯入"按鈕
- 支持 JSON 或 TXT 格式的檔案（內容需為 JSON）
- 支持兩種格式：
  1. **完整格式**: 匯出的標準術語數組
  2. **簡化格式**: 鍵值對對象 `{"術語名": "翻譯", "術語名2": "翻譯2"}`
- 系統會自動合併新舊術語

## 術語搜索 {#book-details-terminology-section-17}

### 快速查找術語 {#book-details-terminology-section-18}

**操作步驟**：

1. 在術語面板頂部找到搜索框
2. 輸入搜索關鍵詞
3. 列表會實時過濾顯示匹配的術語

**搜索範圍**：

- 名稱
- 翻譯
- 描述

**搜索技巧**：

- 支持模糊搜索
- 不區分大小寫
- 可以搜索部分關鍵詞

## 術語在翻譯中的應用 {#book-details-terminology-section-19}

### AI 自動應用 {#book-details-terminology-section-20}

**翻譯時**：

- AI 會自動檢測原文中的術語
- 使用術語庫中的譯文替換
- 保持翻譯的一致性

**智能填充**：

- **名稱**：必填項
- **翻譯**：留空時，AI 會在翻譯章節的過程中自動填充建議的譯名
- **描述**：留空時，AI 會根據上下文自動補充術語描述
- AI 也會根據需要自動建立、更新或刪除術語以優化翻譯質量

**應用優先級**：

1. 完全匹配優先
2. 長術語優先（避免衝突）
3. 最近添加的術語優先

### 術語的作用 {#book-details-terminology-section-21}

**名稱翻譯**：

- 統一使用設定的譯名
- 確保同一名詞翻譯一致
- 避免翻譯過程中的混亂

**上下文理解**：

- 描述字段幫助 AI 理解術語含義
- 更準確地處理術語相關內容

## 最佳實踐 {#book-details-terminology-section-22}

### 建立術語庫的時機 {#book-details-terminology-section-23}

**推薦流程**：

1. **匯入書籍後立即建立**: 先建立基本的術語庫
2. **翻譯前完善**: 在開始翻譯第一章前，盡可能完善術語庫
3. **翻譯中補充**: 翻譯過程中發現新術語及時添加
4. **定期審核**: 定期檢查和更新術語庫

### 術語命名規範 {#book-details-terminology-section-24}

**統一風格**：

- 人名統一使用"姓·名"或"名 姓"格式
- 地名統一使用官方譯名或音譯
- 技能名稱統一使用"XX術"或"XX之XX"格式

**避免衝突**：

- 一個原文在每個目標語言內使用一致譯名
- 不同原文不要使用相同譯文
- 使用描述區分相似術語
- **與角色名互斥**（v0.13.0 起）：術語名不得與本書任何角色的主名或別名相同，新增 / 編輯時若發生衝突會被拒絕並提示——避免翻譯時同一字串既被當作術語又被當作人名

### 術語的優先級 {#book-details-terminology-section-25}

**重要性排序**：

1. **核心角色**: 主角、重要配角的名字
2. **關鍵地點**: 主要場景、重要地標
3. **核心概念**: 世界觀相關的重要術語
4. **常用技能**: 頻繁出現的技能或魔法
5. **其他術語**: 次要角色、一般物品等

**建議**：

1. 先完善高優先級的術語
2. 低優先級術語可以在翻譯中逐步添加

### 術語質量控制 {#book-details-terminology-section-26}

**定期審核**：

1. 每完成一卷後審核術語庫
2. 檢查術語的一致性
3. 修正錯誤或不當的翻譯

### 術語與角色設定的區別 {#book-details-terminology-section-27}

**術語庫**：

- 存儲所有專有名詞
- 只包含名稱和翻譯
- 可選的描述資訊

**角色設定**：

- 專門管理人物資訊
- 包含性別、說話口吻等詳細資訊
- 支持別名管理

**建議**：

- 地名、物品、組織等放入術語庫
- 需要人物背景和說話口吻的名稱放入角色設定，不以相同原名重復建立術語
- 角色設定提供更豐富的上下文

## 常見問題 {#book-details-terminology-section-28}

### 為什麼 AI 翻譯時沒有使用術語庫？ {#book-details-terminology-section-29}

1. 檢查術語的原文是否完全匹配
2. 確認術語庫已儲存
3. 嘗試重新翻譯該段落
4. 檢查 AI 模型是否支持術語庫

### 如何處理一詞多義的術語？ {#book-details-terminology-section-30}

1. 在描述中說明使用場景
2. 考慮使用章節特殊指令區分
3. 人工翻譯時根據上下文選擇

### 術語太多會影響性能嗎？ {#book-details-terminology-section-31}

- 一般不會影響性能
- 系統會智能快取常用術語
- 建議控制在 1000 個術語以內
- 定期清理不再使用的術語

### 如何批量修改術語？ {#book-details-terminology-section-32}

目前支持**批量刪除**。如果需要批量修改內容：

1.  點選"匯出"按鈕備份資料
2.  修改匯出的 JSON 檔案
3.  重新"匯入"並覆蓋

### 翻譯字段應該留空還是填寫？ {#book-details-terminology-section-33}

- **留空**: AI 翻譯時會自動添加翻譯
- **填寫**: 確保使用你指定的翻譯

建議對於重要術語填寫明確的翻譯，次要術語可以留空讓 AI 自動填充。
