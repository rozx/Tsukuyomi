# 🏠 書籍庫與主頁（Library & Home） {#library-guide-section-1}

主頁（路由 `/`）是 Tsukuyomi 的工作台首頁，用於總覽項目狀態並快速進入常用流程。所有資料預設存儲在瀏覽器 **IndexedDB**，可選 GitHub Gist 同步。

介面初始語言匹配系統，可在 **設定 → 通用設定** 更改並同步。新書在真正建立時以當前介面語言初始化目標；已有書籍的目標獨立儲存在書籍翻譯設定中。

> v0.12.1 起，主頁桌面端改用工作台（Workbench）語言：「繼續閱讀」hero + 緊湊型指標條 + 快捷操作；平板端為 hero 卡 + 5 項 stat 網格 + 最近編輯；移動端保持單列 stat + 最近編輯 + 快捷操作。下文按設備變體逐個說明。

---

## 🖥️ 桌面端 {#library-guide-section-2}

桌面端主頁由四個區塊組成：

```
+--------------------------------------------------------+
|  DesktopWorkbenchHeader (title + metrics)              |
+--------------------------------------------------------+
|  Continue Reading hero (most recent book)              |
+--------------------------------------------------------+
|  Quick actions (4 cards)                               |
+--------------------------------------------------------+
|  Recently edited (6 cards)                             |
+--------------------------------------------------------+
```

### 1) 工作台 Header + Metrics {#library-guide-section-3}

頂部頭部使用統一的 `DesktopWorkbenchHeader`，與書籍列表 / AI 模型 / 設定等其他工作頁視覺對齊：

- 標題：「歡迎回來」（無任務時）/「工作台正在運行」（有 AI 任務時）。
- 副標題：上次停留的書籍提示（若有），以及當前是否有進行中任務的狀態。
- **Metrics 條**（`DesktopWorkbenchMetrics`）：5 項關鍵指標，從左到右：

| Metric  | 含義                         |
| :------ | :--------------------------- |
| 📚 書籍 | 當前書籍總數                 |
| 📑 章節 | 全部書籍章節總數             |
| 📝 字數 | 章節內容字數總和（異步計算） |
| 🏷️ 術語 | 術語庫條目總數               |
| ⭐ 收藏 | 收藏書籍數                   |

### 2) 繼續閱讀 Hero {#library-guide-section-4}

最近正在翻譯 / 閱讀的書籍以大封面卡形式置頂，包含：

- **Eyebrow**：`Continue Reading`。
- **狀態**：「正在翻譯」（pill + 載入點）/「更新於 YYYY-M-D」（無任務時）。
- **標題 + 作者**。
- **統計**：章節數、字數（異步載入時顯示骨架）、收藏標記（如已收藏）。
- **主 CTA**：進入書籍詳情頁（繼續翻譯 / 查看進度）。
- **次 CTA**：「打開書庫」回到 `/books`。

無書籍時（首次啟動或全部刪除後）hero 不顯示，只保留 Metrics + 快捷操作。

### 3) 快捷操作 {#library-guide-section-5}

4 張卡片（響應式網格）：

| 卡片              | 行為                                                                                                                                                         |
| :---------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ➕ **添加書籍**   | 彈出 BookDialog 手動建立：標題、作者、簡介、標籤、封面、別名、Web URL、書籍級特殊指令                                                                        |
| 🌐 **從網站匯入** | 進入同步工作區 — 內置支持 `ncode.syosetu.com`、`novel18.syosetu.com`、`kakuyomu.jp`、`syosetu.org`，其他網站可交給 AI 匯入器；支持章節勾選、跳過與目標卷選擇 |
| 📚 **打開書庫**   | 跳轉到書籍列表頁 `/books`                                                                                                                                    |
| 🤖 **AI 設定**    | 跳轉到 AI 模型管理頁 `/ai`，配置可用模型與任務路由                                                                                                           |

### 4) 最近編輯 {#library-guide-section-6}

按 `lastEdited` 倒序展示最近 **6 本**書籍卡片：

- 封面、標題、作者、章節數、字數。
- 點選任一卡片進入書籍詳情頁。
- 任何寫操作（編輯章節、生成翻譯、修改術語等）都會更新 `lastEdited`，自動上浮到前列。

## 📱 平板端 {#library-guide-section-7}

平板端主頁採用 hero + 緊湊指標 + 操作 + 最近列表的卡片化佈局：

### Hero 雙卡 {#library-guide-section-8}

- 上次停留的書籍以**繼續閱讀卡**呈現：標題、作者、章節數 + 「更新於 X」副線、CTA「繼續翻譯」。
- 若有進行中 AI 任務，旁邊再疊一張**正在翻譯卡**：spinner + 「正在翻譯」狀態、CTA「查看進度」。
- 無書籍時 hero 區域省略。

### 5 項 Stat 網格 {#library-guide-section-9}

緊湊橫排 5 個指標，**與桌面端 Metrics 同源**，但用更大圖標 + 數值的卡片樣式：

- 📚 總書籍 · 📑 總章節 · 📝 總字數 · 🏷️ 術語 · ⭐ 收藏

### 最近編輯 {#library-guide-section-10}

與桌面端相同的最近 6 本書邏輯，使用平板尺寸的卡片排版。

### 快捷操作 {#library-guide-section-11}

繼續保留「添加書籍 / 從網站匯入 / 打開書庫 / AI 設定」4 個入口，但在卡片底部條狀排布，節省垂直空間。

## 📲 移動端 {#library-guide-section-12}

移動端主頁採用單列卡片堆疊，照顧窄屏滾動：

```
+----------------------+
|  Stat grid (2x2)     |
|  Books / Chapters    |
|  Words / Starred     |
+----------------------+
|  Recently edited     |
|  (single-column)     |
+----------------------+
|  Quick actions       |
|  + Add book          |
|  + Import from URL   |
+----------------------+
```

### Stat 網格（4 項） {#library-guide-section-13}

移動端不顯示「術語」指標（窄屏空間優先），保留：

- 📚 書籍 · 📑 章節 · 📝 字數 · ⭐ 收藏

### 最近編輯 {#library-guide-section-14}

最近 6 本書的單列卡片列表，一屏滾 2-3 張，封面縮略圖 + 標題 + 作者。

### 快捷操作 {#library-guide-section-15}

移動端只保留兩個核心入口：

- ➕ **添加書籍**（PrimeVue primary）
- 🌐 **從網站匯入**（outlined）

如需訪問書庫 / AI 設定 / 設定頁，請使用頂部 sysbar 的導航或主菜單抽屜。

> 移動端會強制禁用本地嵌入功能（避免 WASM 記憶體崩潰）。AI 翻譯、術語 / 角色 / 記憶等核心功能完全可用，但「按語義自動注入記憶」「`query_chapter` 檢索原文」等語義功能會自動降級為關鍵詞 + 時間衰減。

## 🔄 資料備份與同步 {#library-guide-section-16}

不論哪個變體，主頁都不直接管理同步：

- **手動備份**：在**設定 → 匯入/匯出**點選「匯出資料」生成 `tsukuyomi-settings-YYYY-MM-DD.json`。
- **GitHub Gist 同步**：在**設定 → 資料同步**配置 Gist Token 與 ID 即可啟用，狀態顯示在頂部 sysbar 的「同步」chip 上（詳見 [系統欄與導航](/help/toolbar-guide)）。

## 📚 路由速查 {#library-guide-section-17}

| 路徑                                              | 說明                           |
| :------------------------------------------------ | :----------------------------- |
| `/`                                               | 主頁（本指南）                 |
| `/books`                                          | 書籍列表頁                     |
| `/books/:id`                                      | 書籍詳情頁（預設進入翻譯模式） |
| `/books/:id/settings/(terms\|characters\|memory)` | 書籍詳情頁中切到對應設定面板   |
| `/ai`                                             | AI 模型管理                    |
| `/settings`                                       | 應用設定                       |
| `/help/:docId?`                                   | 幫助頁（本檔案即來自此處）     |

> 這些路徑在所有設備變體上一致，dispatcher 會根據當前設備變體載入對應的桌面 / 平板 / 移動模板。

## ❓ 常見問題（FAQ） {#library-guide-section-18}

**Q: 網站匯入失敗怎麼辦？**
A: 先核對 URL 與網路連通性；Web 端可在**設定 → 代理設定**配置代理；查看 sysbar 的訊息歷史 🔔 看具體錯誤紀錄。

**Q: 可以一次性匯出全部資料嗎？**
A: 可以。**設定 → 匯入/匯出**的「匯出資料」會打包 AI 模型、書籍（含章節內容）、封面歷史、記憶、同步配置、應用設定。

**Q: 字數統計為什麼不更新？**
A: 字數是背景異步計算。批量匯入大量章節後請稍等，進度條結束後會刷新。

**Q: 桌面端主頁沒有 hero，怎麼回事？**
A: 還沒建立任何書籍。添加第一本書後 hero 自動出現。

**Q: 桌面端的 Metrics 數字和平板 / 移動端不一致？**
A: 三個變體使用同一份 store 資料，刷新時機也一致。如果出現跨變體差異通常是快取未刷新；切換路由再回來即可。
