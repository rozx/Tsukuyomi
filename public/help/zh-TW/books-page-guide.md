# 📚 書籍列表頁使用指南 {#books-page-guide-section-1}

書籍列表頁用於統一管理所有書籍項目，支持搜索、排序、匯入、編輯、刪除與收藏。

---

## 📖 頁面概覽 {#books-page-guide-section-2}

- **搜尋**：按標題、別名、作者、簡介、標籤實時過濾。
- **排序**：支持多維排序並記住上次選擇。
- **新增書籍**：手動添加 / 從網站匯入 / 從 JSON 匯入。
- **卡片操作**：收藏、檢查更新、編輯、刪除。
- **全部檢查更新**：一次檢查書庫中所有可檢查的書是否有新章節。
- **分頁**：支持 10/20/50/100 每頁。

---

## 🔍 搜索 {#books-page-guide-section-3}

搜索範圍：

- 標題
- 別名（alternateTitles）
- 作者
- 簡介
- 標籤

輸入後即時生效；右側清除按鈕可快速重置搜索詞。

---

## 🔄 排序 {#books-page-guide-section-4}

當前可選排序項：

- 預設
- 標題 (A-Z)
- 標題 (Z-A)
- 建立時間 (最新)
- 建立時間 (最早)
- 更新時間 (最新)
- 更新時間 (最早)
- 章節數 (多→少)
- 章節數 (少→多)
- 字數 (多→少)
- 字數 (少→多)
- 收藏優先

> 說明：排序選項由設定持久化，重新進入頁面會恢復上次選擇。

## ➕ 添加與匯入 {#books-page-guide-section-5}

### 1) 手動添加 {#books-page-guide-section-6}

點選主按鈕 **新增書籍** 打開表單。

可填寫內容包括：標題（必填）、別名、作者、簡介、標籤、封面、網站鏈接、卷/章結構。書籍級特殊指令（翻譯/潤色/校對）請在書籍詳情的「翻譯設定」中填寫。

新書真正儲存時，目標語言取當前介面語言；網站匯入和 AI 匯入建立新書也遵循此規則。以後可在書籍的翻譯設定中更改目標，介面語言切換不會自動改變已有書籍。

### 2) 從網站匯入 {#books-page-guide-section-7}

通過分割按鈕下拉選擇 **從網站匯入**，進入同步工作區（`/books/new/web`）：輸入小說目錄網址（內建網站也可以貼上某一章的網址）後檢查，先核對「新書資訊」中的書名、作者和簡介，再勾選要匯入的章節（可跳過、可改放到新卷、可預覽正文），確認後顯示擷取進度，建立新書並跳轉過去。詳見「書籍詳情 · 章節」中的「檢查更新與從網站匯入」。

內置支持的站點：

- `ncode.syosetu.com`
- `novel18.syosetu.com`（R18 站點，抓取時自動處理年齡確認；桌面端注入 Cookie 直連，Web 端經外部代理轉發，需 v0.15.0+）
- `kakuyomu.jp`
- `syosetu.org`

其他網站可以在工作區里「交給 AI 匯入器」處理。

### 3) 從 JSON 匯入 {#books-page-guide-section-8}

通過分割按鈕下拉選擇 **從 JSON 匯入**，選擇 `.json` 或 `.txt` 檔案。

支持格式：

- 單本書籍對象
- 書籍數組
- 包含 `novels` 字段的資料
- 包含 `novel` 字段的資料

匯入成功後會顯示成功/失敗數量，並支持復原匯入。

書籍 JSON 匯入保留檔案中的目標與各語言成果；舊檔案缺少語言標記時按簡中恢復，不使用當前介面語言改寫舊書。

## 🧱 書籍卡片資訊與操作 {#books-page-guide-section-9}

每張卡片包含：

- 封面（點選可進入詳情頁）
- 標題、作者
- 章節數、字數、建立時間、更新時間

卡片底部操作：

- ⭐ 收藏/取消收藏
- 🔄 檢查更新（僅來自內建網站或已錄製更新配方的書顯示）
- ✏️ 編輯
- 🗑️ 刪除

有待處理的更新時，封面上會顯示「N 新章」或「N 章待比對」角標，見下文「檢查更新」。

---

## 🔄 檢查更新 {#books-page-guide-section-16}

不進入書籍詳情，也可以在書庫中檢查書籍是否有新章節。只有來自內建網站（見上文「從網站匯入」）或已錄製更新配方的書可以檢查。

### 單本檢查 {#books-page-guide-section-17}

- 桌面版：點書卡底部的 🔄「檢查更新」按鈕；手機版：點書卡上的 🔄 按鈕；平板：在右側書籍詳情中點「檢查更新」。
- 檢查只讀取目錄、不抓取正文，進行中顯示「正在檢查更新…」。完成後提示「發現更新」（例如「《書名》有 3 個新章節」）或「已是最新」；目錄無法依已儲存的規則讀取時，會提示到檢查更新頁處理。
- 有更新時，封面上顯示「N 新章」，或「N 章待比對」（站點上的章節更新日期比本機新）。點選角標（「查看更新」）打開該書的檢查更新頁面，直接沿用剛才的檢查結果，在那裡勾選並套用。

### 全部檢查更新 {#books-page-guide-section-18}

- 書庫工具欄的「全部檢查更新」（手機版、平板為工具欄中的 🔄 圖示按鈕）會逐一檢查所有可檢查的書（不受搜尋篩選影響），同時最多檢查 2 本。
- 進行中按鈕顯示「已檢查 N / 共 M」，再次點選可以取消。全部完成後只彈出一條匯總提示，例如「2 本書有更新」或「已檢查 8 本書，均沒有新章節」；各書的角標照常更新。
- 書庫中沒有可檢查的書時，按鈕不可用。

### 結果保留與重複檢查 {#books-page-guide-section-19}

- 檢查結果儲存在本機（不參與雲端同步），重新整理頁面後角標仍在。匯入新章節、跳過章節或比對正文後，角標會按書籍當前內容自動減少或消失。
- 為避免頻繁請求觸發站點限流，1 分鐘內再次檢查同一本書、或 10 分鐘內再次「全部檢查更新」時，會直接沿用上次結果。需要強制重新檢查時，到該書的檢查更新頁面點「重新檢查」。
- 檢查同樣遵循按站點排隊與暫停規則，詳見 [設定說明](/help/settings-guide#settings-guide-section-12) 的「網站對應」。

## ✏️ 編輯書籍 {#books-page-guide-section-10}

點選卡片“編輯”進入編輯對話框，可修改書籍資訊與配置。

儲存後會更新 `lastEdited`，並支持通過 Toast 撤銷。

---

## 🗑️ 刪除書籍（安全確認） {#books-page-guide-section-11}

刪除需要輸入書名完全匹配後才可執行。

輔助功能：

- 可點選複製按鈕，將標題複製並自動填入輸入框。

比較前會對**輸入與書名同時**做歸一化，因此以下差異不影響匹配（v0.14.4 起）：

- 首尾空白
- 全角空格（`U+3000`）與半角空格
- 零寬字符（BOM / ZWSP / ZWNJ / ZWJ）——網頁抓取的標題里常見，鍵盤敲不出來
- Unicode NFC / NFD 等價形式（例如日文濁音假名的分解寫法）

書名之間的差異僅限上述幾類時，直接手打或用複製按鈕填入都能通過校驗。若書名為空，則任何輸入都不會通過（防止誤刪）。

刪除成功後支持短時間撤銷。

## ❓ 常見問題 {#books-page-guide-section-14}

**Q: 搜索不到書籍？**

A: 先清空搜索詞，再嘗試用標題/作者/標籤等不同關鍵詞。

**Q: 字數顯示延遲？**

A: 字數統計是異步計算，首次載入或資料變更後會短暫延遲。

**Q: 刪除後能恢復嗎？**

A: 可以，在刪除成功提示消失前點選撤銷。

**Q: 書卡上為什麼沒有「檢查更新」按鈕？**

A: 只有來自內建網站、或通過 AI 匯入器錄製過更新配方的書才能檢查更新。手動建立或從 JSON 匯入、且沒有配方的書不顯示該按鈕。

**Q: 匯入報錯怎麼辦？**

A: 檢查檔案格式（JSON/TXT）與資料結構，或檢查網站 URL 是否可訪問。

---

## 🎯 使用建議 {#books-page-guide-section-15}

1. 用收藏標記當前活躍項目。
2. 書籍較多時優先用搜索 + 排序組合定位。
3. 大型作品建議分批網站匯入。
4. 重要資料定期在設定中匯出資料備份。
