# 📥 AI 导入工作台

把小说网址或文件交给月詠，告诉她要导入哪些内容。她会读取正文、整理卷章，你检查后再把小说放进书库。

整个过程是：**添加来源 → 与月詠对话 → 检查草稿 → 确认导入**。看到「可预览」时，小说还没有进入书库；完成最后的「确认导入」才会写入。

## 开始前

先在 [AI 模型配置](/help/ai-models-guide) 中，为「助手」指定默认模型。导入工作台使用这个模型与月詠对话、整理小说。

然后打开「AI 导入」（路由 `/import`）：

| 设备 | 入口                                                                            |
| :--- | :------------------------------------------------------------------------------ |
| 桌面 | 左侧图标栏「AI 导入」                                                           |
| 平板 | 左侧图标栏「AI 导入」，任务列表在工作台的「任务」标签页中                       |
| 手机 | 侧边菜单「AI 导入」，打开任务后默认进入「对话」；底部栏「月詠」按钮也可切回对话 |

桌面和平板的月詠对话在右侧，工作区中间有「来源」「卷章草稿」「导入方案」。手机对应的分区叫「来源」「草稿」「方案」。下文使用桌面的名称。

## 第一次使用：把一本 EPUB 导入书库

手边有一本 EPUB 时，可以照着下面走一遍。网址、TXT 和 Markdown 的具体说法见后面的例子。

### 1. 新建任务，添加文件

点击「新任务」；空白页面上也可以点「新建导入任务」。一个任务整理一本小说，同一本书的多个文件可以放在一起。

切到「来源」，在「添加来源」区域点「选择文件」，选中 EPUB；也可以直接把文件拖进这个区域。添加成功后，来源会显示「尚未读取」，这是正常状态。发送需求后，月詠才开始读取。

### 2. 告诉月詠要做什么

在对话中发送，例如：

> 请把这个 EPUB 导入为一本新小说。按书中的目录分卷分章，保留序言和后记。整理好后告诉我有没有缺章。

接下来，对话里会出现读取来源、提取正文、整理草稿等操作。月詠识别出书名后会给任务命名；你也可以直接修改顶部的任务名称，手动起的名称会保留。

如果月詠问「这几个文件属于哪一本书」或让你选择作品，在对话里回答后她才会继续。暂时想停下来，可以点任务顶部的「暂停」。

### 3. 检查书名、目录和正文

等本轮整理完成，打开「卷章草稿」。建议按下面的顺序检查：

1. 在「基本信息」看书名、作者、简介和标签是否正确；「导入到」应是「新建小说」。这些字段可以直接修改。
2. 如果下面出现「元信息候选」，先核对内容，再点「采用」。这里的元信息就是作者、简介、封面、标签等书籍资料。
3. 查看卷章标题和顺序。章节前的勾选框决定是否导入；不需要的内容可以取消勾选，标题可直接编辑，也可以上移、下移或移到其他卷。
4. 点击章节旁的眼睛图标「检查正文」。至少抽查第一章、中间一章和最后一章，确认开头、结尾都在，正文没有混入目录或导航文字。长章节可点「显示更多」继续查看。

发现问题时，可以直接在对话里说明，例如：

> 第二卷的第 3 章开头混进了目录。请检查这一章，把目录去掉，保留正文。其他章节先不要改。

月詠会读取你已经做过的草稿修改。若同时修改导致版本冲突，重新载入最新草稿后再继续。

### 4. 生成导入方案

打开「导入方案」，点「生成导入方案」。如果月詠已经生成过，直接检查即可。月詠仍在运行或等待回答时，需要先等本轮结束、暂停，或回答问题。

方案会列出这次将写入书库的内容。重点看：

- 顶部是「新建《书名》」还是「更新《书名》」，目标是否正确。
- 有多少章将导入，是否标着「部分导入」，缺失范围是否符合预期。
- 新增、修订、移动和删除段落的数量是否合理。
- 更新已有小说时，会不会清空译文，以及会清空多少个版本。

如果显示「待处理」，按下方提示选择章节对应关系或确认替换。若生成方案后又改了草稿，会显示「已过时」，点「重新生成」后再检查。目标小说有了新修改时，也需要重新生成方案。

### 5. 确认并打开小说

方案显示「可以导入」后，点「确认导入」。弹出的「确认导入到书库」窗口会再次列出目标书籍、章数和译文影响；核对后，再点一次「确认导入」。

看到「已导入」后，点「打开小说」即可进入书籍详情，开始阅读或翻译。

## 换一种来源时，可以这样操作

### 从小说网站导入

在「来源」里粘贴小说目录网址，点「添加网址」。网址只支持 http／https，也可以添加单章页面。然后发送：

> 请导入这个目录里的第一卷，按网站顺序排列。先不要导入第二卷。整理后列出没有取得正文的章节。

月詠会检查目录并抽查章节，再批量提取。同一批最多 500 章；章节更多时需要分批处理。目录里发现的章节链接会显示为「月詠发现」的来源，无需逐章手动粘贴。

需要登录、人机验证或完全依赖脚本显示正文的网站，可能无法读取。此时把缺失章节保存为文件，添加到同一个任务，再告诉月詠文件对应哪几章。已取得的正文会保留。

### 把整本 TXT 拆成章节

添加 TXT 后，告诉月詠文件中的标题长什么样。例如标题是独立一行的「第一章 出发」，可以发送：

> 这份 TXT 是一本完整小说。请按独立一行的「第一章 出发」这类标题拆章，章名保留完整标题。开头的简介和序言先单独列出来，供我选择是否导入。

月詠会预览拆章结果，再整理到草稿。检查时留意章数、重复标题、空章，以及第一章之前的内容。尚未归类的内容会保留为默认未勾选的草稿章，想保留序言时记得勾选。

标题规则复杂时，可以给出几行真实示例，让月詠调整匹配规则；也支持正则表达式。每次拆章最多处理 500 章。

### 按 Markdown 标题分卷分章

添加 Markdown 文件后，可以发送：

> 一级标题是卷名，二级标题是章名。请按这个层级整理，保留章节中的正文和段落顺序。

拆章会识别 Markdown 标题层级，忽略代码块里的类似标题。卷标题的层级需要比章标题更高，例如一级为卷、二级为章。

### 导入多个文件或整个文件夹

点击「选择文件」可一次多选。出现「选择文件夹」按钮时，也可以一次添加整个文件夹；没有这个按钮时用多选文件即可。HTML 文件也可以作为来源。

添加后说明这些文件的关系，例如：

> 这些文件都是同一本书，文件名开头的数字是章节顺序。请合成一本新小说。无法确定顺序的章节先问我。

如果里面混有多部作品，需要先选定本任务处理哪一本，再继续整理。其他扩展名的文件也会尝试按内容解析，能否读取以处理结果为准。

## 继续整理草稿

### 去掉杂质、统一章名

在对话里说清处理范围和要改的内容，例如：

> 删除第一卷每章中单独一行的「返回目录」，其他文字保持原样。

> 去掉已选章节标题末尾的「某某小说网」，保留章节编号和章名。

正文清理支持删除匹配片段或整行，卷章标题支持批量替换。月詠会先查看预览中的命中数量和前后示例，再应用到草稿；每批最多 500 项。可以在对话的操作详情中核对结果。正文清理用于去除来源里的杂质，不会生成新的小说正文。

如果草稿在预览后发生变化，需要重新预览。整理完后还要重新生成导入方案，才会按新草稿导入。

### 补作者、简介、封面和标签

书名、作者、简介和标签可以在「基本信息」中直接填写。输入标签后按回车添加，重复项和首尾空白会自动清理。网站或 EPUB 中的标签也可以提取到候选中。

需要月詠联网查资料时，在 [设置](/help/settings-guide) 配置 Tavily API Key，或保持默认开启的 Firecrawl 回退（无需 Key），再发送：

> 请查找这本书的作者、简介和封面，列出出处供我核对。

月詠找到的信息会显示在「元信息候选」中，点「采用」才进入草稿；有「导入时写入书库」选项的字段，还可以选择是否写入。没配置搜索也可以继续导入正文，资料手动填写即可。

搜索只补书籍资料，不会替你寻找缺章正文。需要使用某个网页的正文时，请把该网址添加到「来源」。

### 删除来源、删除草稿的区别

删除来源会一并移除它派生出的来源入口，但已经生成的草稿章节和已保存的正文引用仍会保留。若还要继续抓取这个来源，需要重新添加。

只是不想导入某章，可以取消它前面的勾选。确定要从草稿移除时，用章节旁的「删除草稿章节」；要重新整理整本书，可用「清空卷章」。这些操作修改的是本任务的草稿。

## 给书库里已有的小说补章

添加新章节的网址或文件，在「卷章草稿 → 基本信息 → 导入到」中选择已有小说，再告诉月詠要补什么。例如：

> 这些文件是书库中《书名》的第 11～15 章。请补到这本书里，检查有没有重复章节，原有章节保留。

月詠也可能给出目标小说建议，需要你点「采用建议」。出现「确认更新这本小说」或章节匹配提示时，先核对书名和章节对应关系。

生成方案后，尤其要检查「新建」还是「更新」以及译文影响。更新遵循以下规则：

- 原文不变的段落保留已有译文，移到其他章节时也一样。
- 原文修订的段落会清空该段的全部译文版本，方案会列出受影响数量。
- 新来源没有包含的旧章节会保留，不会因为这次没提供而被删除。

例如，只提供第 11～15 章时，原有第 1～10 章会保留。如果某章原文确实修订，先查看变化再决定是否导入。

### 先导入成功的部分

有几章读不到时，可以告诉月詠：

> 先整理已经成功取得的章节，列出缺失章节。这次我只导入成功的部分。

方案会标记「部分导入」，说明已取得的范围和缺失章节；目录总数尚未核实时也会说明完整性未确认。核对范围后可以确认导入。

之后把缺失文件补进同一个任务，说明对应章节，再检查目标仍是同一本小说。补齐时，已匹配且未变化的章节不会重复导入，已有译文也会保留。

## 网站连载有新章时，怎么继续更新

网站导入中出现的「更新配方」，记录的是这本书的目录地址、正文位置和清理方式。保存后，下次可以直接在书籍详情的「检查更新」里查看新章，不必重新整理整本书。

例如，这次从网站导入了前 20 章。之后网站发布第 21 章，就打开书籍详情的「检查更新」，检查并选择新章，再确认应用。具体操作见 [章节管理与检查更新](/help/book-details-chapters)。

### 导入前看「更新配方」的状态

月詠会用本任务已经保存的目录页和章节页试读，确认这套方法能得到与草稿一致的正文。这里的「自测」使用已保存页面，不会重新访问网站。

- 显示「新增」或「替换」：确认导入时会一起保存配方。「可复现」表示已经验证过的章节数。
- 显示「保留原有」：继续使用书籍之前的配方。
- 显示「已失效」：先看原因。可以让月詠按当前草稿修正，再重新生成方案；也可以只导入章节，这次不写入失效配方，原有配方保持不变。

比如生成配方后，又从草稿中删掉了每章末尾的导航文字，原来的提取方式可能与草稿不一致。可以告诉月詠：

> 我刚清理了每章末尾的导航文字，请把同样的清理规则记入更新配方，重新自测并生成方案。

有配方的目录中，已进入草稿但被取消勾选的章节会记为「已跳过」，以后检查更新不再把它们当作新章；从未进入草稿的目录章节不会因此被跳过。保存配方时，目录地址也会放到书籍来源网址的第一位。

### 需要重建或修复配方时

在书籍的「检查更新」里点「用 AI 导入器建立配方」或「用 AI 导入器修复配方」。工作台会打开这本书未完成的修复任务，没有则新建，并填好目标书籍、目录来源和问题说明。

检查输入框里的说明后发送，月詠才开始处理。修复后仍要检查方案并确认导入；即使没有新章，也可以只更新配方。

### 哪些来源不能这样更新

配方要求网站目录与导入章节一一对应。把一张网页拆成多章、把多章合在一起，或整卷正文都放在一页的来源，无法生成这种配方。少数有意手工修改的章节可以保留为「固定正文」，最多占 20%。

小説家になろう、カクヨム、ハーメルン等内置站点会使用站点目录规则，正文仍按本次导入方式验证。撤销导入时，配方和来源网址也会一起恢复。

## 暂停、继续和撤销

### 下次再整理

点击任务顶部的「暂停」，等待状态变为「已暂停」，已完成的提取和草稿修改会保留。回来后在任务列表打开原任务，点「继续整理」或「继续执行」，也可以直接发送新的要求。

刷新或关闭页面后，任务不会自动运行，也不会自动导入。来源、草稿、对话和待回答的问题保存在当前设备，导入工作台需要保持打开才能执行，不能在另一台设备续跑。任务本身不参与云同步，确认导入后的书籍可以正常同步。

同一时间只运行一个导入任务，其他标签页也共用这个限制。切到另一个任务时，如果提示已有任务运行，先暂停原任务。

长对话接近模型上下文窗口时会自动压缩：保留最近的对话，较早部分合并为摘要；有待执行的工具调用时不会压缩。也可点对话标题栏的「压缩对话上下文」按钮手动总结全部可总结内容。已保存的来源和草稿不靠聊天记录保存。

### 导入后撤销

打开原任务的「导入方案」，在底部「导入记录」找到这次操作，点「撤销」，再在弹窗中确认「撤销导入」。

- 如果这次新建了小说，撤销会删除该小说及正文。
- 如果这次更新了小说，撤销会恢复导入前的资料、卷章、原文和译文。

开始新的翻译、编辑、同步下载或再次导入后，书籍已有后续修改，就不能整次撤销；只打开查看不影响。书籍已删除或记录已撤销时也不可用，界面会显示原因。

删除导入任务会清除来源、对话、提取结果和撤销记录，已导入的小说仍在书库，但之后不能再通过该任务撤销。

## 遇到这些提示时

| 看到的情况                     | 下一步                                                                                                                   |
| :----------------------------- | :----------------------------------------------------------------------------------------------------------------------- |
| 来源显示「尚未读取」           | 在对话中发送导入要求，或点「继续整理」。添加来源后不会立即读取。                                                         |
| 显示「已检查」，还没有正文     | 月詠已检查页面或文件结构，继续整理才会提取章节。                                                                         |
| 显示「已提取」                 | 内容已经保存；到「卷章草稿」检查章数、顺序和正文，再生成方案。                                                           |
| 来源显示「已排除」             | 该来源不参与本次导入。若仍需要它，在对话中说明要使用哪份来源。                                                           |
| 「处理失败」或章节「提取失败」 | 查看错误原因。临时读取失败可以让月詠只重试失败章节；登录或验证页面请改为补充文件。                                       |
| 「等待回答」                   | 到对话区回答月詠的问题，回答后才会继续。                                                                                 |
| 「可预览」，书库却找不到小说   | 打开「导入方案」，生成或检查方案，再点「确认导入」。                                                                     |
| 「完整性未确认」               | 已发现的章数不一定是全书总数。让月詠继续核对目录，或按部分导入检查并确认。                                               |
| 「确认导入」不可用             | 先看方案顶部提示：等待整理结束、回答问题、处理待处理项，或为过时方案点「重新生成」。显示「无变化」则没有需要写入的内容。 |
| 目标小说正忙                   | 等该书的翻译、润色、校对或助手写入结束。即使已点停止，也要等收尾保存完成，再重试导入或撤销。                             |
| 提示存储失败                   | 先按错误提示恢复存储；恢复前不要关闭页面，最新进度可能尚未保存。                                                         |
| 数据库升级被其他页面阻塞       | 关闭其他打开本应用的标签页，再刷新。                                                                                     |

导入或撤销写入期间，同一本书的新翻译任务会暂时无法开始，完成后即可继续；其他书籍和只读操作不受影响。

浏览器需要支持跨标签页锁（Web Locks），否则无法运行导入、确认导入或撤销。桌面应用使用同一数据目录时只允许一个实例，再次启动会切回已有窗口。

文件超过处理上限时，请拆成较小文件后添加。缺少后台线程的环境会使用更低的处理上限；超限会明确报错，不会把截断正文当作完整结果。
