# 📥 AI 导入工作台

AI 导入工作台（路由 `/import`）让月詠替您把网页、TXT、Markdown、HTML、EPUB 等来源整理成卷章结构，再导入书库——既可以**新建一本小说**，也可以**更新已有的小说**。整个过程分成「整理草稿」和「确认导入」两步：月詠只会修改导入草稿，真正写入书库必须由您检查方案并点击确认。

---

## 🚪 入口与准备

| 设备 | 入口 |
|:-----|:-----|
| 桌面 | 左侧图标栏「AI 导入」 |
| 平板 | 左侧图标栏「AI 导入」，任务列表位于工作台标签页中，对话常驻在右侧 |
| 手机 | 侧边菜单「AI 导入」；对话是工作台的一个分区，打开任务时默认进入，底部栏「月詠」按钮也会切到对话 |

**使用前需要：**

- 在 AI 模型设置中配置「助手」任务的默认模型，导入对话与整理都由它执行。未配置时无法开始。
- （可选）在设置中配置 Tavily API Key，月詠才能联网搜索作者、简介、封面等元信息。未配置时导入照常进行，元信息可由您手动填写。

---

## 🧭 基本流程

1. **新建任务**：每个任务各自保存来源、草稿、对话与导入记录，多个任务互不影响。
2. **添加来源**：在「来源」页输入网址，或选择／拖入文件和文件夹。
3. **让月詠开始**：在对话中说明需求（例如「导入这本书的前两卷」），或直接点击继续。月詠会检查来源、读取目录、抽样确认正文，再批量提取章节。
4. **任务命名**：月詠识别出书名后会为任务命名，便于在列表中区分；您手动改过的名称不会被月詠覆盖。
5. **检查草稿**：在「草稿」页查看和修改书名、作者、简介、卷章标题、顺序、归属，以及每章是否导入。
6. **生成方案**：月詠根据当前草稿生成导入方案，列出新增、更新的章节和对已有译文的影响。
7. **确认导入**：在「方案」页检查后点击确认，这时才会写入书库。
8. **需要时撤销**：满足条件时，可在导入记录中整次撤销。

## 📂 来源

### 可以添加的来源

- **网址**：小说目录页或章节页（仅限 http／https）。
- **文件**：TXT、Markdown、HTML、EPUB。其他扩展名的文件只要内容可读，也会尝试解析，不会仅凭扩展名拒绝。
- **文件夹**：浏览器支持时可以选择整个文件夹；不支持时请一次多选文件。
- **拖放**：把文件拖到「添加来源」区域即可。

### 添加≠读取

添加来源只会登记访问范围，**不会立即抓取或解析**。月詠开始工作后，才会按需逐项检查、读取和提取，每一步都会显示在对话里。月詠在目录或页面中发现的新链接会作为「月詠发现」的子来源登记，并在来源列表里标出。

### 来源状态

| 状态 | 含义 |
|:-----|:-----|
| 已登记 | 已添加，尚未读取 |
| 已检查 | 已读取结构和元信息 |
| 已提取 | 已取得正文，可供草稿引用 |
| 失败 | 读取或提取失败，可查看原因 |
| 已排除 | 已被排除，不参与导入 |

点击来源可以查看已保存的内容和排除记录。删除来源时，其派生来源会一并删除，但已生成的草稿章节和书库内容会保留。

### 网站限制

网页读取沿用应用现有的抓取与代理能力，**没有真实浏览器接管**：

- 需要登录、人机验证或完全由脚本动态渲染的页面，通常只能取得空壳或提示页。月詠会把这类来源标记为未取得正文，不会把页面上的提示文字当作小说正文。
- 遇到这种情况，请把对应章节保存成文件，再补充到**同一个任务**，然后让月詠继续。已成功提取的章节会保留。

## 🔍 元信息搜索

月詠可以用网络搜索补充作者、简介、封面和别名：

- 搜索只用于**元信息**。搜索到的页面即使包含章节正文，也不会被当作正文来源；如确实需要，请您主动把该网址添加为来源。
- 搜索得到的候选信息会连同出处列在草稿的「基本信息」中，由您决定是否采用。候选之间有冲突时，月詠会列出差异并询问。
- 未配置搜索或搜索失败时，已提取的正文不受影响，元信息可以手动填写。

## ✏️ 草稿与方案

- 您在草稿页的修改与月詠的修改作用于同一份草稿，月詠随后会读到您的改动。如果有人基于旧版本修改，该次修改会被拒绝并重新载入，不会覆盖较新的内容。
- 来源中包含多部作品，或来源归属发生变化时，需要先在对话中选定本次要导入的小说，才能继续编辑卷章。
- 方案基于生成时的草稿与目标小说计算。之后草稿或目标小说有变化，方案会标为**过时**，需要重新生成。
- 对已有小说的更新规则：
  - 原文有修订的段落会清空该段的全部译文；原文不变的段落保留原有译文，移动到其他章节时也一样。
  - 新来源里没出现的旧章节**不会被删除**，其正文和译文保持不变。

### 部分导入

没取得全部章节时，也可以只导入已经成功的部分。方案会写明已知总数、成功范围和缺失的章节。导入结果标记为「部分导入」，缺失章节保留待补充记录。之后补齐时，已导入的章节不会重复，未变化的译文也不会被清空。

## ⏯️ 暂停、恢复与上下文压缩

- 对话标题栏提供**暂停**、**继续**与**压缩**。暂停后不会再发起新的步骤，已完成的提取和草稿修改都会保留。
- 同一时间只能有一个导入任务在执行，在其他标签页打开同一应用也一样；其他任务需要等当前任务暂停或结束。
- **刷新或关闭页面后**，任务的来源、草稿、对话和待回答的问题都保存在本机。重新打开后任务不会自动继续，也不会自动写入书库；点击继续即可从中断处恢复，已成功的步骤不会重做。
- 导入只在工作台打开期间执行，**不会在后台持续运行**。任务数据只保存在当前设备，不参与云同步，也无法在另一台设备上继续。
- 对话过长时，月詠会自动把早期记录压缩成摘要后继续；也可以在标题栏手动压缩。
- 月詠需要您做决定时会提出问题并暂停，您在对话中回答后会自动继续。

## ↩️ 撤销导入

每次确认导入都会保存导入前的快照，可在「方案」页的导入记录中整次撤销：

- **新建**的小说：撤销会删除这次导入创建的小说。
- **更新**的小说：撤销会恢复导入前的结构、正文与被清空的译文。

以下情况**不能整次撤销**（界面会说明原因）：

- 导入后这本小说又有了修改，例如新的翻译、编辑、同步下载或其他导入。只是查看不影响撤销。
- 目标小说已被删除，或这次导入已经撤销过。

### 与正在进行的翻译

导入和撤销在写入时会独占目标小说，不会和翻译、润色、校对或月詠助手的写入冲突：

- 这本书正在翻译、润色、校对（包括在其他标签页中）时，确认导入或撤销会提示目标小说正忙，并列出占用者（例如「翻译章节」）。
- **点击停止翻译后，仍须等待收尾保存结束**，才能应用或撤销；已完成的结果会先保存下来。
- 导入或撤销提交期间，同一本书的新翻译任务也会暂时无法开始，提交完成后即可正常开始。其他书籍和只读操作不受影响。

## 🖥️ 运行环境说明

- 桌面应用（Electron）同一数据目录只允许运行一个实例：再次启动会直接切换到已打开的窗口，确保导入与翻译共用同一套互斥规则。
- 浏览器缺少跨标签页锁（Web Locks）时，无法开始导入执行，也无法确认导入或撤销。
- 解析大文件时，若环境不支持后台线程，会改在主线程分段处理，并采用更低的单次处理上限。超出上限时会明确报错，不会把截断的内容当作完整结果。
