# 🛠️ 系统栏与导航 {#toolbar-guide-section-1}

Tsukuyomi 在不同设备上采用不同的系统栏（System Bar）布局，但功能集合一致：**导航 / 任务中心 / 同步 / 月詠助手 / 消息**。本文按设备变体逐一说明各栏的位置与入口。

> v0.12.1 起桌面端整体迁移到工作台（Workbench）语言，左栏改成图标轨道；平板与移动端继续沿用 chip-based sysbar。章节任务的进度统一在顶部的「任务中心」查看（原右栏「翻译进度」与「AI 思考」入口已合并）。桌面右侧图标栏与平板书库页、书籍详情页的右侧竖栏已移除：月詠助手从顶部系统栏打开，向量化进度与操作并入任务中心的「后台 · 向量化」区。

---

## 🖥️ 桌面端布局 {#toolbar-guide-section-2}

桌面端（`useResponsiveLayout` 判定为 `desktop` 或 Electron 强制 desktop）由四个区域组成：

```
+------------------------------------------------------------+
|  Sysbar (AppHeader): brand | Tasks | Sync || 月詠 | Notify  |
+--------+------------------------------------------+--------+
|        |                                          |        |
| Left   |          Workspace (route content)       | 月詠   |
| rail   |                                          | (open) |
|        |                                          |        |
+--------+------------------------------------------+--------+
|  Footer (AppFooter): version | repo link                   |
+------------------------------------------------------------+
```

右侧的月詠助手面板只在打开时出现；关闭时工作区延伸到窗口右边缘。

### 1) 顶部 Sysbar（`AppHeader`） {#toolbar-guide-section-3}

chip 风格的状态栏，从左到右：

- **侧栏开关（`☰`）** — 展开 / 收起左栏图标轨道。
- **品牌** — Logo + 应用名 + Moonlit Translator 副标题。
- **任务中心**
  - 空闲时是一个安静的图标「任务」。
  - 有章节任务运行时显示运行数和整体进度条；同时有排队项时显示运行数、排队数和分段进度条（已完成 / 运行中 / 未开始）。
  - 只有助手对话等其他 AI 活动时显示「AI 处理中」和脉冲圆点；队列暂停时显示「已暂停 · N 排队」；一批任务结束后显示完成与失败数，直到打开任务中心或清除已完成项。
  - 新任务开始时 chip 只闪动提示，不会自动弹出面板。
  - 只有后台向量化在运行时同样显示脉冲圆点，不计入运行数和进度条；向量化被暂停或因同步挂起时不显示。
  - 点击打开任务中心：章节任务按「进行中 / 排队中 / 已完成」分组，点击任务行查看详情（思考、工具调用和输出），可停止、重试、拖动排序、暂停或继续队列；启用本地嵌入时下方有「后台 · 向量化」区（见下文 [后台向量化](/help/toolbar-guide#toolbar-guide-section-10)），再下方「其他 AI 活动」列出助手对话、单段落任务等。可以固定成可移动、可调整大小的悬浮面板，或收起成迷你进度条。详见 [任务队列与任务中心](/help/book-details-translation#book-details-translation-section-9)。
- **同步状态** — 图标 + 状态 chip，状态见下表：

| 状态       | 显示                    | 说明                                                                         |
| :--------- | :---------------------- | :--------------------------------------------------------------------------- |
| 未启用     | 云图标「同步」          | 未配置 Gist 或未开启自动同步                                                 |
| 未同步     | 云图标「未同步」        | 已启用但本地与远端尚未对齐                                                   |
| 已同步     | 云✓「已同步 · 5m / 2h」 | 显示距下次同步的倒计时                                                       |
| 待同步变更 | ↑「N 项变更」           | 检测到本地有未上传的变更（含书籍 / AI 模型 / 封面 / 设置 / 记忆 / 删除墓碑） |
| 同步中     | spinner「同步中」       | 正在执行 push / pull / merge                                                 |

点击打开「同步状态」面板：显示「最后同步时间」「下次同步时间」、「待同步变更」列表和「远程数据」统计（书籍 / AI 模型数量）。同步进行中会显示「整体进度」百分比与进度条，百分比只增不减；进度条下方是当前阶段：「准备本地数据」/「下载中」/「上传中」/「应用中」/「合并中」/「保存同步状态」。面板底部是「同步」按钮；打开「强制推送本地数据到远程（覆盖远程）」开关后，按钮变为「强制推送到远程」。未启用 Gist 同步、同步进行中或正在恢复已删除项目时按钮不可用。

- **月詠** — 💬，位于分隔线之后，点击打开 / 关闭右侧的月詠助手面板，面板打开时按钮高亮。在 AI 导入页，导入助手对话固定显示，按钮保持高亮、点击不会关闭它。
- **消息历史** — 🔔，点击查看 toast 历史；未读角标超过 99 显示 `99+`。可按严重程度筛选（错误 / 警告 / 成功 / 信息），单条删除或清空，部分操作支持撤销。

窗口较窄时（Electron 没有最小窗口宽度），系统栏按顺序收起文字：先隐藏品牌副标题，再隐藏同步倒计时，最后各按钮只留图标（任务中心改为只显示运行 / 排队数字），不会横向溢出。

> **批量摘要按钮已移除**（v0.12 起 AI 章节摘要功能撤回，由 `query_chapter` 工具按需检索原文取代）。

### 2) 左栏图标轨道（`AppSideMenu`） {#toolbar-guide-section-4}

默认是窄轨道，只显示图标；按 `☰` 展开成完整菜单，展开后还会显示「导航」分组和「收藏小说」列表。

主要导航：

- 🏠 **首页** — `/`
- 📚 **书籍列表** — `/books`
- 📥 **AI 导入** — `/import`
- ✨ **AI 列表** — `/ai`

辅助导航（轨道底部）：

- ⚙️ **设置** — `/settings`
- ❓ **帮助** — `/help`

### 3) 右侧助手面板（`AppRightPanelDesktop`） {#toolbar-guide-section-5}

右侧不再常驻图标栏。点击顶部系统栏的「月詠」按钮打开助手面板：面板停靠在右侧、挤窄工作区（不会盖在内容上），可拖拽左边缘调整宽度；面板上的关闭按钮或再次点击「月詠」都会把它收起，收起后右侧不占任何宽度。

- 💬 **月詠（聊天助手）** — 对应 `AppChatPanelDesktop`，包含会话列表、消息流、输入区、上下文（书籍 / 章节 / 段落）、待办、上下文用量进度条。月詠是应用内 AI 助手化身（月下学者人格）。
- 面板关闭时在阅读页对段落使用「复制原文到助手」或「解释选中文本」，会自动打开面板并把内容填进输入框。

> 在 AI 导入页（`/import`），右侧固定显示导入助手对话面板，不能收起。

### 4) 底部 Footer（`AppFooter`） {#toolbar-guide-section-6}

显示版本号与 GitHub 链接（GitHub 图标）。Electron 桌面版会用同样的 footer。

Electron 桌面版在版本号右侧额外显示**更新徽标**（v0.16.1 起，Web 版不显示）：

- `latest`（✓）：已检查且当前为最新版本；尚未完成检查时不显示。
- `vX.X.X · NN%`：发现新版本，正在后台下载。
- `vX.X.X available`：新版本已下载，点击即弹出确认，重启并更新；若有任务或保存未完成，会以提示说明原因。
- `updating…`：正在检查任务与保存状态并准备重启。

详见 [设置说明 · 关于](/help/settings-guide)。

## 📱 平板端布局 {#toolbar-guide-section-7}

平板端（`tablet` 断点）使用紧凑型 sysbar + 左侧导航轨道，页面右侧没有竖向工具轨道，内容延伸到窗口右边缘：

```
+--------------------------------------------------------+
|  TabletSysBar: [list] brand | Tasks | Sync || 月詠 | 🔔 |
+------+-------------------------------------------------+
| Nav  |                                                 |
| rail |           Workspace (route content)             |
|      |                                                 |
+------+-------------------------------------------------+
```

### Sysbar 结构 {#toolbar-guide-section-8}

- **左侧**：书库页的「书籍列表」开关、书籍详情页的「目录」开关（只在这两个页面出现，其他页面不占位置），然后是品牌名 + 当前版本号。竖屏宽度不够时品牌文字以省略号截断。
- **右侧 chips**：任务中心 / 同步状态，分隔线之后是月詠 / 通知 — 各项行为与桌面端一致，只是 chip 更紧凑，月詠只显示图标；同步 chip 显示「同步」「同步中」「N 项变更」或「已同步」。任务中心同样可以固定成悬浮面板。

### 导航与助手 {#toolbar-guide-section-9}

- **左侧导航轨道**（`TabletNavRail`）：顶部 Logo（返回首页），主导航为首页 / 书库 / AI 导入 / AI 模型，底部固定帮助 / 设置。
- **列表 / 目录开关**：在顶部 sysbar 最左侧。竖屏时列表或目录以叠层打开，点外侧即可关闭，按钮同步变为收起状态；横屏时打开会挤窄内容区。
- **月詠**：所有平板页面都能从顶部 sysbar 的「月詠」按钮打开，面板从右侧滑入，点遮罩或再次点击按钮关闭（遮罩不覆盖顶部 sysbar）。AI 导入页横屏时导入助手常驻停靠，按钮保持高亮、点击无效；竖屏时按钮照常开关从右侧滑入的导入助手。

### 后台向量化（任务中心） {#toolbar-guide-section-10}

向量化不再有单独的按钮或抽屉。本地嵌入实际可用时，任务中心在「其他 AI 活动」上方显示「后台 · 向量化」区，三种布局（桌面 / 平板的弹出层与固定面板、手机底部抽屉）内容一致；本地嵌入关闭时整个区不出现。

- **区头**：待处理总数与「暂停向量化」/「继续向量化」按钮，点击标题可折叠（默认折叠，状态会记住）。云同步期间显示「同步中，稍后继续」，同步结束后队列自动继续；同步期间点了暂停的，结束后保持暂停。
- **队列行**：正在处理的类型与数量（「本书 章节 ×N」，处理别的书时显示「其它书籍 · …」和该书书名）、剩余时间；空闲时显示「队列空闲」或「待处理 N」。
- **旧版向量**：模型版本升级后有旧向量时显示「旧版向量：N 个章节 / N 条记忆」，点「重建」入队。
- **书籍详情页**：显示当前书名、「补齐缺失」按钮，以及「章节向量」「记忆向量」两条「已嵌入 X / Y」进度。「⋯」菜单里有「重建本书章节向量」「测试向量查询」「嵌入设置」。
- **其他页面**：只显示全局队列状态，并提示「打开一本书后可补齐或重建该书的向量」。

模型后端（WebGPU / WASM）与模型版本在 **设置 → 本地嵌入** 的模型分组里查看。

本地嵌入是否可用由**设备 UA** 判定（`isMobileDevice()`），与窗口宽度无关：手机、平板等移动设备上始终禁用；桌面浏览器缩窄到平板或手机宽度时，只要在**设置 → 本地嵌入**中开启，仍可正常使用。详见 [本地嵌入](/help/local-embedding)。

## 📲 移动端布局 {#toolbar-guide-section-11}

移动端（`mobile` 断点）使用极简 sysbar + 主体内容 + 底部标签栏：

```
+----------------------------------------+
|  MobileSysBar:                         |
|  logo | Tasks | Sync | 🔔 | Help       |
+----------------------------------------+
|                                        |
|      Route content (full width)        |
|                                        |
+----------------------------------------+
|  MobileTabBar: Home | Library | Chat   |
|                AI | Settings           |
+----------------------------------------+
```

### Sysbar 结构 {#toolbar-guide-section-12}

- **左侧**：Logo + 应用名 + 版本号。
- **右侧 chips**：
  - 任务中心（有任务时显示运行与排队数；点击以底部抽屉打开，点任务行进入全屏详情；手机上不能固定或收起）
  - 同步状态（同步中 / 有变更 / 已同步时显示「同步中」「N 项变更」「已同步」）
  - 通知
  - **帮助**（移动端独有 chip，直接跳到 `/help`）

> 移动端主导航在底部标签栏：首页 / 书库 / 月詠 / AI 模型 / 设置；月詠以底部抽屉打开，没有左栏轨道。本地嵌入（含 `query_chapter` 的语义检索）按设备 UA 判定，在手机等移动设备上被禁用，避免浏览器 WASM 内存上限触发崩溃；桌面浏览器缩到手机宽度不受影响。

## 🔁 跨设备一致的状态语义 {#toolbar-guide-section-13}

不论哪个变体，下列状态来源都是同一份 `useSystemBar()`：

- 待同步变更数（含书籍 / AI 模型 / 封面 / 设置 / 记忆增删改 / 墓碑删除）。
- 距下次同步的倒计时（启用自动同步时）。
- 任务中心状态（运行 / 排队数量、整体进度、暂停状态）。
- 消息历史未读条数。

修改同步配置 / 主动触发同步 / 暂停队列 / 清空消息历史等操作，会立即在三个变体的 sysbar 同步刷新。

## ❓ 常见问题 {#toolbar-guide-section-14}

**Q: 桌面端为什么找不到「批量摘要」按钮？**
A: 章节摘要功能已在 v0.12 移除。AI 现在通过 `query_chapter` 工具按需对原文做语义检索，不再需要预生成摘要。

**Q: 「向量索引」按钮去哪了？**
A: 向量化的进度与操作已并入顶部「任务中心」的「后台 · 向量化」区，任何页面都能查看；补齐、重建与测试查询需要先打开对应的书。请先在**设置 → 本地嵌入**启用功能；移动设备上无法启用。详见 [本地嵌入](/help/local-embedding)。

**Q: 右侧的图标栏去哪了？**
A: 已移除。月詠助手改从顶部系统栏的「月詠」按钮打开；平板书库页的书籍列表开关、书籍详情页的目录开关移到了顶部 sysbar 最左侧。

**Q: 同步按钮一直显示「同步中」？**
A: 检查 Gist 配置、网络连通性与 Token 权限；点开 sysbar 上的消息历史 🔔 查看具体错误日志。

**Q: 原来的「AI 思考」和「翻译进度」入口去哪了？**
A: 两者已合并为顶部的「任务中心」。点击任务中心里的章节任务即可查看进度、思考与输出；助手对话、单段落任务等在任务中心下方的「其他 AI 活动」中。

**Q: 任务中心为空？**
A: 当前可能没有任务记录或已被清除。开始任何翻译、润色、校对任务都会在这里出现。

**Q: 平板端把窗口拉大后变成了桌面布局，为什么本地嵌入仍然灰显？**
A: 物理移动设备的 UA 标识不会因窗口尺寸改变而消失。本地嵌入按 UA 判定（避免移动设备 WASM 崩溃），与窗口宽度无关。
