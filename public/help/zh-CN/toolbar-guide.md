# 🛠️ 系统栏与导航 {#toolbar-guide-section-1}

Tsukuyomi 在不同设备上采用不同的系统栏（System Bar）布局，但功能集合一致：**导航 / AI 思考 / 同步 / 消息 / 右栏面板 / 向量索引**。本文按设备变体逐一说明各栏的位置与入口。

> v0.12.1 起桌面端整体迁移到工作台（Workbench）语言，左/右栏改成图标轨道、聊天与翻译进度独立面板；平板与移动端继续沿用 chip-based sysbar。「向量索引」入口在三种布局下都可用：桌面右栏、平板书籍详情页侧轨、手机顶部 sysbar。

---

## 🖥️ 桌面端布局 {#toolbar-guide-section-2}

桌面端（`useResponsiveLayout` 判定为 `desktop` 或 Electron 强制 desktop）由四个区域组成：

```
+------------------------------------------------------------+
|  Sysbar (AppHeader): brand | AI | Sync | Notifications     |
+--------+------------------------------------------+--------+
|        |                                          |        |
| Left   |          Workspace (route content)       | Right  |
| rail   |                                          | rail   |
|        |                                          |        |
+--------+------------------------------------------+--------+
|  Footer (AppFooter): version | repo link                   |
+------------------------------------------------------------+
```

### 1) 顶部 Sysbar（`AppHeader`） {#toolbar-guide-section-3}

chip 风格的状态栏，从左到右：

- **侧栏开关（`☰`）** — 展开 / 收起左栏图标轨道。
- **品牌** — Logo + 应用名 + Moonlit Translator 副标题。
- **AI 思考过程**
  - 图标 ✨，无任务时显示「AI 思考」。
  - 有任务时变为 pill 状态，显示「AI 思考中」或「AI 处理中」并带脉冲圆点。
  - 点击打开思考面板：进行中任务（模型 / 类型 / 状态 / 用时）、思考消息、最近完成 10 条、停止 / 清空操作。
- **同步状态** — 图标 + 状态 chip，状态见下表：

| 状态       | 显示                    | 说明                                                                         |
| :--------- | :---------------------- | :--------------------------------------------------------------------------- |
| 未启用     | 云图标「同步」          | 未配置 Gist 或未开启自动同步                                                 |
| 未同步     | 云图标「未同步」        | 已启用但本地与远端尚未对齐                                                   |
| 已同步     | 云✓「已同步 · 5m / 2h」 | 显示距下次同步的倒计时                                                       |
| 待同步变更 | ↑「N 项变更」           | 检测到本地有未上传的变更（含书籍 / AI 模型 / 封面 / 设置 / 记忆 / 删除墓碑） |
| 同步中     | spinner「同步中」       | 正在执行 push / pull / merge                                                 |

点击打开「同步状态」面板：显示「最后同步时间」「下次同步时间」、「待同步变更」列表和「远程数据」统计（书籍 / AI 模型数量）。同步进行中会显示「整体进度」百分比与进度条，百分比只增不减；进度条下方是当前阶段：「准备本地数据」/「下载中」/「上传中」/「应用中」/「合并中」/「保存同步状态」。面板底部是「同步」按钮；打开「强制推送本地数据到远程（覆盖远程）」开关后，按钮变为「强制推送到远程」。未启用 Gist 同步、同步进行中或正在恢复已删除项目时按钮不可用。

- **消息历史** — 🔔，点击查看 toast 历史；未读角标超过 99 显示 `99+`。可按严重程度筛选（错误 / 警告 / 成功 / 信息），单条删除或清空，部分操作支持撤销。

> **批量摘要按钮已移除**（v0.12 起 AI 章节摘要功能撤回，由 `query_chapter` 工具按需检索原文取代）。

### 2) 左栏图标轨道（`AppSideMenu`） {#toolbar-guide-section-4}

默认是窄轨道，只显示图标；按 `☰` 展开成完整菜单，展开后还会显示「导航」分组和「收藏小说」列表。

主要导航：

- 🏠 **首页** — `/`
- 📚 **书籍列表** — `/books`
- 📥 **AI 导入** — `/import`
- ✨ **AI 列表** — `/ai`

辅助导航（轨道底部）：

- ⚙️ **设置** — `/settings`
- ❓ **帮助** — `/help`

### 3) 右栏图标轨道（`AppRightPanelDesktop`） {#toolbar-guide-section-5}

右栏收起时是一条图标轨道；点击入口会展开对应面板（宽度可拖拽调整），面板上的关闭按钮会把它收回轨道。轨道入口：

- 💬 **月詠（聊天助手）** — 对应 `AppChatPanelDesktop`，包含会话列表、消息流、输入区、上下文（书籍 / 章节 / 段落）、待办、上下文用量进度条。月詠是应用内 AI 助手化身（月下学者人格）。
- 📊 **翻译进度** — 对应 `AppProgressPanelDesktop`，显示翻译 / 润色 / 校对任务进度条；活跃任务数量以数字角标显示，开始新任务时面板自动切到该任务，可在面板内取消。
- ⚡ **向量索引**（仅书籍详情页，且本地嵌入实际可用时显示） — 打开「本地向量索引」面板，详见下文 [关于本地嵌入入口](/help/toolbar-guide#toolbar-guide-section-10)。

> 切换轨道入口会自动激活对应面板；未激活面板**不挂载**任何 watcher，避免跨面板的副作用。在 AI 导入页（`/import`），右栏固定显示导入助手对话面板。

### 4) 底部 Footer（`AppFooter`） {#toolbar-guide-section-6}

显示版本号与 GitHub 链接（GitHub 图标）。Electron 桌面版会用同样的 footer。

Electron 桌面版在版本号右侧额外显示**更新徽标**（v0.16.1 起，Web 版不显示）：

- `latest`（✓）：已检查且当前为最新版本；尚未完成检查时不显示。
- `vX.X.X · NN%`：发现新版本，正在后台下载。
- `vX.X.X available`：新版本已下载，点击即弹出确认，重启并更新；若有任务或保存未完成，会以提示说明原因。
- `updating…`：正在检查任务与保存状态并准备重启。

详见 [设置说明 · 关于](/help/settings-guide)。

## 📱 平板端布局 {#toolbar-guide-section-7}

平板端（`tablet` 断点）使用紧凑型 sysbar + 左侧导航轨道；书籍列表与书籍详情页右侧另有竖向工具轨道：

```
+--------------------------------------------------------+
|  TabletSysBar: brand | version | AI | Sync | Notify    |
+------+------------------------------------------+------+
| Nav  |                                          | Side |
| rail |        Workspace (route content)         | rail |
|      |                                          |      |
+------+------------------------------------------+------+
```

### Sysbar 结构 {#toolbar-guide-section-8}

- **左侧**：品牌名 + 当前版本号。
- **右侧 chips**：AI 思考过程 / 同步状态 / 通知 — 各项行为与桌面端一致，只是 chip 更紧凑：空闲时显示「AI 思考过程」，有任务时显示「AI 思考中」；同步 chip 显示「同步」「同步中」「N 项变更」或「已同步」。

### 导航与右栏 {#toolbar-guide-section-9}

- **左侧导航轨道**（`TabletNavRail`）：顶部 Logo（返回首页），主导航为首页 / 书库 / AI 导入 / AI 模型，底部固定帮助 / 设置。
- **右侧工具轨道**（`TabletSideRail`，书籍列表与书籍详情页）：列表 / 目录开关、月詠、翻译进度（带任务数角标）；书籍详情页在本地嵌入可用时还会显示「向量索引」按钮。
- 月詠与翻译进度以浮层面板从右侧滑入，点击遮罩即可关闭，交互细节与桌面端一致。

### 关于本地嵌入入口 {#toolbar-guide-section-10}

「向量索引」按钮在三种布局下都有入口，只在**书籍详情页**（`/books/:id` 及其子路由）且本地嵌入**实际可用**时显示：

- 桌面：右栏图标轨道（⚡）。
- 平板：书籍详情页右侧工具轨道。
- 手机：顶部 sysbar 最左侧的 chip。

点击打开「本地向量索引」面板。面板只在主布局中挂载一份：桌面与平板以右侧抽屉打开，手机以底部抽屉打开；窗口断点切换时面板保持打开，切换到另一本书或本地嵌入变为不可用时自动关闭。面板内容：

- 顶部状态：「就绪」/「模型加载中」/「加载失败」/「未就绪」/「已禁用」。
- 「章节向量」：「已嵌入 X / Y」、待处理数量与进度条，提供「回填缺失」和「全部重算」。
- 「记忆向量」：同样显示嵌入进度，提供「回填缺失」。
- 检测到旧版向量时显示「Embedding 空间已升级」横幅，可点「立即重建」。
- 「测试向量查询」：用自然语言检索本书章节或记忆。
- 底部显示模型、后端与队列状态，可「暂停」/「恢复」嵌入队列。

本地嵌入是否可用由**设备 UA** 判定（`isMobileDevice()`），与窗口宽度无关：手机、平板等移动设备上始终禁用；桌面浏览器缩窄到平板或手机宽度时，只要在**设置 → 本地嵌入**中开启，仍可正常使用。详见 [本地嵌入](/help/local-embedding)。

## 📲 移动端布局 {#toolbar-guide-section-11}

移动端（`mobile` 断点）使用极简 sysbar + 主体内容 + 底部标签栏：

```
+----------------------------------------+
|  MobileSysBar:                         |
|  logo | Vectors | AI | Sync | 🔔 | Help |
+----------------------------------------+
|                                        |
|      Route content (full width)        |
|                                        |
+----------------------------------------+
|  MobileTabBar: Home | Library | Chat   |
|                AI | Settings           |
+----------------------------------------+
```

### Sysbar 结构 {#toolbar-guide-section-12}

- **左侧**：Logo + 应用名 + 版本号。
- **右侧 chips**：
  - **向量索引**（⚡，仅书籍详情页且本地嵌入可用时显示，打开底部抽屉）
  - AI 思考过程（有任务时显示「AI 思考中」）
  - 同步状态（同步中 / 有变更 / 已同步时显示「同步中」「N 项变更」「已同步」）
  - 通知
  - **帮助**（移动端独有 chip，直接跳到 `/help`）

> 移动端主导航在底部标签栏：首页 / 书库 / 月詠 / AI 模型 / 设置；月詠与翻译进度以底部抽屉打开，没有左栏轨道。本地嵌入（含 `query_chapter` 的语义检索）按设备 UA 判定，在手机等移动设备上被禁用，避免浏览器 WASM 内存上限触发崩溃；桌面浏览器缩到手机宽度不受影响。

## 🔁 跨设备一致的状态语义 {#toolbar-guide-section-13}

不论哪个变体，下列状态来源都是同一份 `useSystemBar()`：

- 待同步变更数（含书籍 / AI 模型 / 封面 / 设置 / 记忆增删改 / 墓碑删除）。
- 距下次同步的倒计时（启用自动同步时）。
- 当前 AI 任务标签（思考中 / 处理中 / 等）。
- 消息历史未读条数。

修改同步配置 / 主动触发同步 / 暂停队列 / 清空消息历史等操作，会立即在三个变体的 sysbar 同步刷新。

## ❓ 常见问题 {#toolbar-guide-section-14}

**Q: 桌面端为什么找不到「批量摘要」按钮？**
A: 章节摘要功能已在 v0.12 移除。AI 现在通过 `query_chapter` 工具按需对原文做语义检索，不再需要预生成摘要。

**Q: 「向量索引」按钮去哪了？**
A: 该按钮仅在书籍详情页路由（`/books/:id` 及其子路由）下出现，且依赖本地嵌入实际可用：桌面在右栏轨道，平板在书籍详情页右侧工具轨道，手机在顶部 sysbar。请先在**设置 → 本地嵌入**启用功能；移动设备上无法启用。详见 [本地嵌入](/help/local-embedding)。

**Q: 同步按钮一直显示「同步中」？**
A: 检查 Gist 配置、网络连通性与 Token 权限；点开 sysbar 上的消息历史 🔔 查看具体错误日志。

**Q: AI 思考面板为空？**
A: 当前可能没有任务记录或已被清空。开始任何翻译 / 润色 / 校对任务都会留下记录。

**Q: 平板端把窗口拉大后变成了桌面布局，为什么本地嵌入仍然灰显？**
A: 物理移动设备的 UA 标识不会因窗口尺寸改变而消失。本地嵌入按 UA 判定（避免移动设备 WASM 崩溃），与窗口宽度无关。
