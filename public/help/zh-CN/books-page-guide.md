# 📚 书籍列表页使用指南 {#books-page-guide-section-1}

书籍列表页用于统一管理所有书籍项目，支持搜索、排序、导入、编辑、删除与收藏。

---

## 📖 页面概览 {#books-page-guide-section-2}

- **搜索**：按标题、别名、作者、简介、标签实时过滤。
- **排序**：支持多维排序并记住上次选择。
- **添加书籍**：手动添加 / 从网站导入 / 从 JSON 导入。
- **卡片操作**：收藏、检查更新、编辑、删除。
- **全部检查更新**：一次检查书库中所有可检查的书是否有新章节。
- **分页**：支持 10/20/50/100 每页。

---

## 🔍 搜索 {#books-page-guide-section-3}

搜索范围：

- 标题
- 别名（alternateTitles）
- 作者
- 简介
- 标签

输入后即时生效；右侧清除按钮可快速重置搜索词。

---

## 🔄 排序 {#books-page-guide-section-4}

当前可选排序项：

- 默认
- 标题 (A-Z)
- 标题 (Z-A)
- 创建时间 (最新)
- 创建时间 (最早)
- 更新时间 (最新)
- 更新时间 (最早)
- 章节数 (多→少)
- 章节数 (少→多)
- 字数 (多→少)
- 字数 (少→多)
- 收藏优先

> 说明：排序选项由设置持久化，重新进入页面会恢复上次选择。

## ➕ 添加与导入 {#books-page-guide-section-5}

### 1) 手动添加 {#books-page-guide-section-6}

点击主按钮 **添加书籍** 打开表单。

可填写内容包括：标题（必填）、别名、作者、简介、标签、封面、网站链接、卷/章结构。书籍级特殊指令（翻译/润色/校对）请在书籍详情的「翻译设置」中填写。

新书真正保存时，目标语言取当前界面语言；网站导入和 AI 导入创建新书也遵循此规则。以后可在书籍的翻译设置中更改目标，界面语言切换不会自动改变已有书籍。

### 2) 从网站导入 {#books-page-guide-section-7}

通过分割按钮下拉选择 **从网站导入**，进入同步工作区（`/books/new/web`）：输入小说目录网址（内置站点也可以粘贴某一章的网址）后检查，先核对「新书信息」中的书名、作者和简介，再勾选要导入的章节（可跳过、可改放到新卷、可预览正文），确认后显示抓取进度，创建新书并跳转过去。详见「书籍详情 · 章节」中的「检查更新与从网站导入」。

内置支持的站点：

- `ncode.syosetu.com`
- `novel18.syosetu.com`（R18 站点，抓取时自动处理年龄确认；桌面端注入 Cookie 直连，Web 端经外部代理转发，需 v0.15.0+）
- `kakuyomu.jp`
- `syosetu.org`

其他网站可以在工作区里「交给 AI 导入器」处理。

### 3) 从 JSON 导入 {#books-page-guide-section-8}

通过分割按钮下拉选择 **从 JSON 导入**，选择 `.json` 或 `.txt` 文件。

支持格式：

- 单本书籍对象
- 书籍数组
- 包含 `novels` 字段的数据
- 包含 `novel` 字段的数据

导入成功后会显示成功/失败数量，并支持撤销导入。

书籍 JSON 导入保留文件中的目标与各语言成果；旧文件缺少语言标记时按简中恢复，不使用当前界面语言改写旧书。

## 🧱 书籍卡片信息与操作 {#books-page-guide-section-9}

每张卡片包含：

- 封面（点击可进入详情页）
- 标题、作者
- 章节数、字数、创建时间、更新时间

卡片底部操作：

- ⭐ 收藏/取消收藏
- 🔄 检查更新（仅来自内置站点或已录制更新配方的书显示）
- ✏️ 编辑
- 🗑️ 删除

有待处理的更新时，封面上会显示「N 新章」或「N 章待比对」角标，见下文「检查更新」。

---

## 🔄 检查更新 {#books-page-guide-section-16}

不进入书籍详情，也可以在书库中检查书籍是否有新章节。只有来自内置站点（见上文「从网站导入」）或已录制更新配方的书可以检查。

### 单本检查 {#books-page-guide-section-17}

- 桌面版：点书卡底部的 🔄「检查更新」按钮；手机版：点书卡上的 🔄 按钮；平板：在右侧书籍详情中点「检查更新」。
- 检查只读取目录、不抓取正文，进行中显示「正在检查更新…」。完成后提示「发现更新」（例如「《书名》有 3 个新章节」）或「已是最新」；目录无法按已保存的规则读取时，会提示到检查更新页处理。
- 有更新时，封面上显示「N 新章」，或「N 章待比对」（站点上的章节更新日期比本地新）。点击角标（「查看更新」）打开该书的检查更新页面，直接沿用刚才的检查结果，在那里勾选并应用。

### 全部检查更新 {#books-page-guide-section-18}

- 书库工具栏的「全部检查更新」（手机版、平板为工具栏中的 🔄 图标按钮）会逐一检查所有可检查的书（不受搜索过滤影响），同时最多检查 2 本。
- 进行中按钮显示「已检查 N / 共 M」，再次点击可以取消。全部完成后只弹出一条汇总提示，例如「2 本书有更新」或「已检查 8 本书，均没有新章节」；各书的角标照常更新。
- 书库中没有可检查的书时，按钮不可用。

### 结果保留与重复检查 {#books-page-guide-section-19}

- 检查结果保存在本机（不参与云同步），刷新页面后角标仍在。导入新章节、跳过章节或比对正文后，角标会按书籍当前内容自动减少或消失。
- 为避免频繁请求触发站点限流，1 分钟内再次检查同一本书、或 10 分钟内再次「全部检查更新」时，会直接沿用上次结果。需要强制重新检查时，到该书的检查更新页面点「重新检查」。
- 检查同样遵循按站点排队与暂停规则，详见 [设置说明](/help/settings-guide#settings-guide-section-12) 的「网站映射」。

## ✏️ 编辑书籍 {#books-page-guide-section-10}

点击卡片“编辑”进入编辑弹窗，可修改书籍信息与配置。

保存后会更新 `lastEdited`，并支持通过 Toast 撤销。

---

## 🗑️ 删除书籍（安全确认） {#books-page-guide-section-11}

删除需要输入书名完全匹配后才可执行。

辅助功能：

- 可点击复制按钮，将标题复制并自动填入输入框。

比较前会对**输入与书名同时**做归一化，因此以下差异不影响匹配（v0.14.4 起）：

- 首尾空白
- 全角空格（`U+3000`）与半角空格
- 零宽字符（BOM / ZWSP / ZWNJ / ZWJ）——网页抓取的标题里常见，键盘敲不出来
- Unicode NFC / NFD 等价形式（例如日文浊音假名的分解写法）

书名之间的差异仅限上述几类时，直接手打或用复制按钮填入都能通过校验。若书名为空，则任何输入都不会通过（防止误删）。

删除成功后支持短时间撤销。

## ❓ 常见问题 {#books-page-guide-section-14}

**Q: 搜索不到书籍？**

A: 先清空搜索词，再尝试用标题/作者/标签等不同关键词。

**Q: 字数显示延迟？**

A: 字数统计是异步计算，首次加载或数据变更后会短暂延迟。

**Q: 删除后能恢复吗？**

A: 可以，在删除成功提示消失前点击撤销。

**Q: 书卡上为什么没有「检查更新」按钮？**

A: 只有来自内置站点、或通过 AI 导入器录制过更新配方的书才能检查更新。手动创建或从 JSON 导入、且没有配方的书不显示该按钮。

**Q: 导入报错怎么办？**

A: 检查文件格式（JSON/TXT）与数据结构，或检查网站 URL 是否可访问。

---

## 🎯 使用建议 {#books-page-guide-section-15}

1. 用收藏标记当前活跃项目。
2. 书籍较多时优先用搜索 + 排序组合定位。
3. 大型作品建议分批网站导入。
4. 重要数据定期在设置中导出资料备份。
