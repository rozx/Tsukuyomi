# 发布说明 - v0.20.0

## 版本信息

- **版本号**: 0.20.0
- **发布日期**: 2026 年 11 月 24 日
- **基于版本**: v0.19.2

本版本有三项主要变化。整章的翻译、润色、校对改为全局任务队列，由顶部系统栏的「任务中心」统一管理，可以多选章节批量启动并设置同时运行的任务数。新增「外部 Agent」工作台，Claude Code 等本地 Agent 可以通过 MCP 直接读写书库并翻译。界面整体翻新：AI 导入页改为「来源 → 整理 → 导入」三步引导，月詠助手移到顶部系统栏，桌面端右下角新增月詠桌宠，页头、按钮和设置页统一了样式。此外，「获取模型资料」改为在线查询最新目录，侧边栏新增「反馈问题」入口，并清零了依赖安全告警。

---

## 📋 任务队列与任务中心 (Task Queue & Task Center)

- **全局任务队列**：整章的翻译、润色、校对都进入同一个队列，所有书籍共用。任务不依赖当前打开的章节，切换章节、离开书籍详情页或打开其他页面后继续运行。单段落的翻译、润色、校对不进队列，仍然直接执行。
- **同时运行的任务数**：在「设置 → 通用设置 → 任务队列 → 最大同时进行任务」中设置（1–5，默认 2）。调高后排队中的任务立即开始，调低不会中断正在运行的任务。同一章节同时只运行一个任务。
- **任务中心**：顶部系统栏的任务中心取代了原来的「翻译进度」面板和「AI 思考」入口，显示运行数、排队数和整体进度。章节任务按「进行中」「排队中」「已完成」分组，可以暂停或继续队列、全部停止、拖动调整排队顺序、移出排队项，失败或已取消的任务可以重试。助手对话、单段落任务等列在「其他 AI 活动」中，不占用并发名额。
- **任务详情**：点击任务行查看该任务的模型、已用时间、分块进度、待办事项和实时日志（思考、工具调用和输出的时间线）。
- **固定面板**：桌面和平板上可以把任务中心固定成悬浮面板，拖动标题栏移动、拖动边缘调整大小，位置和大小在刷新后保留；固定后还能收起成迷你条。手机上任务中心以底部抽屉打开。
- **断点续跑**：每批译文写入后立即保存，停止、失败或中断后点「重试」只处理剩下的段落。刷新页面或重启应用后队列会保留并暂停，点「继续」后从断点运行。打开多个标签页时只有一个标签页执行队列，其他标签页可以查看和操作。
- **批量启动**：在章节列表点「多选」，勾选章节或整卷（「选未翻译」一次勾选全书未译完的章节），再点底部的「润色」「校对」或「翻译 N 章」。确认对话框逐章列出将处理的段落数或跳过原因，可以选择「只翻译未翻译的段落」或「全部重新翻译」，以及「排在队尾」或「插到队首」。批量任务不逐章弹出提示，整批结束时汇总一次。
- **后台向量化并入任务中心**：启用本地嵌入时，向量化进度显示在任务中心的「后台 · 向量化」区，不再有单独的按钮或抽屉；设置页的「本地嵌入」会显示运行后端与模型版本。

## 🔌 外部 Agent 工作台 (External Agents over MCP)

- **用已有的 Agent 订阅翻译**：新增「外部 Agent」页面（`/mcp`）。Claude Code、Pi、Antigravity 等本地 Agent 可以通过 MCP 建书、导入和补章、分块翻译并写回译文、维护术语、角色、记忆和特殊指令。
- **两种接入方式**：桌面版内置本地 MCP 服务，只绑定本机 `127.0.0.1`（默认端口 `48321`），默认关闭，访问需要 Bearer Token。浏览器版通过 WebMCP 本地中继接入，页面会显示是否已接上本机中继及原因。
- **两步完成接入**：开启服务，然后复制「快速上手指南」交给 Agent。指南会让 Agent 建立项目文件夹、配置好 MCP，并把指南保存为该文件夹里的 `AGENTS.md`，之后在这个文件夹里启动 Agent 就能直接工作。应用更新后，Agent 会自行换成新版指南。
- **三档权限**：「仅只读」「翻译与编辑」（默认）和「完全控制」。只有「完全控制」允许删除书籍，切换到它和重新生成令牌都需要再确认一次。
- **与内置翻译一致**：Agent 遵守的翻译规则、准备 → 翻译 → 复核的步骤与内置翻译是同一份。取翻译块时会带上相关的术语、角色和记忆，上一章末尾的译文与最近几章的标题译名，以及与前文原样重复的段落当时的译法。
- **调用活动**：页面实时显示每次工具调用的参数与返回结果摘要，刷新页面后仍保留。译文历史中会标出外部来源（如 `MCP · claude-opus-4`）。
- **只保存在本机**：端口、令牌、服务开关与权限模式不参与 Gist 同步，也不包含在导出的备份文件中。

## 📥 AI 导入三步引导 (Guided Import)

- **「来源 → 整理 → 导入」**：导入任务按三步进行，顶部显示每一步的进度，点任意一步可以查看；底部是当前这一步的主按钮（「让月詠开始整理」「暂停整理」「生成导入方案」），「确认导入」在「导入」这一步。
- **平板与手机**：导入页分为任务列表和任务两层。平板竖屏和手机在任务顶部显示月詠正在做什么，点它打开对话。手机可以从首页「快速操作」或书库「+」进入「AI 导入」。
- **桌面与平板横屏**：月詠对话停靠在右侧；桌面的任务列表、任务和对话改为平铺分栏。

## 🎨 界面翻新 (Interface Refresh)

- **月詠入口移到顶部**：桌面右侧的图标栏和平板页内的右侧竖栏已移除。点击顶部系统栏的「月詠」按钮打开助手面板，面板停靠在右侧，可以拖动左边缘调整宽度。
- **月詠桌宠**：桌面端右下角新增月詠桌宠。任务中心或助手面板收起时，它在气泡里转述翻译、润色、校对任务和助手回复的进度，任务结束后给出结果小结；点头像打开助手面板。可以在「设置 → 通用设置 → 月詠桌宠」中关闭。
- **统一的页头与控件**：桌面与平板各页面使用同一种页头，按钮和控件统一为淡底薄蓝样式，搜索框与按钮同高；任务、同步、消息三个弹层使用同一外壳。
- **设置页**：各标签统一为分区卡片。同步页的选项改为开关，并分为「自动同步」「立即同步」「危险操作」几个分区。
- **反馈入口**：侧边栏和平板导航新增「反馈问题」，打开 GitHub 的新建 Issue 页面并预填版本号与运行环境；「关于」页新增反馈链接和「在 GitHub 上点 Star」。

## 🧠 翻译上下文与助手 (Translation Context & Assistant)

- **「可能相关」的术语与角色**：原文里的写法与术语名或角色名接近（例如同音字、换了敬称）时，这些条目会作为「可能相关」单独列出并标明原文写法，供 AI 确认后使用。翻译、润色、校对和外部 Agent 的翻译块共用这一提示。
- **衔接上一章**：翻译新章节时，上下文会带上最近几章的标题译名和上一章末尾的已译段落，用来延续语气、标点习惯和标题格式。
- **助手可以移动章节**：聊天助手新增移动章节的能力，可以调整章节在卷内的顺序，或移到另一卷（也可以新建一卷），不改动正文与译文。
- **可选的模糊搜索**：助手搜索术语、角色、词频和帮助文档时可以开启模糊匹配，默认仍为精确匹配；帮助文档搜索现在也会搜索使用文档的正文。

## 🤖 模型资料 (Model Information)

- **内置目录更新**：随应用打包的模型目录快照已刷新。

## 📝 问题修复

- 修复：桌面版点击外部链接会打开应用内窗口。现在改用系统默认浏览器打开，并且只放行 http(s) 和 mailto 链接。
- 修复：刚发布的模型在「获取模型资料」中查不到上限。
- 修复：阅读区在刷新页面或按键后切换章节时，整块正文会被焦点框框住。
- 修复：章节设置和快捷键弹层在按钮下方空间不足时显示不全，箭头没有对准按钮。
- 修复：AI 统计词频时，章节的原始抓取文本会被重复计入。

## 📌 升级说明 (Upgrade Notes)

- 本版本没有同步协议变化，可以直接从 v0.19.x 升级；多设备同步不需要按顺序升级。
- 任务队列只保存在本设备，不参与云同步。
- 桌面右侧图标栏、平板页内右侧竖栏、「翻译进度」面板和「AI 思考」入口已移除：助手从顶部系统栏的「月詠」按钮打开，任务进度和向量化进度在任务中心查看。
- 外部 Agent 的本机配置（端口、令牌、开关、权限）不同步、不导出，换设备后需要重新开启。
- 开发者：Quasar CLI 需要 Node.js 22.22 及以上；Electron 主进程运行时依赖移到 `src-electron/package.json`，构建时注入的常量改用 `import.meta.env`，详见 [`docs/BUILD_TROUBLESHOOTING.md`](../../docs/BUILD_TROUBLESHOOTING.md)。新增 `bun run screenshots`，用演示书库重新生成 README 截图。
