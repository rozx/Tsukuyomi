# 发布说明 - v0.14.2

## 版本信息

- **版本号**: 0.14.2
- **发布日期**: 2026 年 7 月 14 日
- **基于版本**: v0.14.1

> 本版本把书籍级翻译设置提升为书籍工作区的一等入口，并新增按书覆盖翻译、校对与润色模型；桌面 / 平板的「检查更新」也升级为内嵌面板。与此同时，我们集中修复了跨设备同步、长对话压缩、整章翻译持久化、移动端滚动与抓取器布局中的一批数据安全和稳定性问题。

---

## ⚙️ 书籍级翻译设置与本书模型覆盖 (Per-book Translation Settings)

书籍级设置不再藏在章节齿轮弹窗里。桌面 / 平板现在可从书籍详情页侧栏的 **SETTINGS → 翻译设置** 进入独立工作区，集中管理整本书的翻译行为；手机端仍可在阅读器底部抽屉的「全局设置」页签完成同样配置。

- **集中管理书籍级选项**：过滤行首空格、显示时规范化符号、显示时规范化标题、跳过 AI 追问、原文校验，以及翻译任务分块大小
- **新增本书模型覆盖**：可为单本书分别指定「翻译模型」和「校对 / 润色模型」，适合不同题材、文风或成本策略的书籍并行处理
- **安全回退全局默认**：选择「跟随全局默认」即可继承全局配置；若覆盖模型被禁用或删除，任务会自动回退到全局默认，同时在设置页保留失效提示，等待用户重新选择
- **覆盖范围清晰**：本书覆盖作用于整章与段落翻译、润色、校对，以及 AI 工具的翻译兜底；术语翻译、助手和解释任务仍使用全局模型
- **章节设置职责收敛**：桌面 / 平板的章节齿轮弹窗改名为「章节设置」，只保留当前章节的翻译、润色、校对指令；保存章节指令不会再误改书籍级开关或模型覆盖

---

## 🔄 检查更新工作区与移动抓取器 (Book Update & Mobile Scraper)

桌面 / 平板的「检查更新」由临时弹窗升级为书籍工作区内的路由面板。进入面板后会自动带入当前书籍来源 URL、开始抓取并默认筛选未导入章节，章节预览和导入仍沿用原有安全链路。

- **更宽敞的更新工作区**：侧栏 SETTINGS → 检查更新进入 `/books/:id/settings/update`，取消后返回书籍工作台
- **手机交互保持轻量**：手机端继续使用底部抽屉 / 对话框，不强制套用桌面路由面板
- **修复章节列表塌缩**：移动端虚拟列表会填满可用区域，不再缩成狭窄列表
- **两行列表头**：标题与全选位于首行，章节过滤器独占第二行并可横向滚动，窄屏不再挤成三行

## ☁️ 跨设备同步与恢复安全 (Sync & Recovery Safety)

本版本对 Gist 增量同步和修订恢复做了系统性加固，重点避免跨设备 ID 不一致、上传期间继续编辑、单条下载失败或恢复快照不完整时造成重复章节、译文回滚或旧数据覆盖新数据。

- **跨设备条目智能配对**：章节优先按来源 `webUrl`、卷按原文标题回退匹配；不同设备生成了不同本地 ID 时也能识别为同一内容，并保留已有卷译名
- **同步快照边界更准确**：`lastSyncTime` 锚定本地快照生成时刻；上传期间继续产生的编辑会留到下一轮同步，不会被误标为已同步
- **失败条目自动重试**：下载或应用失败的条目不会记录为成功，下轮会重新拉取，避免陈旧本地副本反向覆盖远端新数据
- **备份包含章节正文与译文**：同步失败回滚不再只恢复书籍元数据；独立存储的章节内容也会一并还原
- **修订恢复全有或全无**：必要文件读取不完整时会中止恢复并保留当前本地数据；恢复成功的条目会刷新时间戳并清理对应墓碑，避免下轮再次被删除
- **敏感凭据留在设备本地**：首次上传与强制推送都会剥离同步配置中的 GitHub Token，不会写入 Gist
- **主动拦截截断文件列表**：当 Gist 文件数超过 GitHub API 单次返回上限时，同步会明确中止并提示处理，而不是冒险应用不完整数据

## 💬 月詠长对话与 AI 工具可靠性 (Chat & Tool Reliability)

月詠在长会话、上下文压缩和多轮工具调用中的容错能力得到集中增强，减少摘要失败后回复消失、上下文遗失、会话切换串写，以及不完整工具历史导致后续请求被拒绝的情况。

- **摘要请求先做输入限流**：超长工具结果会截短，并按模型上下文预算保留最近消息，避免摘要请求自身再次超限
- **摘要失败不再吞回复**：界面会正确退出「总结中」状态并使用降级上下文继续请求；既有摘要也会被保留，不再清空早期对话信息
- **会话写入绑定发送时会话**：发送途中切换会话时，流式回复与最终持久化仍写回原会话，避免内容串线
- **工具链保持完整**：裁剪上下文时剔除孤立工具结果；达到轮次上限时补齐失败结果；用户取消后不再执行剩余写入工具
- **绝对轮次上限**：AI 工具循环增加 200 轮硬上限，防止异常模型持续返回纯文本导致无限循环
- **流式 Markdown 更流畅**：增加按消息缓存、LRU 与节流渲染；外链统一使用安全属性，并清理拖拽产生的临时状态

## 📖 翻译持久化与阅读体验 (Translation & Reader Reliability)

- **每个翻译分块立即保存**：整章翻译中途停止或完成部分后立刻刷新，已经完成的批次仍会保留，不再等到整章任务收尾才落盘
- **拒绝半截工具参数入库**：模型输出达到 token 上限导致 JSON 被截断时，系统会要求缩小批次后重试，不再把修补后的半截译文当作成功结果保存
- **修复停止翻译后的大片空白**：译文分批写入不再错误重置虚拟滚动测量，末段下方不会突然出现大段留白
- **修复手机拖动滚动条后触摸失效**：系统取消指针或丢失指针捕获时也会结束拖动状态，页面不会继续被滚动条劫持
- **翻译版本选择更稳健**：淘汰当前译文后会重新指向有效版本；相邻章节读取按全书顺序分页，工具更新会正确上报到界面

## 🧰 构建与代码质量 (Build & Code Quality)

- 生产构建不再对完整源码树重复启动 `vue-tsc` 与 ESLint 检查器，避免部署阶段内存不足或异常退出；开发模式仍保留即时检查
- 聊天面板、帮助页、设置面板和可翻译输入等重复样式已抽到共享文件，模板复杂度和代码重复率进一步下降
- 开发服务器支持通过 `PORT` 环境变量覆盖端口，调试配置可自动分配端口

## 📝 问题修复

- 修复：桌面章节设置仅提交章节指令时，书籍级设置可能被默认值覆盖
- 修复：模型覆盖下拉无法稳定表示「跟随全局默认」与失效模型状态
- 修复：手机翻译设置抽屉长内容被裁切
- 修复：整章翻译中途停止并刷新后，已生成译文可能整章丢失
- 修复：模型输出截断后，JSON 修复逻辑可能把不完整译文静默入库
- 修复：停止翻译后虚拟滚动重新测量，末段下方出现大片空白
- 修复：移动端拖动自定义滚动条后，页面触摸可能持续锁死
- 修复：同步时跨设备 ID 不一致导致卷或章节重复、失败条目不再重试、恢复后条目再次被墓碑删除等问题
- 修复：长对话摘要失败吞掉回复、上下文重复计数、会话切换串写及工具调用历史不完整

---

## ⚠️ 升级提示

- **无 IndexedDB schema 变更，无 manifest schema 迁移**：旧书籍没有本书模型覆盖字段时会继续使用全局默认模型
- 本书模型覆盖随书籍数据自动同步；旧客户端读取未知字段时保持兼容
- 无需重新导入书籍、重建章节内容或重跑本地嵌入
- 多设备用户建议逐台升级后各执行一次同步，以尽快应用新的配对与恢复保护逻辑
