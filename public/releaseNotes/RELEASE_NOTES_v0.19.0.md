# 发布说明 - v0.19.0

## 版本信息

- **版本号**: 0.19.0
- **发布日期**: 2026 年 10 月 24 日
- **基于版本**: v0.18.1

本版本新增原生 Anthropic（Claude）提供商，每个模型可以单独关闭「发送温度参数」，Claude 4.7 及之后的型号会自动关闭。书库可以直接「检查更新」，也可以「全部检查更新」，结果以角标留在书卡上。书籍级特殊指令从编辑书籍弹窗移到「翻译设置」，聊天助手也能查看和修改特殊指令；简繁译文会保留原文的「」『』。网页抓取的站点排队和暂停改为在同一浏览器的多个标签页之间共享。设置导入改为按字段是否存在决定替换还是保留，导入导出进度切换选项卡后也会保留。

---

## 🤖 Anthropic 提供商与温度开关 (Anthropic Provider & Temperature)

- **原生 Anthropic 提供商**：模型对话框的「提供商」新增「Anthropic (Claude)」，直接调用 Anthropic API。「基础地址」可以不填，留空时使用官方地址 `https://api.anthropic.com/v1`；可用模型列表从 Anthropic 获取，并带出上下文窗口与最大输出。浏览器版同样遵循「使用 CORS 代理」开关。
- **思考等级**：Claude 4.6 及之后的型号把思考等级换算为自适应思考的强度，4.5 及更早的型号换算为思考预算；思考摘要会像其他提供商一样显示在思考过程中。
- **提示缓存**：工具定义、系统提示词和对话历史会使用 Anthropic 的提示缓存，长对话和工具循环中重复发送的内容费用更低。
- **「发送温度参数」开关**：每个模型新增「发送温度参数」开关（默认开启）。关闭后，所有任务都不发送温度，温度滑块和默认任务中的任务温度会隐藏，模型卡片上的温度显示为「不发送」。部分新模型（例如 Claude 4.7 及之后的型号）收到温度参数会直接报错。
- **自动关闭**：在模型对话框中把模型标识改成 Claude 4.7 及之后的型号（含 Fable、Mythos，以及 OpenRouter、Bedrock 的写法）时，会自动关闭「发送温度参数」；打开已保存的模型不会改动原有设置。原生 Anthropic 提供商即使开启了该开关，也不会向这些型号发送温度。
- **切换代理后刷新模型列表**：在模型对话框中切换「使用 CORS 代理」后，会按新设置重新获取模型列表，旧请求的结果不再覆盖列表；关闭对话框时会中止尚未完成的请求。现在点击开关旁的文字也能切换开关。

## 📚 书库直接检查更新 (Bookshelf Update Checks)

- **单本检查**：来自内置站点或已录制更新配方的书，在书库的书卡上新增「检查更新」按钮（平板在右侧书籍详情中）。它只读取目录、不抓取正文，不必进入书籍详情页，完成后提示「发现更新」或「已是最新」。
- **结果角标**：有更新的书会在封面上显示「{count} 新章」或「{count} 章待比对」，点击角标（「查看更新」）打开该书的检查更新页面，直接沿用刚才的检查结果，不再重复请求目录。
- **全部检查更新**：书库工具栏新增「全部检查更新」，对所有可检查的书逐一检查（同时最多 2 本），进行中显示「已检查 {checked} / 共 {total}」，再次点击可以取消。完成后只弹出一条汇总提示，例如「{count} 本书有更新」。没有可检查的书时按钮不可用。
- **刷新后保留**：检查结果保存在本机，刷新页面后角标仍在。导入新章节、跳过章节或比对正文后，角标会按书籍当前内容自动减少或消失。这些记录不参与云同步。
- **避免频繁请求**：1 分钟内重复检查同一本书、或 10 分钟内重复「全部检查更新」时，会直接沿用上次结果，不会再次请求站点，避免触发限流。需要强制重新检查时，到检查更新页面点「重新检查」。

## 🗒️ 特殊指令与原文引号 (Special Instructions & Quotes)

- **书籍级特殊指令移到「翻译设置」**：书籍级的翻译、润色、校对指令不再在编辑书籍弹窗中填写，改为在书籍详情的「翻译设置」中维护（手机为阅读器齿轮抽屉的「全局设置」页签），标题为「特殊指令（书籍级别）」。已有指令保持不变。
- **助手可以维护特殊指令**：聊天助手新增查看和修改特殊指令的能力，可以修改书籍级或章节级的翻译、润色、校对指令。当你指出某个译法有误或说明长期偏好时，月詠可以把纠正规则写入特殊指令，之后的翻译就不会再犯。这两个工具只在聊天助手中可用，翻译、润色、校对任务本身不能修改指令。
- **保留原文「」『』**：目标语言为简体或繁体中文时，提示词会要求保留原文的「」『』；AI 仍把它们改成“”‘’时，写入译文前会按原文位置还原。英文译文不受影响。

## 🌐 网页抓取跨标签页协调 (Cross-tab Request Coordination)

- **多个标签页共享排队**：v0.18.1 引入的按站点排队、请求间隔和被拒计数，现在在同一浏览器的多个标签页之间共享。在多个标签页中同时导入或检查同一网站时，请求会依次发出；任一标签页触发暂停后，其他标签页在暂停期间也不再访问该站点。浏览器不支持跨标签页协调或无法使用本地存储时，退回为各标签页分别计算。桌面版不受影响。
- **暂停只看连续拒绝**：以前在上次成功之后累计 3 次拒绝就会暂停，中间夹着网络错误或 404 也照样累计。现在只有连续 3 次拒绝（403、429 或反爬验证页）才会暂停约 5 分钟，夹着成功、网络错误或 404 等其他结果都会重新计数，取消请求不影响计数。

## 💾 设置导入 / 导出 (Settings Import & Export)

- **按字段决定替换还是保留**：导入时，文件中有的字段会整体替换本机对应数据（空数组表示清空），没有的字段则保持本机数据不变。以前备份中缺少书籍或封面历史字段时会清空本机书籍和封面历史，而显式的空 Memory 或空同步配置反而被忽略。字段不为空但没有任何有效条目（例如旧版或损坏的备份）时，按没有该字段处理。
- **保留未导入内容的删除记录**：文件中没有同步配置时，只移除与本次导入的书籍、模型和 Memory 相关的待同步删除记录，其他尚未同步出去的删除照常保留。
- **切换选项卡不再丢失进度**：导入或导出进行中切换到其他选项卡再回来，进度、按钮状态和上次结果都会保留，同一时间也只能进行一个导入或导出。

## 🧭 界面与版本号 (Interface & Version)

- **页面加载提示**：切换页面时顶部的细进度条改为内容区中央的加载提示，只有切换超过 0.3 秒才会出现，在页面布局尚未加载完成时也能显示。
- **版本号格式**：「关于」中的版本号改为 `版本.提交数 (提交 SHA)`，例如 `0.19.0.1600 (a1b2c3d)`，无法确定提交数时只显示 `版本 (提交 SHA)`，方便反馈问题时对应到具体构建。

## 📝 问题修复

- 修复：AI 导入方案中，合并章节等跨越多章的原文替换会归到开头所在的章节，点「确认本章」会顺带确认清空其他章节译文的替换。现在跨章替换单独成行，标有「跨 N 章」并列出涉及的全部章节，按钮为「确认跨章替换」。
- 修复：章节翻译、润色或校对进行中切换到其他页面再回来，任务会误显示为已停止。现在任务状态在切换页面后仍正确显示。
- 修复：切换书籍时，如果新会话尚在创建中，旧书的聊天会话可能被改挂到新书。
- 修复：カクヨム和 syosetu.org 抓取时，含有「お前の話」「次の話」等字样的正文段落会被误当作导航链接删除。现在只删除整段都是导航文字的段落。
- 修复：使用 Claude 并开启思考时，工具循环中的后续请求会因缺少带签名的思考内容而被拒绝。
- 修复：AI 任务中被拒绝的状态切换会在工具调用和工具结果之间插入一条助手消息，导致对话历史格式错误；以助手消息结尾的请求也会被 Claude 4.6 及之后的型号拒绝。

## 📌 升级说明 (Upgrade Notes)

- 本版本没有同步协议变化，可以直接从 v0.18.x 升级；多设备同步不需要按顺序升级。
- 模型新增的「发送温度参数」设置随模型一起保存、导入导出和同步；旧版本没有该字段时视为开启。旧版本不支持 Anthropic 提供商，使用该提供商的模型同步到旧版本设备后会提示「不支持的 AI 提供商: anthropic」而无法调用，请先升级所有设备。
- 设置导入规则有变化：备份文件中缺少的字段不再清空本机数据。需要清空某一部分时，请使用该字段为空数组的文件。
- 开发者：提交钩子与 `bun run setup:git-hooks` 已移除，版本号中的提交数和 SHA 在构建时生成。
