# 发布说明 - v0.16.2

## 版本信息

- **版本号**: 0.16.2
- **发布日期**: 2026 年 9 月 24 日
- **基于版本**: v0.16.1

本版本把 AI 厂商适配层整体迁移到 Vercel AI SDK，并以厂商实测的 Token 用量为基础重做了助手与导入 agent 的上下文管理：长对话压缩后保留近期消息，摘要改为结构化更新，摘要失败不再静默丢弃历史。模型配置新增 models.dev 离线资料、独立的可用性测试与思考等级选项；手机端 AI 模型页也重新设计。

---

## 🔌 AI 厂商层迁移 (AI SDK Provider Backend)

- **统一走 Vercel AI SDK**：OpenAI 兼容服务使用 `@ai-sdk/openai-compatible`，Gemini 使用 `@ai-sdk/google`，原有的手写流式解析与消息转换代码全部移除。
- **兼容行为保持不变**：思考内容与正文分离（含 `<think>` 标签与 DeepSeek `reasoning_content`）、工具调用、空响应报错、取消、Base URL 自动补 `/v1`、自定义请求头和按模型的 CORS 代理开关均照旧可用。
- **Gemini 修复**：生成请求现在会真正使用自定义 Base URL、自定义请求头和 CORS 代理设置（此前只有模型列表请求会使用）；思考模式下的 thought signature 也会正确回传。
- **厂商实测用量**：每次请求都会记录厂商返回的输入 / 输出 / 思考 / 缓存 Token 数，供上下文度量与任务面板使用。

---

## 🧠 上下文管理重做 (Context Measurement & Compaction)

- **实测为准的上下文度量**：以上一次请求的厂商实测输入 Token 数为基准，只对之后新增的内容做估算，估算系数会按该模型的「实测 / 估算」比值自动校准。聊天面板进度条、任务面板与压缩触发共用这一个数值。
- **用量显示**：聊天面板显示 `百分比 · Token 数 / 上下文窗口`；尚无实测数据时数字前带 `≈` 表示近似值；模型未设置上下文窗口时只显示 Token 数、不显示进度条。翻译 / 润色 / 校对任务的「实时日志」标题栏新增当前上下文用量。
- **单一压缩算法**：只在上下文接近模型窗口时触发，从最新消息往回保留近期内容，切点不会拆开工具调用与其结果；被切掉的部分由模型**更新**一份结构化摘要（目标、约束与偏好、进展、关键决定、用户问答、下一步、关键标识），不再反复拼接或「摘要的摘要」。
- **三个触发点**：发送前、工具循环的每一步之间、厂商返回上下文超限错误时（只自动恢复重试一次）。模型窗口未知时只做超限后的恢复压缩。
- **不再按消息条数压缩**：移除「180 条消息自动压缩」「退回最近 5 条」「降级拼接摘要」以及执行模式按估算直接暂停等旧逻辑。摘要生成失败时保留完整历史并直接提示错误。每个会话 200 条可见消息的存储上限保留。
- **导入 agent 同步改用新算法**：压缩后保留近期消息而非清空；仍然保持「有待执行工具调用时不压缩」和超限暂停后自动恢复的行为，手动「压缩对话上下文」仍会总结全部可总结内容。

## ⚙️ 模型配置增强 (Model Setup)

- **获取模型资料**：只查询随应用打包的 [models.dev](https://models.dev) 目录快照，离线可用、不发送生成请求。未收录的型号会提示手动填写，已有数值保持不变；常见的思考等级后缀（如 `gpt-6-sol(high)`）在匹配目录时会被忽略，实际请求仍使用原始模型标识。不再通过「询问模型自身上限」获取资料。
- **资料来源标记**：上下文窗口和最大输出 Token 会标记来源（models.dev / 手动）；手动填写的值始终优先。旧版本通过模型自述获取的数值，若目录有记录则运行时以目录为准。
- **测试可用性**：使用表单中尚未保存的地址、密钥、请求头、代理与思考等级发送一条简短请求，显示成功 / 失败及耗时。最多等待 30 秒，不修改也不自动保存配置；编辑表单或关闭弹窗会取消测试。
- **思考等级**：可选默认、关闭 / 最低、极低、低、中、高、极高。设置随模型保存、导入导出和同步，并用于助手、翻译、润色、校对、术语翻译及上下文摘要。OpenAI 兼容接口映射为 reasoning effort，Gemini 按型号转换为思考等级或思考预算。

## 📱 手机端 AI 模型页 (Mobile AI Page)

- 重新设计手机端 AI 模型页：顶部「添加」按钮；无模型时显示引导卡片与「两步开始使用」说明；已有模型按提供商分组，显示模型数量与已启用数量；原「任务路由」区更名为「任务默认模型」并重新排版，点击任务行即可为翻译、校对、术语翻译、助手分别选择模型。

---

## 📝 问题修复

- 修复：保存 AI 模型时自定义请求头没有被持久化的问题。
- 修复：在模型选择框中直接输入模型标识时，输入焦点会被下拉筛选框抢走的问题（输入法组字时同样适用）。
- 修复：Gemini 生成请求忽略自定义 Base URL、请求头与 CORS 代理设置的问题。

## 📌 升级说明 (Upgrade Notes)

- 已有的聊天会话、导入任务和模型配置无需迁移即可继续使用；旧会话中的 `toolCallTokenOverhead` 修正值会被忽略。
- 新增的模型字段（资料来源、思考等级）均为可选，旧版客户端同步到的数据保持兼容。
- 不再兼容极旧的流式 `function_call` 格式；如果某个自建服务只支持该格式，工具调用可能失效，请反馈。
- 升级了 `gpt-tokenizer`、`@huggingface/transformers`、`jsonrepair` 等依赖，移除了 `openai` 与 `@google/generative-ai`。
