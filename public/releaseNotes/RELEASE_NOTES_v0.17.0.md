# 发布说明 - v0.17.0

## 版本信息

- **版本号**: 0.17.0
- **发布日期**: 2026 年 10 月 1 日
- **基于版本**: v0.16.2

本版本把月詠变成真正的多语言工具：界面、帮助文档与 README 提供简体中文、繁體中文和 English 三种语言；每本书独立设置译文目标语言，原文不再限定日语，各语言的译文、标题和术语 / 角色译名分别保存、互不覆盖。网页抓取新增 Firecrawl 回退，取代原来的「自动切换代理服务」，书籍更新检查改为只读目录、按需逐章比对。同步升级到 manifest v4，术语、角色、别名和译文版本的删除不会再被其他设备的旧数据带回。**多设备同步用户请先阅读文末的升级说明。**

---

## 🌐 三语言界面 (App Localization)

- **界面语言**：在 **设置 → 通用设置 → 界面语言** 选择简体中文、繁體中文或 English，切换后立即生效。没有保存过偏好时按系统首选语言匹配（繁体脚本及台港澳用繁中，简体脚本、中国大陆和新加坡用简中，英语地区用英文，其他语言回退简中）；语言偏好随应用设置同步到其他设备。
- **全面本地化**：页面、对话框、无障碍标签、提示消息、日期与数字格式、组件库文案，以及 AI 任务的状态、问题、待办说明和错误提示都跟随界面语言。抓取、Firecrawl、Gist 同步、备份导入导出和 AI 服务的错误改为稳定错误码，按当前语言显示。
- **AI 执行语言**：助手、翻译 / 润色 / 校对和导入任务在启动时固定界面语言与目标语言，中途切换只影响之后新开始的执行；暂停、重启后继续的导入任务沿用原来的语言。简繁中文对话保持月詠的人格，英文对话改用中性专业表达。
- **帮助文档三语化**：16 篇使用指南和索引提供三种语言，帮助页切换语言时重新加载对应文档并保留章节锚点；AI 的帮助检索工具也按执行语言读取指南。历史更新日志保持简中原文，只本地化分类和简介。
- **README 三语化**：新增 `README.zh-TW.md` 与 `README.en-US.md`，GitHub Wiki 由帮助文档自动生成。

## 🈯 按书设置目标语言 (Multilingual Translation)

- **书籍目标语言**：在 **书籍详情 → 设置 → 翻译设置** 选择简体中文、繁體中文或 English。新书在真正创建时（手动创建、网站导入或 AI 导入确认写入）以当时的界面语言初始化，之后单独修改；切换界面语言不会改动已有书籍。
- **原文不限语言**：AI 按段落判断原文语言，同一本书可以混合多种语言。已经是目标语言的段落可以原样提交并计为已处理，简繁之间仍会按目标转换。
- **各语言成果分别保存**：段落译文版本与选用、卷章标题，以及术语、角色、别名的译名都按目标语言独立保存。切换目标后缺段落或标题译文时显示原文，缺术语 / 角色 / 别名译名时保持为空，不会借用其他语言。润色与校对只处理当前目标语言已有选用译文的段落。
- **上下文与检索按语言隔离**：翻译上下文、章节向量、标题片段和全文索引只使用原文与当前目标语言的译文，切换目标后过期的缓存会在后台重建；记忆库与用户编写的说明在各语言间共享。
- **英文目标的标点**：中文标点规范化只作用于中文目标，英文译文不再被强制转换为中文标点。
- **导出、备份与导入**：导出、书籍 JSON 导入导出、完整备份与恢复、AI 导入撤销都保留目标语言及全部语言的成果。
- **默认封面**：未设置标题的新书生成默认封面时使用界面语言的文字。

## 🔥 Firecrawl 抓取回退 (Firecrawl Fetch Fallback)

- **被拦截时自动回退**：网页抓取顺序改为「网站映射中的代理（按序）或默认代理 → 瞬时错误重试一次 → Firecrawl」。只有网络 / CORS / 超时、403、429、5xx 或返回反爬验证页时才回退，404 等错误照常报告。无需 API Key 即可使用（keyless 模式按 IP 每日限额）。
- **API Keys 新增 Firecrawl 卡片**：可填写 Firecrawl API Key（保存时校验，无效 Key 不会保存），「检查额度」显示剩余额度、套餐额度与账期结束日；「启用 Firecrawl 回退」总开关默认开启，同时控制网页抓取与 AI 网络工具的回退。Firecrawl API Key 与 Tavily Key 一样随设置同步。
- **额度保护**：Firecrawl 请求排队执行（最多 2 个并发），遇到 429 时整个队列按服务端给出的时间暂停；额度耗尽后在一段时间内直接失败而不再发请求，书籍更新检查会停止剩余章节。
- **AI 网络工具**：助手聊天和导入 agent 的 `search_web` / `fetch_webpage` 优先使用 Tavily，未配置或 Tavily 出错时回退 Firecrawl；翻译 / 润色 / 校对任务仍只在配置 Tavily Key 时提供网络工具，避免长任务消耗抓取额度。
- **novel18 支持**：经 Firecrawl 抓取小説家になろう R18 站点（novel18.syosetu.com）时同样携带年龄确认 Cookie，并识别年龄确认页。

## 🗺️ 网站映射独立成页 (Site Mappings)

- 「网站映射」从「代理设置」中拆出，成为网页版与桌面版都显示的独立标签页，映射可以选择 Firecrawl。
- **仅 Firecrawl 可用时自动添加映射**（默认开启，依赖 Firecrawl 回退总开关）：某个网站只能经 Firecrawl 抓取成功时，自动把 Firecrawl 置顶写入该网站映射，下次直接使用。
- 映射表新增删除按钮。桌面版中 CORS 代理条目会标注「桌面端不生效，仅网页端使用」，仍可维护并同步到网页端。

## 🔄 书籍更新检查重做 (Faster Update Checks)

- **快速检查只读目录**：只读取目录页列出新章节，不再下载已导入章节的正文；按站点日期把已有章节分为「无变化」「可能有修订」「未比对正文」。
- **逐章比对正文**：想确认哪些章节原文确有修订时点「逐章比对正文」，有进度、可随时取消；确认未变的章节会记录站点日期，空行差异不再算作修订，30 分钟内已抓取的正文可以复用。经 Firecrawl 限速时显示等待时间。
- **手动添加的章节自动关联**：没有网址的手动章节会按标题或相邻位置关联目录条目并补上网址，不再被重复列为新章节。
- **syosetu.org 目录解析修复**：适配站点新版目录结构，此前在新版页面上取不到章节。

## ☁️ 同步协议升级 (Sync Protocol v4)

- **manifest v4**：书籍携带实体协议版本；旧协议 1–3 的 Gist 会在首次成功同步时迁移。数据量超过单次上传上限时先写入升级标记再分批上传，中途中断时下一次同步会继续完成升级。
- **稳定身份与删除记录**：术语、角色、别名拥有稳定 ID（别名改名保留身份），字段按逻辑版本合并，不依赖设备时钟。删除优先于迟到的离线编辑，书内删除记录长期保留，删除角色也会阻止其旧别名回流。
- **译文版本不再复活**：删除的段落译文版本会留下删除记录，原处修改译文也会推进版本，其他设备的旧副本不会把已删除的版本带回或覆盖较新的修改。
- **明确恢复生成新身份**：撤销删除、从备份或修订历史覆盖恢复、强制推送时，恢复的实体获得新身份并保留已知删除记录，后续同步不会被旧删除记录吞掉。
- **强制推送也检查协议**：强制推送前会读取并验证远端协议和删除记录，遇到更新的协议或读取失败时不上传。

## 📝 问题修复

- 修复：撤销书籍详情中的删除操作时，被删除的术语、角色、别名会在一个事务内一次恢复，不再因为其他标签页已删除而静默跳过部分实体。
- 修复：编辑书籍资料改为只保存实际修改的字段，并应用在最新的存储记录上，不会覆盖其他标签页或同步刚写入的数据；较早发起但较晚完成的保存不再覆盖较新的修改。
- 修复：封面历史在同步与导入时保留封面 ID、添加时间和删除链接，按最新记录去重，不再丢失或重复。
- 修复：数据库升级被其他打开的旧页面阻塞时，应用会先按系统语言显示界面并提示关闭旧页面，不再一直停在加载状态。
- 修复：手机端多个页面的滚动问题、帮助页章节跳转被路由滚动打断，以及章节设置的布局问题。
- 修复：书籍侧边栏的统计与操作按钮保持在同一行；批量翻译待办不再带入原文文本。
- 修复：聊天会话列表的相对时间在每次渲染时更新并按界面语言显示。

## 📌 升级说明 (Upgrade Notes)

- **多设备同步请按顺序升级**：本版本写入 manifest v4，旧版客户端的普通同步无法处理 v4。请先在每台参与同步的设备上导出备份，再把所有设备升级到 v0.17.0，最后逐台完成同步。已发布的旧版强制推送无法被新版拦截，升级前请关闭旧设备的同步，切勿用旧版对共享 Gist 强制推送。降级回旧版本不能安全编辑多语言数据。
- **旧数据归为简中**：已有书籍的目标语言为简体中文，未标记语言的译文、标题和译名都归入简中；旧别名会按确定规则补上稳定 ID。不会自动翻译已有内容。
- **「自动切换代理服务」已移除**：请求失败时不再在代理列表中轮转，`proxyAutoSwitch` 设置不再生效；原「自动添加映射」不再记录成功的 CORS 代理，只记录 Firecrawl。已保存的代理列表和映射保持不变。
- **桌面版抓取改为直连**：Electron 抓取不再经过外部 CORS 代理，被拦截时由 Firecrawl 回退，并开始上报真实的 HTTP 状态码。原先只能经 CORS 代理访问的站点改由 Firecrawl 兜底。
- **隐私**：触发 Firecrawl 回退时，被访问页面的网址会发送给 Firecrawl；AI 搜索回退到 Firecrawl 时，搜索词同样会发送给 Firecrawl。可在 API Keys 中关闭「启用 Firecrawl 回退」。
- 新增 `@intlify/core-base` 与 `@intlify/message-compiler` 依赖（vue-i18n 运行时）。
