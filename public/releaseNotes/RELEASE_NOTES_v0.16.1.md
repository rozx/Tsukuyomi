# 发布说明 - v0.16.1

## 版本信息

- **版本号**: 0.16.1
- **发布日期**: 2026 年 9 月 24 日
- **基于版本**: v0.16.0

本版本为桌面版加入应用内自动更新：新版本在后台下载，由用户确认后重启安装；有翻译、导入、同步或未完成保存时不会重启。桌面分发包同步改为 Windows 便携 ZIP、macOS ZIP 与 Linux AppImage。另修复多处主题颜色变量缺失导致的显示问题。

---

## ⬆️ 桌面版自动更新 (Desktop In-App Updates)

- **自动检查与后台下载**：正式桌面包启动 30 秒后检查一次，之后每六小时检查；发现同平台架构的新正式版本后自动在后台下载。开发模式和 Web 版不执行原生更新。
- **设置 → 关于**：显示当前更新状态（检查中、下载进度、已下载、失败可重试），可手动「检查更新」，下载完成后点击「重启并更新」；也可通过「查看发布版本」前往 GitHub 发布页手动下载。离开关于页再回来会看到当前进度，不会重新开始下载。
- **页脚状态徽标**：桌面版页脚新增更新徽标。确认已是最新时显示 `latest`；下载中显示目标版本与进度；下载完成显示 `vX.X.X available`，点击即可确认重启更新。
- **只由用户触发安装**：普通关闭或下次启动都不会绕过确认自动安装。已下载后若又发布了更高版本，会在后台下载更高版本并在重启时安装它。
- **安全重启保护**：存在翻译、导入、同步、书籍执行锁或未完成保存时，重启请求会被拒绝并提示原因，更新包保持可用。重启前的保存检查期间开始的新工作会照常执行并落盘，本次重启准备改为失败，稍后可再次尝试；准备失败或超时后应用恢复正常使用。
- **更新源绑定**：只从官方 GitHub 发布页选择更新目标，仅主窗口可以触发安装，其他窗口或子 frame 的请求会被拒绝。

## 📦 桌面分发包调整 (Desktop Packaging)

- **Windows**：从单文件便携 EXE 改为 **便携 ZIP**，解压即可运行。请保留整个解压目录（包含更新组件），不要只复制其中的 EXE。
- **macOS**：提供包含 `.app` 的 ZIP，采用 ad-hoc 签名，未经过 Apple 公证。首次打开如遇 Gatekeeper 拦截，请尝试打开一次后进入 **系统设置 → 隐私与安全 → 仍要打开**，无需关闭整台 Mac 的 Gatekeeper。
- **Linux**：提供 AppImage。
- 各平台产物、更新包与清单按平台架构区分，全部构建并校验成功后才公开为正式版本。

---

## 📝 问题修复

- 修复：部分主题颜色变量（如 `--primary-rgb` 等）未定义，导致翻译进度面板、任务状态栏、思考详情对话框、帮助文档等处文字、边框或背景颜色显示异常的问题。
- 修复：关于页元信息颜色未跟随主题色板。

---

## 📌 升级说明 (Upgrade Notes)

- **旧版桌面用户需手动升级一次**：v0.16.0 及更早版本没有更新模块，请从 GitHub 发布页手动下载 v0.16.1；之后的版本即可在应用内自动更新。
- 应用名称与默认数据目录保持不变，书库和设置继续使用原有数据，无需迁移。
- macOS 在无 Developer ID 签名下的应用内更新尚在验证中；若自动更新失败，可随时从发布页手动下载替换应用，原用户数据保留。
- Web 版不受影响。
