# 发布说明 - v0.18.1

## 版本信息

- **版本号**: 0.18.1
- **发布日期**: 2026 年 10 月 14 日
- **基于版本**: v0.18.0

本版本是 v0.18.0 之后的修复与体验改进版本，没有数据格式变化。网页抓取改为按站点排队：同一站点一次只发一个请求、每次间隔 1 秒，连续被拒 3 次后暂停访问该站点约 5 分钟，避免 Web 版共用的 CORS 代理被カクヨム等站点封禁。「从网站导入 / 检查更新」新增新书信息卡、应用进度和 Firecrawl 抓取章数；AI 导入工作台中，段落切分方式不同造成的大量「替换」改为自动接受或按章合并确认；设置页的「导入资料 / 导出资料」现在会显示进度、结果和当前数据量。

---

## 🌐 按站点排队抓取 (Per-site Request Throttling)

- **同站请求排队**：抓取小说网站时，按目标站点排队：同一站点一次只发一个请求，相邻请求至少间隔 1 秒。以前批量导入和检查更新会同时抓取 3 章、且不留间隔，很容易触发站点对 CORS 代理出口 IP 的限流。
- **连续被拒后暂停该站点**：同一站点连续 3 次拒绝请求（403 / 429，或返回反爬验证页）后，会暂停访问该站点约 5 分钟，期间不再发请求，避免越请求封得越久。同一次请求在多个代理之间切换、重试，只算一次。
- **批量任务及时停止**：站点被暂停后，AI 导入的批量提取和「检查更新」的应用会像 Firecrawl 额度用尽时一样停止领取新章节，已取得的章节保留，稍后可以继续。已启用 Firecrawl 回退时，被暂停的站点会改由 Firecrawl 抓取。
- **更清楚的错误提示**：站点拒绝请求或被暂停时，错误提示会说明原因，并按平台给出建议。浏览器版会建议改用桌面版直连，或在「网站映射」中为该站点启用 Firecrawl；桌面版则建议稍后重试或启用 Firecrawl。例如「{host} 连续拒绝请求（可能在对代理出口 IP 限流），已暂停访问该站点约 {minutes} 分钟」。

## 📖 从网站导入与检查更新 (Book Sync)

- **新书信息**：从网站新建书籍时，检查结论上方会显示「新书信息」卡片，包括封面、书名、作者、标签和简介；简介较长时默认折叠，可点「展开简介」查看。这些信息以前只在创建书籍时使用，页面上看不到。更新已有书籍时不显示该卡片。
- **应用进度**：点「应用到书籍」或「应用并创建书籍」并确认后，确认窗口里会显示进度条和「正在抓取正文 {completed} / {total}」。Firecrawl 因限速暂停时，旁边显示「（等待 Firecrawl 限速，约 N 秒）」；全部抓取完成后显示「正文已抓取，正在写入书籍…」。以前抓取十几章可能要等一分多钟，期间只有一个加载图标。
- **显示 Firecrawl 抓取章数**：「逐章比对正文」的进度和应用完成的通知中，会显示「其中 {count} 章经 Firecrawl 抓取」，方便了解 Firecrawl 额度的使用情况。已缓存的章节不计入。
- **新建书籍的通知**：新建书籍完成后，通知标题改为「书籍已创建」（部分章节失败时为「书籍已创建，部分章节失败」）。

## 📥 导入方案中的原文替换 (Import Plan Replacements)

用 AI 导入器更新已有书籍时，如果新旧来源的段落切分方式不同（例如书籍原先用内置カクヨム规则导入，这次改用 AI 导入器），方案中会出现大量「多段替换」。以前同一处替换会被列出两次：一次作为无法操作的冲突说明，一次作为只显示段落数量的替换项，而且只能逐条确认，每次确认都要重新生成整个方案。

- **不丢失译文的替换自动接受**：没有清空任何译文版本的替换，在生成方案时会自动接受；只有会清空译文的替换才需要你确认。
- **按章合并**：待确认的替换按章节合并为一行，显示章节名，以及「{ranges} 处替换：{removed} 段旧原文 → {added} 段新原文，清空 {versions} 个译文版本」。点「确认本章」一次确认整章。
- **查看原文**：点「查看原文」可以逐处对比「旧原文」和「新原文」。旧版本保存的方案中没有原文，不提供对比。
- **一次全部确认**：「待处理」卡片右上角新增「全部确认替换（{count}）」，所有替换只修改一次草稿、只重新生成一次方案。
- **计数一致**：替换产生的冲突说明不再单独列出，待处理数量与方案状态中的计数一致。

## 💾 设置导入 / 导出 (Settings Import & Export)

- **显示当前数据**：「导入资料」卡片中会显示「当前数据（导入后会被整体替换）」，列出 AI 模型、书籍、章节、封面历史、Memory 和同步配置的数量，导入之前可以确认会覆盖多少数据。
- **进度与阶段**：导入时显示进度条和当前阶段，例如「正在备份当前数据…」「正在导入书籍…」「正在导入 Memory…」，并提示「进行中，请不要关闭或刷新页面」。导出时显示「正在打包导出数据…」。
- **防止重复操作**：导入或导出进行中，两个按钮都不可用。
- **保留结果**：最近一次导入或导出的结果（成功，或失败及原因）和完成时间会留在面板上，不会只在通知中一闪而过。
- **失败不再静默**：以前写入数据或导出过程中出错时没有任何提示，现在会显示错误原因。导入失败时，会恢复到导入前的数据。

## 📝 问题修复

- 修复：从网站导入时粘贴的是章节网址（例如カクヨム的某一话）时，会把章节页当作目录页读取，因读不到作品数据而被误报为配方失效。现在所有内置站点都会先换算成作品目录页再检查。
- 修复：第一次打开设置页（还没有记住过选项卡）时，打开的是「AI 模型」而不是「通用设置」。现在默认打开「通用设置」，之后仍会记住上次打开的选项卡。

## 📌 升级说明 (Upgrade Notes)

- 本版本没有数据格式或同步协议变化，可以直接从 v0.18.0 升级；多设备同步不需要按顺序升级。
- 按站点排队后，同一站点的批量抓取会比以前慢一些（每章至少间隔 1 秒），但被站点限流的可能性明显降低。
